## 摘要
统一音频-语言建模已成为现代语音系统中的一个突出趋势，有望将大型语言模型的推理能力引入听觉任务。然而，现有的统一基础模型往往难以在自动语音识别 (ASR)、文本到语音合成 (TTS) 和实时口语交互方面达到专用系统的深度。弥合这一差距仍然是一个公开挑战。本报告介绍了 StepAudio 2.5，一个统一音频-语言基础模型，它在所有三个能力方面与专用系统相当或超越之。我们不将这些任务视为架构上截然不同的，而是基于这样一个前提：一旦文本和音频共享多模态表示空间，任务专门化就变成了操作制度的问题：数据构建、优化目标和解码约束。在这一见解的指导下，我们将后训练范式从标准的监督学习推进到任务定制的基于人类反馈的强化学习 (RLHF)，将其作为定义复杂优化目标的主要机制。我们利用这种以 RLHF 为中心的对齐，结合专门化解码，将共享主干塑造为三种不同的操作模式。具体来说，ASR 分支通过可验证的多 token 解码提升转录效率；TTS 分支通过基于偏好的 RLHF 和丰富的上下文监督实现可控、富有表现力的合成；实时分支通过在 RLHF 框架内的生成式奖励建模实现低延迟、人物角色一致的对话。在标准基准测试中，StepAudio 2.5 在 ASR、TTS 和实时方面取得了最先进的结果，表明单一的音频-语言基础可以成功地将语音理解、生成和实时交互的不同部署目标内化。

## Abstract
Unified audio-language modeling has emerged as a prominent trend in modern speech systems, promising to bring the reasoning capabilities of large language models to auditory tasks. However, existing unified foundations often struggle to match the depth of specialized systems across automatic speech recognition (ASR), text-to-speech synthesis (TTS), and realtime spoken interaction. Bridging this gap remains an open challenge. This report presents StepAudio 2.5, a unified audio-language foundation model that matches or exceeds specialized systems across all three capabilities. Rather than treating these tasks as architecturally distinct, we operate on the premise that once text and audio share a multimodal representational space, task specialization becomes a matter of operational regimes: data construction, optimization targets, and decoding constraints. Guided by this insight, we advance the post-training paradigm from standard supervised learning to task-tailored Reinforcement Learning from Human Feedback (RLHF), using it as the primary mechanism to define complex optimization targets. We leverage this RLHF-centric alignment, alongside specialized decoding, to shape a shared backbone into three distinct operational modes. Concretely, the ASR branch advances transcription efficiency via verifiable multi-token decoding; the TTS branch achieves controllable, expressive synthesis through preference-based RLHF and context-rich supervision; and the Realtime branch realizes low-latency, persona-consistent dialogue via generative reward modeling within an RLHF framework. On standard benchmarks, StepAudio 2.5 achieves state-of-the-art results across ASR, TTS, and Realtime, demonstrating that a singular audio-language foundation can successfully internalize the distinct deployment objectives of speech understanding, generation, and live interaction.

- **研究动机**：当前语音系统正在向统一音频-语言架构收敛，将语音视为大语言模型（LLM）可处理的另一种序列。然而，现有的统一基础模型在自动语音识别（ASR）、文本到语音合成（TTS）和实时口语对话这三个核心任务上，仍难以匹敌专用系统的深度与效率。
- **核心问题**：如何在单一共享模型内，同时达到 ASR 的高精度与高效率，TTS 的可控、自然与表现力，以及实时对话的低延迟、人物角色一致和副语言敏感性，是未决挑战。
- **整体含义**：提出 StepAudio 2.5，一个统一音频-语言基础模型，其前提是：一旦文本与音频在共享表示空间中良好对齐，任务专门化就不再依赖结构差异，而转化为数据、优化目标和解码约束等**操作制度**问题。借助以 RLHF 为核心的后训练范式和特定解码策略，该模型在三项任务上均达到或超越专用系统，证明单一基础可以内化语音理解、生成与交互的多元化目标。

## 2. 方法论

### 2.1 共享架构与阶段化预训练
- **基础架构**：冻结的音频编码器 + 轻量适配器 + LLM 解码器（MoE 文本模型初始化）。解码器可处理文本和音频 token。
- **预训练课程**：
  - 第一阶段：3B token 的 ASR 数据，仅训练适配器，对齐声学与文本特征。
  - 词汇扩展：增加语音 token，开始统一多模态训练（文本 800B + 语音 800B）。
  - 冷却阶段：600B token 高质量数据，序列长度从 16K 增至 32K，引入音频描述和指令化 TTS 数据。
- **核心思想**：预训练建立文本与音频之间的“操作接口”，而非简单的关联映射，使后续 ASR、TTS、实时三方向均复用同一主干。

### 2.2 ASR 分支：可验证多 token 解码（MTP）
- **机制**：在解码器末端附加并行 MTP-5 头，一次前向预测 6 个 token（主预测下一个 token，5 个分支预测未来第 2~6 个 token）。
- **推理保障**：仅当后续 token 与正常验证路径一致时才被接受，否则回滚 KV 缓存，严格保证转录准确性与自回归等价。
- **训练策略**：
  - 先做 ASR SFT，使用 SpecAugment 等增强。
  - MTP 分两阶段：冻结主干，仅训练 MTP 块（继承最后一层变换器参数），再用低学习率联合校准主干与分支。
  - 损失函数：主 token 交叉熵 + 加权分支损失，分支权重指数衰减（α=0.9）。

### 2.3 TTS 分支：基于 RLHF 的可控合成
- **取消编码器-适配器**：TTS 分支完全基于 LLM 主干，将音频 token 视作新的“语言”，合成为纯下一 token 预测任务。
- **监督微调（SFT）**：
  - 大规模零样本声音克隆，提供全局指令控制。
  - 引入内部高质量录音，标注全局和**内联**表达指令，实现精细粒度控制（如语调、情感）。
- **RLHF**：
  - 训练生成式奖励模型（GRM），对策略模型生成的音频与参考响应进行相对质量打分。
  - 将 GRM 评分经奖励塑形变换作为 PPO 优化信号，对齐复杂、抽象或高度上下文依赖的指令，提升自然度与表现力。

### 2.4 实时分支：面向低延迟对话的渐进对齐
- **三阶段训练**：
  - 音频中心的中训练：继承基础模型的全模态感知与长文本推理。
  - 渐进 SFT：依次注入**对话对齐**（口语化、中断处理）、**人格与风格控制**（大规模可组合人格矩阵）和**副语言敏感性**（捕捉停顿、笑声、叹息等，并联动语调调节）。训练中持续混入通用指令数据以防灾难性遗忘。
  - RLHF 结合生成式奖励：使用多轮对话和单轮提示混合数据，评分不仅基于整体自然度，还引入清晰交互评分准则（rubric），特别关注跨轮一致性和对用户内容的忠实度。

## 6. 主要结论与发现

- **单一基础可行**：共享音频-语言主干，通过不同的后训练目标和解码方案，可以同时达到 ASR、TTS 和实时交互的 SOTA。
- **ASR 高效精准**：MTP-5 在保持准确率不变的前提下，将 RTF 降低至 0.0053，远优于对比系统，证明了“接地”任务中可验证多 token 解码的加速优势。
- **TTS 统一为下一 token 预测**：纯 LLM 预测音频 token，加上全局/内联控制和 RLHF，获得了较高的胜率（67.6%），说明 RLHF 能有效对齐复杂表达。
- **实时交互需要渐进式对齐**：通过分阶段注入对话、人格、副语言能力，并以 RLHF 强化，模型在主观和客观基准上显著优于竞争对手，同时保留了基础推理能力，防止遗忘。
- **RLHF 升格为中心范式**：从单纯的 SFT 升级为以 RLHF 定义多任务复杂目标的核心手段，是缩小与专用系统差距的关键。

## 7. 优点

- **架构统一且务实**：共享主干 + 分支专门化，无冗余子模型，降低工程和维护复杂度。
- **将任务差异视为操作制度问题**：理论清晰，指导了数据、目标和解码的协同设计。
- **ASR 加速思路优雅**：利用声学信号的确定性，引入可验证多 token 解码，不牺牲精度而大幅提高解码效率，并给出详细的接受率衰减分析。
- **TTS 的内联细粒度控制**：支持在文本中直接插入表达指令（如语调、情绪），增强了合成语音的表现力和对齐性。
- **实时对话的全面性**：兼顾对话连贯性、人格一致、副语言感知和低延迟，训练策略（动态预演、评分准则）防止遗忘。
- **丰富的训练数据工程**：多系统验证、ROVER 融合、LLM 后处理等确保长格式 ASR 标签质量；人格矩阵裂变生成海量组合样本。

## 8. 不足与局限

- **算力与规模不透明**：训练总数据量（2.2T token）巨大，但未披露实际训练使用的 GPU 数量、时长，使资源需求难以评估，外部复现门槛高。
- **TTS 评价单一**：仅依赖 Arena 式主观胜率，未配套客观测听指标（如 CER、MOS 或基于嵌入的相似度），可能隐藏某些质量维度（如跨域鲁棒性、长句稳定性）的弱点。774 个提示的覆盖范围是否足够也未充分论证。
- **实时评估基线模糊**：只给出柱状图对比，未指明参与比较的模型名称和版本，无法明确其 SOTA 水平归属。
- **缺乏内部消融**：TTS 中 RLHF 相对于 SFT 的增量、实时分支中各阶段（对话对齐、人格、副语言）的单独收益、不同数据配比的影响等均未量化，削弱了方法可解释性。
- **泛化与偏见风险**：训练数据中多语言（中英为主）可能使其他语种性能退步；人格矩阵虽然规模大，但仍可能从数据中继承恶意刻板印象或语气偏差，未进行安全对齐评估。
- **应用限制**：实时对话的延迟虽低，但完全闭环在 LLM 自回归产生音频 token，对极端网络波动或算力受限设备的适配未讨论。TTS 纯 NTP 方式可能在某些极端韵律或非语音声音生成时受限。

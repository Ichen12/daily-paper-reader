## 摘要
词错误率（WER）是自动语音识别（ASR）的主要评估指标，但当参考文本和假设文本使用不同文字编码相同单词时，它可能会高估错误。这个问题在多语言环境中很常见，因为ASR模型可能输出罗马化文本。我们提出了文字标准化WER（SN-WER），一种无需训练、仅用于评估的评分方法，它在计算WER之前将参考文本和假设文本都音译为特定语言的规范文字。我们在5种印度语言、2个数据集和3个ASR模型上评估了SN-WER。在精心整理的FLEURS数据上，SN-WER将被夸大的模型差距减少了最多12%，而在噪声较大的Common Voice数据上，减少幅度较小或不一致，这表明存在真正的识别弱点，而不仅仅是文字不匹配。受控压力测试显示，人工罗马化引起的WER膨胀被衰减了67%，而词汇替换控制显示对语义错误的敏感度几乎相同，Δ SN-WER / Δ WER 约为 1.09。SN-WER对音译器选择、标准化变化具有鲁棒性，并且在所评估的印度语言环境中标记碰撞率低于0.1%。我们认为，SN-WER应与WER和CER一起作为对文字不敏感的ASR评估的辅助指标报告，特别是当转录文本用于下游搜索、索引或多语言LLM管道时。

## Abstract
Word Error Rate (WER) is the dominant metric for automatic speech recognition (ASR), but it can overestimate errors when references and hypotheses encode the same words in different scripts. This issue is common in multilingual settings where ASR models may emit romanized text. We propose Script-Normalized WER (SN-WER), a training-free, evaluation-only scoring method that transliterates both reference and hypothesis text into a language-specific canonical script before computing WER. We evaluate SN-WER on 5 Indic languages, 2 datasets, and 3 ASR models. On curated FLEURS data, SN-WER reduces inflated model gaps by up to 12%, while on noisier Common Voice data the reductions are smaller or inconsistent, indicating genuine recognition weaknesses rather than only script mismatch. Controlled stress tests show a 67% attenuation of artificial romanization-induced WER inflation, while lexical-substitution controls show near-identical sensitivity to semantic errors, with Delta SN-WER / Delta WER approximately 1.09. SN-WER is robust to transliterator choice, normalization changes, and shows low token-collision rates below 0.1% in the evaluated Indic setting. We argue that SN-WER should be reported alongside WER and CER as a companion metric for script-insensitive ASR evaluation, especially when transcripts feed downstream search, indexing, or multilingual LLM pipelines.

### 1. 研究动机与核心问题
- **核心问题**：在多文字（multi-script）自动语音识别评估中，当参考文本使用本地文字（如天城文、泰米尔文），而模型假设文本输出罗马化转写时，标准词错误率（WER）会将**文字不匹配等同于词汇错误**，从而**系统性高估错误率**。
- **背景与意义**：
  - 多语言ASR（尤其是印度语言）普遍存在模型输出罗马化文本的现象，导致模型性能被误判。
  - 现有指标（WER、CER）未区分文字表面差异和真实的识别错误，干扰模型间公平对比。
  - 下游任务（搜索、索引、多语言LLM）常对文字不敏感，因此需要一个**量化文字不匹配影响**的伴随指标。

### 2. 方法论：SN-WER 评分框架
- **核心思想**：在计算WER之前，将**参考文本与假设文本统一转写**为特定于语言的**规范文字**（通常为基准数据集的本地文字），从而消除文字差异引入的惩罚。
- **公式定义**：
  - 标准 WER = (S + D + I) / N，其中 S、D、I 为编辑操作。
  - **SN-WER(R, H) = WER( T(R), T(H) )**，T 为确定性、保留分词边界的转写映射。
- **关键实现细节**：
  - **转写工具**：采用 ICU、IAST 风格或 ITRANS 风格的映射，并基于 Unicode 块启发式检测罗马化字符，自动触发本地文字转写。
  - **规范化**：统一处理 Unicode 变体、标点与数字，但不合并/拆分词条。
  - **属性设计**：
    - **同一性**：若参考与假设原本同文，SN-WER ≈ WER。
    - **保守性（条件性）**：理论期望 SN-WER ≤ WER，但需实证检验转写碰撞和分词歧义。
    - **词汇敏感度**：仅消除文字差异，对真正的词汇错误（替换、删除、插入）保持完全惩罚。
- **定位**：**仅用于评估**，无需重训模型、修改解码器或额外标注数据。

- **鲁棒性**：转写工具间差异 < 0.002；归一化变动 < 0.05；标记碰撞率 < 0.1%；对抗性检查中 SN-WER 对词序和错词依然给出近 1.0 的惩罚。
- **跨文字推广**：在阿拉伯语（5−7% 相对改善）和乌尔都语（6−9%）上同样有效。
- **使用建议**：SN-WER 应作为 WER/CER 的**辅助指标**共同报告，尤其适用于文字不敏感的下游应用。

### 7. 优点
- **免训练、仅评估**：即插即用，无需改动 ASR 系统。
- **系统性的诊断鲁棒性**：通过音译器分歧、归一化消融、碰撞率、对抗测试和 bootstrap 置信区间等多重保障，使指标可靠性可量化。
- **区分文字与词汇错误**：受控注入实验清晰证明了该指标的预期行为，避免了“一刀切”降低分数的虚假改善。
- **多语言、多场景覆盖**：包含 5 种印度文字与 2 种闪含语系语言，评价数据既有洁净数据也有噪声数据。
- **应用场景明确**：精准定位为文字不敏感下游任务的伴随指标，不替代原有标准，避免了指标过度推广的陷阱。

### 8. 不足与局限
- **应用边界**：**不能替代 WER/CER** 用于需保证输出文字形态的场景（如字幕、教育），对用户界面等文字敏感任务无效。
- **转写假设限制**：假定转写是保序、保词边界的，尽管碰撞率很低，但某些语言可能存在特例，未全面覆盖所有印度语言（仅 5 种）。
- **未直接与其他校正指标对比**：虽提及 toWER、lenient CER，但未进行同等条件下的直接对比实验，难以判断相对优劣。
- **泛化性待拓展**：
  - 仅聚焦单语多文字场景，**未涉及代码切换**（code-switching）。
  - 跨文字验证仅止于阿拉伯语、乌尔都语，对其他多文字语系（如西里尔-拉丁混合）适用性未知。
- **缺乏计算开销分析**：虽为评估指标，但未报告转写与编辑距离相比原始 WER 带来的时延增量。

## 摘要
近期最先进的文本到语音（TTS）系统通常采用由语音令牌器、自回归大语言模型（LLM）和基于扩散的流匹配（FM）模型组成的级联流水线，这些组件独立训练。本文提出了一种完全端到端（E2E）的优化框架，统一训练语音令牌器、LLM、FM模型以及额外的奖励模型（RM）。具体来说，我们首先使用多任务目标联合优化令牌器，这些目标源自FM的重构、LLM的下一个令牌预测以及RM的多识别任务。这种联合训练促使离散语音令牌空间捕获声学上和语义上显著的信息，更好地适应TTS。然后，我们利用FM和RM的下游重构与识别进一步优化LLM，从而减少推理时的失配，并引导LLM生成更优的结果。实验结果表明，我们的E2E框架一致优于级联基线。在Seed-TTS-Eval基准测试中，我们的系统达到了0.78%和1.56%的词错误率（WER），这是使用0.6B参数LLM和0.5B参数FM模型所取得的新领先结果。这些结果验证了整体端到端优化对于改进基于离散令牌的TTS系统至关重要，同时训练流程也更为简单。

## Abstract
Recent state-of-the-art (SOTA) text-to-speech (TTS) systems typically adopt a cascaded pipeline consisting of a speech tokenizer, an autoregressive large language model (LLM), and a diffusion based flow-matching (FM) model, with these components trained independently. In this paper, we propose a fully end-to-end (E2E) optimization framework that unifies the training of the speech tokenizer, LLM, FM model, and an additional reward model (RM). Specifically, we first jointly optimize the tokenizer using multi-task objectives derived from reconstruction for FM, next-token prediction for LLM, and multi recognition task for RM. This joint training encourages the discrete speech token space to capture acoustically and semantically salient information that is better tailored to TTS. We then further optimize the LLM using downstream reconstruction and recognition by FM and RM, which reduces inference-time mismatch and steers the LLM toward more preferred generations. Experimental results show that our E2E framework consistently outperforms cascaded baselines. On the Seed-TTS-Eval benchmark, our system achieves a word error rate (WER) of 0.78% and 1.56%, a new SOTA result with a 0.6B-parameter LLM and 0.5B-parameter FM model. These results validate that holistic E2E optimization is critical for improving discrete-token-based TTS systems with a much simpler training pipeline.

### 1. 论文的核心问题与整体含义
*   **研究动机**：当前性能最优的语音合成（TTS）系统普遍采用级联架构，依次包含语音令牌器（Tokenizer）、自回归大语言模型（LLM）和流匹配解码器（FM）。这些模块通常各自独立训练，导致两个关键问题：
    *   **令牌空间次优**：语音令牌器在训练时缺乏与下游LLM和FM的直接协同，其优化目标（如ASR准确率、自编码保真度）与最终合成任务存在偏差，容易使离散令牌包含冗余、纠缠或不可控的变异因素。
    *   **推理时模块失配**：FM训练时使用真实语音令牌，但推理时接收的是LLM预测的令牌。LLM的预测误差和分布偏移会直接传入FM，引起合成质量下降。此外，LLM以最大化令牌似然为目标进行训练，倾向于生成平庸、平均化的结果，不利于表现力丰富的语音合成。
*   **整体含义**：论文旨在提出一个完全端到端的训练框架，将令牌器、LLM、FM以及一个额外的多任务奖励模型（RM）进行统一优化，从根本上消除模块间的目标失配和推理失配，从而提升离散令牌TTS系统的整体性能和训练效率。

### 2. 论文提出的方法论
论文的核心思想是通过**一阶损失和二阶损失**对系统中的四个组件（令牌器、LLM、FM、RM）进行协同优化，并设计了一个三阶段训练流程以保证稳定性。

*   **核心架构**：系统由四个模块组成。
    *   **语音令牌器**：基于Conformer编码器和有限标量量化（FSQ），将语音转换为离散令牌和对应的量化向量。
    *   **多任务奖励模型（RM）**：与令牌器共享编码器，头部分别用于自动语音识别（ASR）、说话人识别（SPK）和语音情感识别（SER）。
    *   **大语言模型（LM）**：基于Qwen3-0.6B，以文本为条件自回归预测语音令牌序列。
    *   **流匹配模型（FM）**：基于DiT架构，根据量化向量序列重构语音。

*   **关键技术细节与公式（文字说明）**：
    *   **一阶损失（L1）**：以**真实语音令牌**为输入，联合优化令牌器、LM、FM和RM。损失函数是各模块损失的加权和：`L1 = α·LLM + β·LRM + γ·LFM`。其中，`LLM`为自回归预测的交叉熵损失，`LFM`为预测速度场的流匹配损失，`LRM`为ASR（CTC损失）、SER（交叉熵损失）和SPK（余弦相似度损失）的求和。通过反向传播`L1`，令牌器能学习到同时有利于预测、重构和识别的表示。
    *   **二阶损失（L2）**：以**LLM预测的语音令牌**为输入，计算FM的重构损失（`LLFM`）和RM的识别损失（`LLRM`）。通过Gumbel-Softmax技巧，梯度可跨越离散采样过程回传至LLM。这使得LLM不仅被训练去预测正确令牌，还被显式引导去生成更有利于高保真重构和准确识别的令牌，此为一种"强化式对齐"，直接优化了发音准确度、情感表现力和说话人相似度。
    *   **三阶段训练流程**：
        1.  **阶段1**：所有参数可训练，仅使用`L1`损失，使令牌器初步适应下游任务。
        2.  **阶段2**：冻结令牌器，独立训练LM、FM和RM，并可使用不同的优化策略和数据集（如为RM引入噪声数据）。
        3.  **阶段3**：冻结RM，使用`L2`损失联合训练LM和FM，使FM适应LLM输出，并引导LLM优化其生成。
    *   **理论解释（信息论视角）**：将令牌器训练建模为信源编码问题，提出一个好的令牌序列应具备高令牌熵`H(Xn)`（即码本被充分利用）和强时序依赖互信息`I(Xn+1 ; Xn)`（即历史令牌提供丰富上下文）。E2E训练通过`LFM`最大化`H(Xn)`，通过`LLM`最大化`I(Xn+1 ; Xn)`，从理论上解释了联合训练的优势。

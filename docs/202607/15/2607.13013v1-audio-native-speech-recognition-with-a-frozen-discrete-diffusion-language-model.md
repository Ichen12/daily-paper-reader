## 摘要
自动语音识别主要由自回归解码器主导，每次生成一个标记。我们探究是否可以用离散扩散语言模型转录语音，通过少量去噪步骤并行地优化整个转录文本。我们为DiffusionGemma训练了一个音频原生接口，DiffusionGemma是一个260亿参数的混合专家模型，通过均匀随机标记离散扩散而非近期扩散语言模型常用的吸收掩码方案来生成文本。冻结的Whisper编码器提供声学特征，一个轻量投影器将其映射到模型嵌入空间，低秩适配器让冻结的主干网络关注新的模态。大约训练了4200万个参数，占主干网络的0.16%。我们发现自然训练目标无法将音频与文本对齐，因为其梯度仅通过已忽略音频的注意力才到达投影器。通过冻结的输出头应用连接时序分类损失打破了这一僵局。最终模型在LibriSpeech测试集干净子集上达到6.6%的词错误率，无论话语长度如何，大致通过八个并行步骤完成转录，并且使用在六种语言上训练的单一适配器，本文在英语、印地语和普通话上进行了评估。

## Abstract
Automatic speech recognition is dominated by autoregressive decoders that emit one token at a time. We ask whether a discrete diffusion language model can transcribe speech instead, refining a whole transcript in parallel over a small number of denoising steps. We train an audio-native interface for DiffusionGemma, a 26B mixture-of-experts model that generates text by uniform, random-token discrete diffusion rather than the absorbing-mask scheme common to recent diffusion language models. A frozen Whisper encoder supplies acoustic features, a lightweight projector maps them into the model embedding space, and low-rank adapters let the frozen backbone attend to the new modality.   About 42M parameters are trained, which is 0.16 percent of the backbone. We find that the natural training objectives fail to ground the audio because their gradient reaches the projector only through attention that has already dismissed it. A connectionist temporal classification loss applied through the frozen output head breaks this deadlock. The resulting model reaches 6.6 percent word error rate on LibriSpeech test-clean, transcribes in roughly eight parallel steps regardless of utterance length, and uses a single adapter trained on six languages, which we evaluate here on English, Hindi, and Mandarin.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：传统的自动语音识别（ASR）依赖自回归解码器逐 token 输出，解码步骤数正比于转录长度，导致长音频推理延迟高。能否用**离散扩散语言模型**替代自回归解码，通过少量并行去噪步骤直接生成完整转录，从而将解码成本与转录长度解耦？
- **背景**：扩散语言模型（如 DiffusionGemma）已能生成高质量文本；已有工作（TransFusion、Whisfusion）将扩散用于语音，但均从头训练专用解码器且仅限英语。本文探究**是否可以直接复用现成的通用扩散语言模型**，仅通过轻量适配（冻结主干）赋予其听觉能力，实现多语言并行 ASR。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 核心思想
- 使用 **冻结的 Whisper 编码器**提取声学特征，**轻量可训练投影器**将其映射到 DiffusionGemma 的嵌入空间，**低秩适配器 (LoRA)** 让冻结主干学会关注音频模态。仅训练约 42M 参数（占主干 0.16%）。
- 发现标准训练目标（扩散损失 + 自回归辅助损失）无法使音频嵌入有效：梯度经交叉注意力传递，但注意力初始时视音频为噪声而屏蔽，导致梯度消失。引入 **CTC 损失**直接通过冻结输出头监督投影器，打破僵局。

### 关键技术细节
- **音频路径**：Whisper-small 编码器输出 1500 帧 × 768 维特征 → 3 层 Conv1d（步长 2）下采样至 188 个 token → 线性映射到模型宽度 2816。
- **条件注入**：将投影后的音频 token 填充到固定长度提示中的占位符位置，冻结编码器读取提示生成 KV 缓存，扩散解码器通过交叉注意力访问。
- **均匀随机 token 扩散**：腐败过程将每个位置以概率 γ 替换为均匀随机 token（无 mask 符号），模型预测原始 token。去噪时依据预测熵低于阈值保留置信位置，其余重新随机化。
- **训练目标**：
  - 扩散损失 \( \mathcal{L}_{\text{diff}} \)：仅作用于被腐败位置，包含权重 w(γ) 和强制 γ=1 的批次以强迫依赖音频。
  - 自回归辅助损失 \( \mathcal{L}_{\text{ar}} \)：通过因果编码器教师强制生成。
  - CTC 损失 \( \mathcal{L}_{\text{ctc}} \)：直接对投影器输出的每帧 logits 应用 CTC 对齐，梯度不通过注意力，强制嵌入包含语音信息。
  - 总损失 \( \mathcal{L} = \mathcal{L}_{\text{diff}} + \lambda_{\text{ar}} \mathcal{L}_{\text{ar}} + \lambda_{\text{ctc}} \mathcal{L}_{\text{ctc}} \)。
- **推理流程**（算法 1）：
  1. 用 Whisper 编码器和投影器生成音频缓存。
  2. 初始化 canvas 为随机 token。
  3. 迭代 S 步（S≈8）：计算去噪 logits，可选分类器无关引导，根据熵阈值保留置信 token，重新随机化其他位置，直到稳定或达到步数。
  4. 后处理去除重复词。

## 6. 主要结论与发现

- **CTC 损失是关键**：仅靠扩散和自回归损失无法接地，因为梯度需经注意力传播，而注意力初始时忽略音频。CTC 直接通过输出头提供梯度，唤醒投影器，进而使注意力权重变大。
- **扩散解码实现长度无关**：约 8 步即可收敛，步数增加收益甚微，解码成本由步数决定而非转录长度。
- **单适配器多语言**：在六种语言上训练的单一适配器表现出合理泛化（英语最佳，普通话仍较高 29.6% CER）。
- **瓶颈是数据而非架构**：使用更强编码器、更多 token 或更多步数均未带来显著提升，说明当前 219 小时数据量不足，而非方法有问题。

## 7. 优点：方法或实验设计上的亮点

- **极低训练开销**：仅训练 42M 参数（0.16% 骨干），单卡 H100 即可完成，实用性强。
- **创新性接地机制**：揭示并解决了音频条件冻结模型中的“注意力-投影器”死锁，提出 CTC 作为破解工具。
- **并行解码实用性验证**：首次在大型冻结扩散语言模型上实现多语言并行语音识别，且步数远小于转录长度。
- **实验设计细致**：在训练过程中手动解码观察接地动态，识别出损失下降但输出无意义的陷阱，并给出明确建议（人工监听是必须的）。
- **消融实验系统化**：逐步排除编码器、分辨率、步数等可能瓶颈，将焦点指向数据量。

## 8. 不足与局限

- **性能仍落后自回归 Whisper**：英语 LibriSpeech 6.6% vs Whisper large-v3 ~2.0%；多语言差距更大（FLEURS 英语 15.7% vs ~4-5%）。作者认为是数据规模不足（219h vs 数百万小时）。

## 摘要
音频-语言模型可用于提示代码切换语音，但其解码并未针对代码切换进行优化，且常在语言边界处失败。我们提出了一种实用的强化学习方法，结合可验证奖励机制，用于数据高效地将音频-语言模型适配到代码切换语音识别。该方法采用群体相对策略优化，结合错误率奖励和脚本保真度奖励（惩罚错误的书写系统），以及两遍草稿-优化流程。以Qwen2-Audio为可复现测试平台，覆盖10种语言对，仅使用TTS生成的代码切换语音进行训练，我们表明：使用10%数据的强化学习与可验证奖励方法，其性能即可匹配在全数据集上进行LoRA监督微调的结果，且在类型学距离较远的语言对上提升最大。错误率奖励消除了翻译错误，而脚本保真度奖励则在不降低性能的情况下单独减少了脚本污染。这些增益可零样本迁移到人工录制的代码切换语料库。

## Abstract
Audio-language models can be prompted for code-switched speech, but their decoding is not optimized for code-switching and often fails at language boundaries. We propose a practical reinforcement learning with verifiable rewards recipe for data-efficient adaptation of audio-language models to code-switched ASR using group relative policy optimization, combining an error rate reward with a script fidelity reward that penalizes wrong writing systems and a two-pass draft-and-refinement procedure. Using Qwen2-Audio as a reproducible testbed across 10 language pairs, training on only TTS code-switched speech, we show that RLVR with 10% of the data matches LoRA supervised fine-tuning trained on the full dataset, with the largest gains on typologically distant pairs. The error rate reward eliminates translation errors while the script fidelity reward separately reduces script contamination without degradation. These gains transfer zero-shot to a human-recorded code-switching corpus.

- **研究动机**：作者希望利用强化学习（RL）直接优化序列级质量，利用可验证奖励（如CER和脚本保真度）实现数据高效的适应，无需依赖大量人工标注。
- **整体含义**：本文提出一种结合群体相对策略优化（GRPO）的RLVR框架，在仅使用10%合成代码切换语音数据的情况下，达到甚至超越在全数据上使用LoRA监督微调的性能，且零样本泛化到真实人类录制语料。

## 2. 论文提出的方法论

### 核心思想
- 以Qwen2-Audio为基座模型，对其LLM解码器进行RL训练。使用GRPO进行策略优化，对每组采样的G个候选转录进行相对比较（组内z-score归一化作为优势），鼓励模型生成比组内平均得分更高的候选。
- 联合使用两种可验证奖励：
  - **CER奖励**：`-CER(ˆy, y*)`，直接惩罚字符错误率。
  - **脚本保真度奖励（SHR Reward）**：`βsf·Script(ˆy, C)`，其中`Script`为二进制指示函数，若输出中所有字符属于允许的Unicode脚本集合（两语言的并集）则取1，否则取0。βsf设为0.05。
- 引入**两遍草稿-精炼流程**（Two-Pass Draft-and-Refinement）：
  - 第一遍：基于原始音频和语言上下文采样G个草稿，计算奖励，执行GRPO更新，并选出最佳草稿。
  - 第二遍：将最佳草稿拼接至输入中（作为上下文），重新采样G个精炼结果，再次计算奖励并GRPO更新。
  - 推理时仅用单遍生成，不增加额外开销。

### 关键技术细节
- 策略网络πθ解码器全部参数可更新（非LoRA），音频编码器冻结。
- GRPO损失函数（公式1）包含裁剪重要性权重、优势项和KL正则化。
- 训练时使用DeepSpeed ZeRO-2，8 GPU并行，每步采样G=8个候选（温度τ=1.0），最大长度512。
- 学习率恒定10⁻⁶，单遍模型训练8 epochs，两遍模型训练4 epochs（每步两次更新），总梯度更新数对齐。

## 6. 论文的主要结论与发现

1. **数据效率极高**：仅用10%的TTS合成训练数据，RLVR就能匹配或超越LoRA在全数据上的CER（微平均0.155 vs 0.159），20%数据时RLVR性能更好（0.147 vs 0.159）。
2. **类型学距离大的语言对提升最大**：对阿拉伯语、日语、俄语等远距离对，RLVR显著优于LoRA；而在欧洲近缘语言对上LoRA略优。
3. **奖励解耦错误类型**：CER奖励几乎100%消除翻译错误，但脚本污染需额外SHR奖励才能有效降低（SHR下降约41%相对值）。
4. **两遍精炼局部有益但需谨慎**：在CS-FLEURS上精炼改善多数语言对，但阿拉伯语反而恶化；在SwitchLingua上整体无提升，需配合SHR奖励才能稳定。
5. **零样本迁移成功**：在SwitchLingua（人类录制）上，RLVR同样优于LoRA（微平均CER 0.219 vs 0.246），说明方法具有领域鲁棒性。
6. **RLVR减少灾难性错误**：虽然完美转录比例略低于LoRA，但高CER（>0.5）的样本比例更少（10.1% vs 11.8%）。

## 7. 优点

- **方法创新**：将RLVR（GRPO）引入代码切换ASR，结合两遍草稿-精炼和双奖励（CER+脚本保真度），设计精巧且有效。
- **数据高效**：大幅降低对人工标注代码切换数据的需求，仅需少量合成数据即可达到良好效果，对低资源场景有重要意义。
- **奖励可解释**：每个奖励对应不同错误模式，可独立分析和控制，有利于调试和扩展。
- **开源可复现**：使用公开模型Qwen2-Audio和公开数据集CS-FLEURS、SwitchLingua，训练细节完整，便于验证。
- **实验严谨**：多重种子、充分消融、跨领域验证、错误分析，结论稳健。
- **算力友好**：总训练时间小于LoRA SFT（204分钟 vs 315分钟），对研究资源要求不高。

## 8. 不足与局限

- **模型局限性**：仅在Qwen2-Audio一个模型上验证，缺少对Whisper-based、WavLM等更广泛架构的测试，通用性待确认。
- **训练数据局限**：训练使用TTS合成语音（CS-FLEURS XTTS），合成语音可能与真实声学特性有差距，尽管零样本迁移成功，但领域分布差异可能限制性能上限。
- **两遍流程的稳定性问题**：对阿拉伯语等语言对，精炼步骤反而退化，说明该流程对某些语言边界敏感，需要更鲁棒的设计（如条件精炼或动态中止）。
- **SHR奖励过于简单**：二进制奖惩可能鼓励输出避开特定非标准但合理的字符（如标点、数字、特殊符号），论文提到在拉丁语对中间接改善了“seventy km”→“70 km”的规范性，但缺乏对更复杂书写规范的考量。
- **语言对覆盖有限**：仅10个语言对，且训练时每个语言对下按比例均匀采样，未平衡样本数，可能忽略极低资源语言。
- **未与其它RL方法比较**：未与MECT（最小贝叶斯风险）、WER直接优化、批评家方法等对比，仅对比了LoRA SFT和prompt-only，证明RLVR优于监督微调，但未证明优于其他RL方法。
- **推理时未使用两遍生成**：训练时用了两遍，推理只用单遍，这可能限制了模型的修正能力。可以考虑在推理时也用精炼（但会增加延迟）。
- **计算成本仍较高**：每采样8个候选，GRPO计算量仍较大，虽然总训练时间不长，但相比LoRA SFT的每步时间更长（1.5分钟 vs 3.6秒）。

## 摘要
我们提出VibeVoice-ASR-BitNet，这是VibeVoice-ASR的压缩变体，针对边缘CPU上的实时推理进行了优化。我们根据每个阶段的计算特性应用了异构量化：VAE声学分词器采用全流水线INT8量化（I8_S），结合内核融合和SIMD优化，而自回归语言模型采用BitNet风格的三值权重（I2_S）。为了在激进压缩下保持准确性，我们采用了渐进式量化感知训练策略。在推理方面，我们在ggml框架内针对ARM和x86平台实现了自定义SIMD内核和融合算子，仅使用3个CPU线程即可实现RTF < 1的实时识别。在相似模型大小（~1.6 GB）下，VibeVoice-ASR-BitNet比Whisper.cpp快1.6-2.3倍，与FP16基线相比仅略有精度下降。

## Abstract
We present VibeVoice-ASR-BitNet, a compressed variant of VibeVoice-ASR optimized for real-time inference on edge CPUs. We apply heterogeneous quantization tailored to the computational characteristics of each stage: the VAE acoustic tokenizer uses full-pipeline INT8 quantization (I8_S) with kernel fusion and SIMD optimization, while the autoregressive language model adopts BitNet-style ternary weights (I2_S). To preserve accuracy under aggressive compression, we employ a progressive quantization-aware training strategy. For inference, we implement custom SIMD kernels and fused operators within the ggml framework targeting both ARM and x86 platforms, achieving real-time recognition with RTF < 1 using as few as 3 CPU threads. VibeVoice-ASR-BitNet is 1.6-2.3x faster than Whisper.cpp at comparable model sizes (~1.6 GB), with only modest accuracy degradation compared to the FP16 baseline.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- **异构量化**：针对模型不同组件的计算特性分别采用不同的量化方案：
  - VAE 分词器（含声学编码器和语义编码器）为激活密集型（Activation-dominant），采用**全流水线 INT8 量化（I8_S）**，包括权重、激活、中间缓冲和算子边界均保持 INT8。
  - 语言模型解码器为权重密集型（Weight-dominant），采用**BitNet 风格的三值权重量化（I2_S）**（-1,0,+1 存储为 2 bits），配合在线 INT8 激活量化。
- **渐进式量化感知训练（Progressive QAT）**：使用混合参数 α 控制全精度与量化之间的 blending，α 从 0 线性增加到 1，避免直接量化导致的训练不稳定（loss 震荡在 3.3 附近）。
- **推理优化**：在 ggml 框架内实现自定义 SIMD 内核（I8_S / I2_S GEMM 内核，基于 `_mm256_maddubs_epi16` 或 NEON 指令）以及算子融合（如 `im2col_asym`、`mul_mat_add_relu` 等），减少中间内存流量。

### 关键技术细节
- **VAE 分词器架构**：7 级 ConvNeXt，下采样率 3200×（24kHz → 7.5Hz）。由于激活数据量远超权重（表1显示早期阶段激活/权重比高达 5万倍），仅对权重量化无法加速，因此需全 INT8 流水线。
- **语言模型**：将原 VibeVoice-ASR 的 Qwen2.5-7B 替换为 **Qwen2.5-1.5B**（参数减少 4.7 倍），再应用 I2_S 量化。嵌入层和 LM head 使用 Q6_K（6-bit）而非三值，以避免精度损失。
- **训练流程**：先对 VAE 分词器进行 GELU → ReLU 替换并微调，然后以渐进式 QAT 训练（α 从 0→1 线性增长，达到 1 后继续全量化训练稳定）；再冻结 VAE 分词器，与语言模型联合训练（预训练+监督微调）。

## 6. 论文的主要结论与发现

1. **实时 CPU 推理可行**：VibeVoice-ASR-BitNet 在 3 个 CPU 线程上即可实现 RTF < 1（20s 音频 RTF=0.77），满足实时要求。
2. **异构量化有效性**：I8_S 对 VAE 分词器实现 1.3-2.0× 加速，I2_S 对 LM 解码器实现约 2.5× 预填加速和约 4× 解码加速。
3. **压缩与精度权衡**：从 FP16 4.62 GB 压缩至 1.58 GB（2.9×），精度仅下降 1-4% 绝对 WER（与 VibeVoice-ASR-1.5B 基线相比），在多数基准上优于或匹敌其他同级模型。
4. **相比 Whisper.cpp 的优势**：同模型大小下速度提升 1.6-2.3 倍，且支持更多语言。
5. **渐进式 QAT 的必要性**：直接 QAT 无法收敛，渐进式 blending 策略使 loss 稳定降至 0.91。

## 7. 优点：方法或实验设计上的亮点

- **异构量化策略**：根据计算特性（激活密集型 vs 权重密集型）分别设计量化方案，最大化压缩效率，是创新点。
- **渐进式量化感知训练**：引入 α-blending 避免直接量化的不稳定性，训练稳定且效果好。
- **算子融合与 SIMD 优化**：针对 VAE 的激活密集型特点，通过融合算子减少内存流量；三值权重内核与 INT8 内核共享流水线，降低实现复杂度。
- **全面的推理性能分析**：分别评估 VAE 和 LM 的加速比，揭示不同线程数下的内存带宽影响。
- **多语言支持**：原生支持 6 种以上语言，弥补了传统 ASR 模型（如 Parakeet、FunASR）多语言能力弱的不足。

## 摘要
自回归文本到语音模型虽能实现强自然度，但由于顺序令牌生成导致推理速度慢，限制了其在需要低延迟的生产应用中的部署。IndexTTS-2是一种最先进的自回归TTS模型，由GPT、流匹配扩散Transformer和声码器组成。尽管其合成质量高，但推理速度仅勉强达到实时，且不支持流式或批处理。我们提出Faster IndexTTS-2，通过使用NVIDIA TensorRT和TensorRT-LLM加速IndexTTS-2的所有神经网络组件，以在GPU上实现生产部署。Faster IndexTTS-2还支持对延迟敏感的交互式应用进行流式合成，并在所有组件上支持批量推理以最大化GPU利用率。在Seed-TTS基准测试（英语和中文）上的实验表明，自回归GPT加速高达5.0倍，端到端加速3.6倍，同时词错误率、说话人相似度和自然度几乎无下降。我们的方法为在GPU上高效加速类似自回归语音模型提供了实用参考。

## Abstract
Autoregressive text-to-speech models achieve strong naturalness but suffer from slow inference due to sequential token generation, limiting their deployment in production applications that require low latency. IndexTTS-2 is a state-of-the-art autoregressive TTS model consisting of a GPT, a flow-matching Diffusion Transformer, and a vocoder. Despite its high synthesis quality, its inference speed barely reaches real-time without streaming or batching support. We present Faster IndexTTS-2, which accelerates all neural network components of IndexTTS-2 for production deployment on GPUs using NVIDIA TensorRT and TensorRT-LLM. Faster IndexTTS-2 also enables streaming synthesis for latency-sensitive interactive applications, and batched inference across all components to maximize GPU utilization. Experiments on the Seed-TTS benchmark for both English and Chinese demonstrate up to 5.0$\times$ speedup on the autoregressive GPT and 3.6$\times$ end-to-end, with minimal degradation in word error rate, speaker similarity, and naturalness. Our methodology provides a practical reference for efficiently accelerating similar autoregressive speech models on GPUs.

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：将 IndexTTS-2 的**所有神经网络组件**（预处理、GPT、DiT、声码器）分别转换为 TensorRT 引擎或 TensorRT-LLM 引擎，并在此框架下实现流式合成与批量推理。
- **关键技术细节**：
  - **组件划分与加速方案**：
    - **预处理阶段**（包括 Wav2Vec2-BERT 语义编码器、VQ-VAE 语义码本、CAM++ 说话人风格编码器、时长调节器、Perceiver 条件器等）→ 通过 PyTorch→ONNX→TensorRT 管道转换为 TensorRT 引擎，支持动态 batch 和 sequence 形状。
    - **自回归 GPT**（512M 参数）→ 使用 TensorRT-LLM 加速，并针对 TTS 混合输入输出结构进行适配：
      - 利用 TensorRT-LLM 的 **prompt tuning** 机制将条件嵌入（32 个说话人感知器隐变量、1 个情感嵌入、1 个速度嵌入）存入 prompt 嵌入表，通过虚拟 input ID 追加到序列前。
      - **合并文本与语义码的嵌入表**：将两个单独的 embedding table 合并为一个，运行时将文本 token ID 偏移以避免冲突。
      - **自定义位置编码**：条件隐变量使用空白位置编码，文本 token 和语义 token 分别使用不同范围的合并位置嵌入表。
      - **输出 hidden states**：在 TensorRT-LLM 引擎图中注册额外输出张量，支持每步输出最后一层 GPT 的隐状态，用于下游 DiT 增强。
    - **流匹配 Diffusion Transformer（DiT，96M）** 和 **BigVGAN 声码器（113M）** → 同样转换为 TensorRT 引擎。
  - **流式合成**：
    - GPT 每生成一定数量（可配置 chunk size）的语义码 token 后，**立即**送入 DiT 和声码器解码，不等待完整序列。
    - 相邻 chunk 之间设置一定重叠（overlap size），重叠区域的波形使用 **Hann 窗交叉淡入淡出**平滑过渡。
    - 支持批量流式：GPT 每步生成一批 token，多个 utterance 的 chunk 同时转换为波形。
  - **批量推理**：对所有组件采用变长填充和掩码，实现多 utterance 并发合成，最大化 GPU 利用率。

- **算法流程（文字说明）**：
  1. 预处理：输入文本和参考音频，提取语义 token、说话人/情感嵌入、速度嵌入等条件。
  2. GPT（自回归）：接收条件嵌入序列和文本 token，自回归生成语义码 token，每步输出 hidden states。
  3. DiT（流匹配）：将生成的语义码 token 序列（可增量式）与条件（prompt Mel、说话人风格嵌入、GPT hidden states）一同输入，通过 Euler ODE 求解器迭代生成 Mel 谱（多步，含 CFG）。
  4. 声码器：BigVGAN 将 Mel 谱转换为最终波形。
  5. 流式模式下，步骤 2-4 以 chunk 方式循环执行，每生成一个 chunk 立即输出部分波形。

### 6. 论文的主要结论与发现

- **显著加速**：Faster IndexTTS-2 在 FP16 精度下，端到端加速比达 **3.6× (英语) / 3.46× (中文)**，GPT 组件加速 **5.0× (英语) / 4.8× (中文)**。RTF 降至 0.22~0.24，远优于基线的 0.76~0.84。
- **质量几乎无退化**：WER 仅上升 0.07~0.13 个百分点，SIM-o 降低 <0.01，UTMOS 下降 <0.1，实际听感差异极小。W8A16 量化保持质量接近 FP16，W4A16 略有退化但仍可接受。
- **流式合成可行**：chunk size 2 秒时流式质量与非流式相当，TTFA 降至约 600ms；更小 chunk（1 秒）可进一步降低 TTFA 至约 400ms，但会引入轻微质量损失（UTMOS 降 0.1~0.2）。
- **批量推理有效**：批处理可提高吞吐量至约 1.67 utterances/s（batch 8 以上增益渐饱和）；流式模式保持低 TTFA，但过大 batch（如 16）会因 DiT/Vocoder 逐 chunk 开销增加而降低效果。
- **实践建议**：FP16 和 W8A16 最适合生产部署，实现 4~5 倍实时合成且质量损失极小。

### 7. 优点：方法或实验设计上的亮点

- **系统全面性**：加速了所有神经网络组件，而非仅优化 GPT，避免了瓶颈转移。

- **流式设计实用**：chunk 重叠+交叉淡入淡出保证了波形连续性；支持批量流式，兼顾延迟和吞吐。

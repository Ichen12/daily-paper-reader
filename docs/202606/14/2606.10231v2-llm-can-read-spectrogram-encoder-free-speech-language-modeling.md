## 摘要
最近的语音感知大语言模型（Speech-LLMs）依赖一个预训练的语音编码器，将音频转换为LLM可消费的语义丰富表示。然而，在这项工作中，我们探索：LLM能否直接学习读取梅尔语谱图，而无需专用的语音编码器？我们提出Mel-LLM，一种无编码器的Speech-LLM，它通过线性投影将轻度预处理的梅尔语谱图块直接送入LLM，使LLM完全通过自身参数学习语音-文本对齐。我们在自动语音识别（ASR）和文本到语音（TTS）两个任务上进行了大量实验。对于ASR，我们在OpenASR排行榜公开集和生产级扩展实验上评估，表明无编码器方案仅与有编码器初始化的方案相比有有限的性能退化，达到了有竞争力的性能。我们发现当数据有限时，从多模态检查点（Phi-4-MM）初始化对保持性能至关重要。我们还进行了消融研究，揭示哪些LLM层与语音编码相关性较低。对于TTS，我们展示了使用下一token VAE方法的初步结果。虽然TTS性能尚未达到最优，但这些结果确立了全统一无编码器架构用于自回归语音-文本建模的可行性。

## Abstract
Recent speech-aware large language models (Speech-LLMs) rely on a pre-trained speech encoder to convert audio into semantic-rich representations consumable by LLM. In this work, instead, we explore: can an LLM learn to read Mel spectrogram directly without a dedicated speech encoder? We propose Mel-LLM, an encoder-free Speech-LLM that feeds lightly pre-processed Mel spectrogram patches directly into the LLM through a linear projection, allowing the LLM to learn speech-text alignment purely through its own parameters. We conduct extensive experiments on both automatic speech recognition (ASR) and text-to-speech (TTS) tasks. For ASR, we evaluate on the OpenASR leaderboard public sets and production-level scaling experiments, demonstrating that the encoder-free solution achieves competitive performance with only limited degradation compared to encoder-initialized counterparts. We find that when data is limited, initialization from a multimodal checkpoint (Phi-4-MM) is crucial for maintaining performance. We also present ablation studies revealing which LLM layers are less relevant to speech encoding. For TTS, we show preliminary results with a next-token VAE approach. While TTS performance is not yet optimal, these results establish the feasibility of a fully unified encoder-free architecture for autoregressive speech-text modeling.

## 1. 论文的核心问题与整体含义

**研究动机**：传统 Speech-LLM 依赖预训练语音编码器（如 Whisper、Conformer）将音频转换为语义表示再送入 LLM。该范式存在三个主要局限：
- 编码器参数量大（如 Whisper-large 超 600M），增加计算开销；
- 编码器学到的表示可能与 LLM 内部处理不匹配，形成表示鸿沟；
- 编码器成为信息瓶颈，LLM 只能访问压缩后的特征。

**核心问题**：能否完全移除专用语音编码器，让 LLM 直接从原始梅尔频谱图中学习语音-文本对齐？

**整体含义**：探索一种更简洁、统一的架构，使 LLM 自身承担语音编码与语言建模的双重角色，为未来联合语音理解与生成奠定基础。

## 2. 方法论

### 核心思想
提出 **Mel-LLM**：将经过轻量预处理（MVN 归一化、可选卷积降采样）的 80 维 log-Mel 频谱图块，通过线性投影直接映射到 LLM 的嵌入空间，LLM 通过自身 Transformer 层学习隐式语音编码。

### 关键技术细节

**ASR 输入路径**：
- 输入：80 维 log-Mel 频谱 → MVN 归一化 → 可选卷积层（时间降采样率 r，ASR 使用 r=8，即 12.5 Hz token 率）→ 线性投影（`W_proj * e + b_proj`，随机初始化）→ 与文本 prompt 拼接 → LLM（Phi-4-MM，32 层，LoRA 微调，rank=320，α=640）→ 自回归生成文本 token。

**TTS 输出路径**：
- 文本输入 → LLM 生成隐藏状态 → **Mel Head（VAE 解码器）**：
  - 线性层输出均值 μ 和对数方差 logσ²；
  - 重参数化得到 z = μ + σ·ε；
  - 残差 MLP（3 层 tanh + dropout）得到 ˆm；
  - 5 层 Conv1D Postnet 残差精炼得到最终 mel 帧。
- 同时预测停顿时长（stop 损失）。
- 训练损失：`L_TTS = L_reg + λ_KL L_KL + λ_stop L_stop + λ_flux L_flux`（L_reg 为 L1+MSE，L_flux 为平滑性损失，参照 MELLE）。

**训练方式**：LLM 基座冻结，仅训练 LoRA 参数及投影层、Mel Head。

## 6. 主要结论与发现

1. **ASR 无编码器可行**：Mel-LLM 在 OpenASR 上平均 WER 7.12%，仅比带随机编码器的基线（6.97%）差 0.15%，验证 LLM 能自主学得语音编码。
2. **多模态初始化关键（低资源）**：Phi-4-MM LoRA 初始化比随机初始化好 0.32%，说明预训练语义知识帮助解释频谱。
3. **数据缩放消除差距**：10 倍数据后，无编码器模型 WER 差距从 +11.3% 缩小至 +3.8%，表明数据充足时编码器可被替代。
4. **LLM 底层隐含编码器角色**：冻结 L24-31 仅造成 0.28% 退化，而冻结 L16-31 退化更大，证明底层（0-23）学习声学处理，高层（24+）保留原有语言能力。
5. **TTS 初步可行但需优化**：无编码器 TTS 生成可闻语音（无初始化则无声），最佳 WER 11.03%/UTMOS 3.10，离 SOTA 有差距。
6. **计算效率提升**：12.5Hz 设置下训练速度较有编码器基线提升 1.57 倍。

## 7. 优点

- **架构创新**：首次在 Speech-LLM 领域系统比较并验证“无编码器”范式，为未来简化多模态模型提供方向。
- **消融深入**：通过层冻结实验揭示了 LLM 各层在语音任务中的角色，具有可解释性价值。
- **缩放实验**：明确展示了数据规模与无编码器性能的关系，说明可扩展性。
- **计算效率**：移除编码器带来实质加速，且低 token 率下性能不减。
- **统一架构**：同一 LLM 骨干同时支持 ASR 和 TTS，便于未来联合训练。

## 8. 不足与局限

- **TTS 性能未成熟**：WER 高达 11%+，UCMOS 仅 3.25，远不及当前 SOTA 系统（如 MELLE）。部分变体甚至产生不可听输出（dropout 降低后 WER 85%）。
- **语言覆盖有限**：所有实验仅基于英语，未验证跨语言泛化能力。
- **数据依赖严重**：低资源场景下需强初始化（Phi-4-MM）或大量数据才能赶上编码器方案，实际部署门槛高。
- **未联合训练**：ASR 和 TTS 分别独立训练，未探索共享表示下的双向建模潜力（论文已列为未来工作）。
- **未见训练时长报告**：无法评估实际计算成本与收敛速度的具体度量。
- **协议风险**：公共数据组合可能存在分布差异，测试集未做领域外泛化分析。

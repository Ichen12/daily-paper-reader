## 摘要
语音合成（TTS）的最新进展极大地提升了语音的自然度、说话人相似度和可控性。然而，现有大多数可控TTS系统仍然依赖用户显式提供的风格提示，难以在长篇幅、复杂的对话场景中自动判断句子应如何朗读。本方案介绍了ISCSLP 2026 CoT-TTS挑战赛，旨在评估系统能否从上下文信息中推断出预期的说话方式，并生成与推理输出及周围场景一致的语音。挑战包含两个赛道：文本上下文感知CoT-TTS和音频上下文感知CoT-TTS。我们从富含语音的媒体中构建大规模双语训练集，并提供经过精心筛选的评估数据用于排行榜比较。每个系统需要输出思维链推理分析和生成的语音波形。官方评估结合了客观指标、基于多模态大语言模型的评估以及人工主观评估。为了促进可重复性，我们提供了推理代码以及基于0.6B Qwen3模型的三阶段训练微调方案。该挑战赛有望支持上下文理解、思维链推理以及表达性语音生成的研究，应用于电影配音、有声书制作、虚拟角色和语音对话代理等场景。更多相关挑战信息请访问：https://iscslp2026-cot-tts.github.io/challenge-website/

## Abstract
Recent advances in text-to-speech (TTS) have greatly improved speech naturalness, speaker similarity, and controllability. However, most existing controllable TTS systems still rely on explicit user-provided style prompts, making it difficult to automatically determine how a sentence should be spoken in long and complex conversational scenarios. This proposal introduces the ISCSLP 2026 CoT-TTS Challenge, which aims to evaluate whether a system can infer the intended speaking manner from contextual information and generate speech consistent with both the reasoning output and the surrounding scene. The challenge contains two tracks: text-context-aware CoT-TTS and audio-context-aware CoT-TTS. We construct a large-scale bilingual training set from speech-rich media and provide carefully filtered evaluation data for leaderboard comparison. Each system is required to output both a chain-of-thought reasoning analysis and the generated speech waveform. The official evaluation combines objective metrics, multimodal LLM-based evaluation, and human subjective assessment. To facilitate reproducibility, we provide inference code together with a fine-tuning recipe for a 0.6B Qwen3-based model trained via a three-stage strategy. This challenge is expected to support research on context understanding, chain-of-thought reasoning, and expressive speech generation for applications such as film dubbing, audiobook production, virtual characters, and spoken dialogue agents. Further information about the associated challenge is available at:https://iscslp2026-cot-tts.github.io/challenge-website/

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：现有可控文本转语音（TTS）系统虽在自然度、说话人相似度和可控性上取得显著进步，但普遍依赖用户**显式提供风格提示**（如情感标签、风格描述），无法在复杂对话场景（如电影、广播剧、多轮对话）中**自动推断**句子应如何朗读，缺乏对上下文的理解与推理能力。
- **整体含义**：为了弥补这一空白，ISCSLP 2026 发起 CoT-TTS 挑战赛，要求系统根据上下文（文本或音频）**显式输出思维链（Chain-of-Thought, CoT）推理分析**，并结合推理结果生成风格一致、上下文匹配的语音。此举旨在推动**上下文感知、可解释、可控制**的语音合成研究，其应用覆盖电影配音、有声书、虚拟角色、口语对话系统等。

## 2. 方法论：核心思想、关键技术细节与流程

- **核心思想**：将“推理”显式纳入 TTS 任务，模型接收**上下文信息**（历史对话）、**目标文本**以及**参考语音**（提供目标说话人音色），输出两部分：
  1. **推理分析**：描述说话意图、情绪、场景等；
  2. **生成语音波形**：风格与推理一致、音色与参考语音一致。
- **双赛道设计**：
  - **Track 1 (Text-Context-Aware)**：上下文为**文本形式**的多轮对话转写（如 `speaker-id: spoken text`）。
  - **Track 2 (Audio-Context-Aware)**：上下文为**连续音频片段**（不提供转写）。
- **训练数据构建流程**（图1）：
  1. 从电影、电视剧、广播剧、短剧等媒体中收集原始音频。
  2. 音频归一化→使用 pyannote 进行说话人日记化（获得说话人标签、时间戳、内容）→根据时间戳划分候选场景→用 LLM（DeepSeek-R1）细化场景边界。
  3. 为每个句子添加**情感标签**（利用 FunASR 初标 + LLM 精修）和**多维推理分析**（基于前 3-5 句语境，覆盖语言行为、场景语义、认知/角色动机、预期结果、情绪轨迹）。
  4. 根据时长、有效语音比、响度、情感表达强度（`Iemo = 0.7 * A + 0.3 * D`，A=唤醒度，D=支配度）进行样本过滤，并用说话人嵌入（WeSpeaker）验证一致性。
- **基线模型**：基于 0.6B Qwen3，采用 UniSS 的**三阶段训练策略**：
  1. **模态对齐**：利用 ASR 与 TTS 任务对齐文本与音频（BiCodec 编码/解码）。
  2. **CoT-TTS 主任务训练**：输入上下文（文本或音频）、参考语音全局 token 和目标文本，输出推理分析 + 目标音频 token；同时混合辅助任务（说话人感知转写、指令型 TTS 等）。
  3. **高质量子集精调**：进一步提升推理稳定性与风格控制。

## 3. 实验设计：数据集、场景与评估方法

- **数据集**：
  - **训练集**：约 **3M 样本**，对应 **~16K 小时**语音，中英比例 54:46（英语 ~8.6K h，中文 ~7.4K h）。来源：电影、电视剧、短剧、广播剧。音频以 FLAC 格式发布，保留原始声学多样性（不同采样率、噪声等）。
  - **评估集**：从另一个约 3M 样本池中经过**多级严格过滤**得到 **1200 样本**（中英各 600）。过滤包括：基础音频质量、MOS 估计、相似去重、LLM 评分（情节丰富度/语境充分性/推理正确性）、多模态模型（Qwen3）检查音频与推理一致性、人工打分（四项标准：转写准确、场景丰富、推理准确、音频-推理一致）。
- **基准（Benchmark）**：论文本身是挑战赛提案，尚未有对比方法。计划提供官方评估（客观指标+LLM评估+主观评测），并设有**两个赛道**和**两种规模类别**（参数 <1B 的受限类别 / 无限制类别）以促进公平对比。
- **评估方法**（公式 2）：最终得分 = 0.3 × 客观得分 + 0.2 × LLM 得分 + 0.5 × 主观得分。
  - 客观指标：UTMOSv2（自然度）、DNSMOS P.835（质量）、CER/WER（可懂度）、说话人嵌入余弦相似度、F0 相关性、情感表达性、时长误差、RTF。
  - LLM 评估：评估上下文理解、推理内部一致性、语音与推理一致性，并引入“推理信息量”乘数惩罚通用性推理。

## 7. 优点

- **任务设计新颖**：首次将**显式思维链推理**与 **TTS 输出**捆绑作为统一评估标准，推动可解释、可验证的上下文感知语音生成。
- **数据集规模大、声学真实**：16K 小时双语数据来自真实影视媒体，保留噪声、背景声等多样性，贴近真实应用。
- **评估体系全面**：客观（自然度、相似度、可懂度等）、LLM（推理质量）、主观（用户感知）三位一体，尤其引入“推理信息量”乘数防止敷衍回答。
- **可重复性重视**：提供基线代码、Docker 化环境、三阶段训练配方及公开平台（GitHub/Hugging Face）。
- **公平性保障**：双赛道+参数约束分类，禁止级联，统一评估环境且关闭网络。
- **应用导向明确**：直接对应电影配音、虚拟角色、有声书、对话系统等需求。

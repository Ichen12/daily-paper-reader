## 摘要
我们提出ZONOS2 8B，这是我们最新的TTS模型，在自然度、韵律和语音克隆保真度方面达到了最先进水平。我们在规模、数据和训练方案上对Zonos-v0.1进行了改进。我们将模型参数从1.6B扩展到8B（实际激活900M），采用了新颖的混合专家模型（MoE）架构，提升了推理延迟和吞吐量。我们使用新的数据处理流水线，将训练语料从20万小时扩展到超过600万小时，并简化了后处理和条件化方案，以提高自然度和语音克隆保真度。我们在质量、说话人相似度、WER以及我们的新型TTS基准ZTTS1-Eval上对ZONOS2 8B进行了评估，其在保持良好流式延迟的同时，与最先进系统相比具有竞争力。我们在GitHub和Hugging Face上以Apache 2.0许可证发布模型权重和示例推理代码。

## Abstract
We present ZONOS2 8B, our latest TTS model, which achieves state-of-the-art naturalness, prosody, and voice cloning fidelity. We improve upon Zonos-v0.1 across scale, data, and training recipe. We scale the model from 1.6B to 8B total parameters (900M active) with a novel mixture-of-experts (MoE) backbone, improving inference latency and throughput. We expand our training corpus from 200K to over 6M hours using a new data processing pipeline, and we simplify our post-training and conditioning recipes to improve naturalness and voice cloning fidelity. We evaluate ZONOS2 8B on quality, speaker similarity, WER, and ZTTS1-Eval, our novel TTS benchmark, where it performs competitively with state-of-the-art systems while maintaining good streaming latency. We release our model weights and example inference code under an Apache 2.0 license on GitHub and Hugging Face.

## 1. 核心问题与整体含义

- **研究动机**：当前的 TTS 系统往往在自然度、可控性、多语种支持或推理效率方面难以兼顾，尤其是在**语音克隆保真度**和**自然韵律**上仍有显著提升空间。多数系统要么输出质量高但控制能力弱（如缺乏说话人克隆），要么推理快但仅支持有限语种。
- **整体含义**：ZONOS2 8B 旨在构建一个**在所有关键维度（稳定性、自然度、可控性、多语种、推理性能）均表现优秀**的 TTS 系统，重点突破自然度与语音克隆保真度，并通过开源促进社区研究与应用。

## 2. 提出的方法论

### 核心思想
- 采用 **Mixture-of-Experts (MoE) 骨干网络**，在保持推理效率的前提下大幅提升模型容量（8B 总参 / 900M 活跃参数）。
- 以 **自回归语言模型** 方式生成音频离散标记（基于 Residual Vector Quantization 的 DAC 音频编解码器）。
- 引入多种条件化机制（说话人嵌入、语速、质量模式）实现零样本语音克隆与细粒度控制。

### 关键技术细节

| 模块 | 技术细节 |
|------|----------|
| **音频标记化** | Descript Audio Codec (DAC)，9 个码本的 RVQ，采用 **延迟模式**（delay pattern）使不同码本按时间偏移生成，实现解码时逐步对齐。 |
| **文本标记化** | 字节级 UTF-8 编码（256 个 token），无需音素转换（G2P），避免低资源语言或代码切换场景下的错误。 |
| **说话人嵌入** | ECAPA-TDNN 提取 2048 维嵌入 → **LDA 降维至 1024 维**（增大说话人间方差 / 减小说话人内变异）→ 线性投影到模型隐藏维度。LDA 减少目标 utterance 中词法、噪声等无用信息泄露，防止过拟合。 |
| **语速条件化** | 按 UTF-8 字节数 / 时长计算速率，量化成离散桶并 prepend 到文本序列。 |
| **质量条件化** | 训练中对克隆音频进行噪声、混响等增强（概率 αAUG），并用额外 token 表示带宽、SNR 等；最后阶段加入“Quality Mode” token。 |
| **MoE 架构** | 28 层 Transformer，前 3 层 + 最后 1 层为 dense，其余为 MoE（16 experts，top-1 路由，仅最后 MoE 层用 top-2）。路由器设计参考 ZAYA1-8B，含 EDA 和三层 MLP。注意力采用 GQA（4 组） + Qwen headwise gating。 |
| **训练目标** | 自回归负对数似然（对非 padding 音频标记），加上路由器平衡损失（Lbal）。softmax 前使用 logit soft-capping（τ=15）。 |

### 训练流程（四阶段）
1. **预训练**（77,500 步，约 2.9T tokens）：无条件化，最大序列 6144 帧，Muon 优化器。
2. **中训练**（15,000 步，约 560B tokens）：提高 ASR 间转录一致性。
3. **第一退火**（10,000 步）：引入说话人嵌入（仅随机裁剪段）、语速/质量条件化，并使用增强音频计算嵌入以防止泄露。
4. **第二退火**（10,000 步）：说话人嵌入覆盖整段音频，移除损失掩码，添加 Quality Mode token。

## 3. 实验设计

### 数据集
- **训练数据**：超过 **620 万小时**，包含公共语音语料、播客、有声书、多语种网页语音及表现力数据集。英语占多数，但覆盖多语种。通过两步流水线处理：VAD 分割 + 多 ASR 系统共同转录，按 pairwise WER 过滤低质量样本。
- **评估基准**：
  - **ZTTS1-Eval**（新提出，开源）：  
    - “Clean” 集：9 种语言（en, zh, de, es, fr, it, ja, ko, ru），各 500 条朗读语音（FLEURS-R），共 13 小时。  
    - “In-the-wild (ITW)” 集：17 种语言，1,618 条自然对话语音（VoxBlink2），约 3 小时。  
    - 指标：WER（Qwen3-ASR）、MSR-UTMOS 质量、ReDimNet 说话人相似度、TTSDS2 韵律、DS-WED 多样性。  
  - 额外在 **CosyVoice 3 Eval** 和 **Seed-TTS-Eval** 上评估。

### 对比方法
- **开源**：Qwen 3 TTS 1.7B、Fish S2 Pro、VoxCPM 2。
- **闭源**：Cartesia Sonic 3.5、Eleven Labs V3、Gemini 3.1 Flash、Inworld TTS 2。

## 6. 主要结论与发现

- ZONOS2 在 **ITW 集的韵律（TTSDS2）和多样性（DS-WED）上表现最佳**，优于所有对比模型。
- 在 **Clean 集的说话人相似度**（如英语）达到开源最好、整体第二（仅次于 Cartesia Sonic 3.5）。
- **Quality Mode 显著提升 WER 和 UTMOS**，但说话人相似度略有下降，用户可根据需求选择。
- **MoE 架构在 TTS 领域的首次开源应用**成功实现：8B 总参下仍保持可流式推理的延迟。
- 字节级文本编码避免了音素错误，尤其在低资源语言和代码切换场景下鲁棒。
- 提出的 **ZTTS1-Eval 基准**比 Seed-TTS-Eval 和 CV3-Eval 覆盖更广的语言和语音类型，并首次引入韵律和多样性指标。

## 7. 优点

- **方法创新点突出**：MoE 用于 TTS（首个开源）、说话人嵌入的 LDA 降维+两阶段退火防止过拟合、延迟模式与 DAC 结合、字节级输入无需 G2P。
- **实验设计全面**：同时覆盖朗读和自然语音、多语言、多种基线（开源&闭源），并自建更完善的基准 ZTTS1-Eval。
- **结果竞争力强**：在韵律、多样性和说话人相似度上表现突出，尤其是自然语音场景。
- **实用性高**：支持零样本语音克隆、语速控制、质量模式，模型权重和基准均以 Apache 2.0 开源。
- **训练数据处理细节详实**：多 ASR 合议过滤、数据增强、语言权重调整等，具有工程借鉴价值。

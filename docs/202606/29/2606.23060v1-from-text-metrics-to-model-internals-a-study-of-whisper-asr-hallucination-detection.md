## 摘要
ASR模型的幻觉——流畅但无音频依据的转录——会降低系统性能并在下游应用中带来风险。对此类错误的稳健检测仍然是一个挑战。本文在真实语音人工标注数据上，研究Whisper large v3的幻觉检测，涉及三种范式：基于文本、基于LLM和内部解码器状态探测。利用文本评估指标的文本分类器实现了高召回率，但在没有参考转录时性能下降。基于LLM的检测通过领域特定的提示条件提高了精确率，但仍不如轻量级的基于文本的方法。无需真实参考的Whisper解码器表示探测取得了最强性能，揭示了幻觉特征在中间解码层中被编码。一个结合文本和内部状态输出的晚期融合元分类器实现了最佳整体检测性能。

## Abstract
Hallucinations of ASR models - fluent transcriptions with no basis in audio - degrade system performance and pose risks in downstream applications. Robust detection of such errors remains a challenge. This paper studies Whisper large v3 hallucination detection on real-speech human-annotated data across three paradigms: text-based, LLM-based, and internal decoder state probing. Text classifiers utilizing metrics for text evaluation achieve high recall but degrade without reference transcripts. LLM-based detection improves precision with domain-specific prompt conditioning, yet remains less competitive than the lightweight text-based methods. Probing Whisper's decoder representations, without a ground-truth reference, yields the strongest performance, revealing that hallucination traits are encoded across intermediate decoding layers. A late-fusion meta-classifier combining text and internal-state outputs achieves the best overall detection performance.

# 从文本指标到模型内部：Whisper ASR幻觉检测研究 — 详细总结

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：自动语音识别（ASR）系统中，模型可能产生“幻觉”——即流畅自然但与音频内容完全无关的转录。这类错误不仅降低 Word Error Rate（WER）等常规指标，还可能引入冒犯性、刻板或错误内容，并在下游自然语言处理（NLP）应用中引发级联故障。
- **研究背景**：现有的 ASR 评估指标（如 WER、BERTScore、SeMaScore）大多需要真实转录（oracle setting），且难以区分幻觉与其他类型的识别错误。目前缺乏在真实语音、人工标注数据上对不同检测范式的系统性比较。同时，参考自由的检测方法（如基于文本的生成速度、重复率、困惑度）性能有限。大型语言模型（LLM）被用于零样本 ASR 错误修正，但在幻觉检测上仍需真实转录。最近，利用解码器内部表示区分低/高 WER 预测的工作显示出潜力，但尚未专门应用于幻觉检测。
- **整体含义**：本文旨在系统地比较三种范式（基于文本、基于 LLM、基于解码器内部状态）在 Whisper large v3 上的幻觉检测能力，并提出跨范式融合的方法，以解决实际部署中无参考转录时的检测难题。

## 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

### 2.1 基于文本的检测
- **核心思想**：利用文本层面的特征训练轻量级分类器，包括需要参考转录的 oracle 特征和完全参考自由的特征。
- **关键特征**：
  - **Oracle 特征**：WER、CER、Insertion Error Rate（IER）、预测与参考的长度比（LenR）、BERTScore、SeMaScore，以及自定义的 Common Hallucinated Phrase（CHP）检测器（若预测中出现已知的常见幻觉短语但参考中无，则标记）。
  - **参考自由特征**：5-gram 重复率（Rep）、停用词比例（StopW）、GPT-2 困惑度（PPL）、每秒字符数（CPS）、wav2vec 强制对齐置信度（Align），以及朴素 CHP 检测器（NCHP，仅检查预测中是否出现常见错误短语）。
- **分类器**：训练 Logistic Regression、Random Forest、XGBoost。通过递归特征消除（RFE）优化。
- **算法流程**：提取特征 → RFE 选择 → 训练分类器 → 预测幻觉概率。

### 2.2 基于 LLM 的检测
- **核心思想**：利用大语言模型（GPT-4o mini、Gemini 2.0 Flash、Gemini 3.0 Flash）进行零样本幻觉检测，并通过逐步增强提示改进性能。
- **提示增强步骤**：
  1. **基线**：使用文献[16]提供的提示，解释幻觉与非幻觉错误的区别，提供 5 个示例，要求返回二元标签。
  2. **升级模型**：从 Gemini 2.0 Flash 升级到 Gemini 3.0 Flash（更强推理能力）。
  3. **注入领域病理知识**：加入 Whisper large v3 在非语音音频上的已知幻觉列表[3]作为错误特征。
  4. **增加 few-shot 示例**：从训练集中选取 10 个目标示例。
  5. **参考自由设置**：移除真实转录，将检测标准转向内在文本异常和错误模式识别。
- **算法流程**：构建增强提示 → 调用 LLM → 解析输出标签。

### 2.3 基于解码器内部状态的探测
- **核心思想**：Whisper 解码器在解码过程中产生每步的隐藏状态，这些状态编码了幻觉信号。通过线性探测或序列模型提取这些信号。
- **关键技术细节**：
  - **线性探测**：对每个解码器层，提取 EOS 令牌嵌入，或对整个解码序列进行均值/最大值池化（包括序列值和每步差分）。使用 Logistic Regression 评估线性可分性（ROC AUC）。
  - **序列建模**：使用双向长短期记忆网络（BLSTM）处理完整解码序列的嵌入。嵌入来源包括 Self-Attention（SA）、Cross-Attention（CA）和最终 MLP 输出（D）。可选附加序列差分（deltas）。
  - **融合**：最优配置为选取两个层的输出（如层 21 和 24 的 D 输出），通过 Grid Search 确定。
- **算法流程**：提取解码器每层嵌入序列 → 池化/序列建模 → 分类。

### 2.4 跨范式融合
- **核心思想**：文本分类器（XGBoost）和内部状态探测器（BLSTM）具有互补的失败模式，因此构建元分类器融合两者。
- **方法**：使用 5 折交叉验证生成训练集上的 out-of-fold（OOF）预测，将两个概率值加上音频时长作为特征，训练 Logistic Regression 元分类器（避免数据泄露）。

## 6. 论文的主要结论与发现

1. **单文本特征**：Oracle 特征中 BERTScore（82.3% AUC）和 CER（81.9%）最强；参考自由特征中 CPS（68.2%）和困惑度（66.0%）最高，但整体较弱。
2. **文本分类器**：XGBoost 在 oracle 模式下 F1 62.8%（Recall 74.1%），优于 Logistic Regression；但参考自由模式下 F1 骤降至 37.7%，召回率严重下降。
3. **LLM 检测**：零样本 LLM 表现一般（baseline F1≈41%）。通过注入领域病理知识和 few-shot 示例，F1 提升至 58.7%，但仍不及 XGBoost。参考自由下 F1 跌至 32.8%。
4. **内部状态探测**：线性探测显示中间层（14~16 层）达到最高 AUC（均值池化 81~82%），且序列均值池化与 EOS 性能相近，最大池化较差。BLSTM 在 D 输出（层 21,24）达到 F1 65.5%、AUC 87.6%，**成为最强的参考自由检测器**，优于所有文本方法和 LLM。
5. **跨范式分析**：三种检测器正确检测的重叠率仅 39%，12% 的幻觉均被漏检（多为单词功能词插入）。文本检测器召回高但精度低，LLM 精度高但召回低，内部状态最均衡。
6. **融合**：Logistic Regression 元分类器融合文本和内部状态概率，达到 F1 68.3%、AUC 90.0%，为整体最佳。音频时长仅在边界案例起次要作用。

## 7. 优点

- **系统性比较**：首次在同一真实语音数据集上严格对比三种完全不同的检测范式，填补了领域空白。
- **创新方法**：
  - 提出基于解码器中间层完整序列建模的检测方法（BLSTM），显著优于仅用 EOS 或 Whisper 自带启发式。
  - 揭示幻觉特征在解码器中呈系统性分布，而非局部尖峰。
  - 构建轻量级融合元分类器，利用跨范式互补性。
- **实验设计严谨**：使用人工标注数据、分层交叉验证消除说话人泄漏、报告标准差、进行特征消融和超参数搜索。
- **实际价值**：内部状态探测不依赖参考转录，可在零样本部署中实时检测幻觉，且计算开销低于 LLM。

## 8. 不足与局限

### 实验覆盖
- **仅一个 ASR 模型**（Whisper large v3），结论对其他架构（如 encoder-only、CTC 模型）的迁移性未知。
- **仅一个数据集**（HALAS 基于 Earnings-22），语音类型相对单一（财报电话会）。未在嘈杂、非语音、多语种场景下验证。
- **未包含音频级特征**：如声学特征（频谱、置信度）未与内部状态结合。

### 偏差风险
- **幻觉定义偏差**：依赖人工标注，但幻觉与严重识别错误的边界可能存在主观性。文中提到 18 个含循环的幻觉占比极低，可能影响对循环模式的检测评估。
- **LLM 选取偏差**：仅测试了几种商业模型（GPT-4o mini、Gemini Flash），未对比开源模型或微调模型，可能低估 LLM 潜力。

### 应用限制
- **内部状态探测需要模型访问**：无法用于黑盒 ASR 系统（如云端 API）。
- **融合方法丧失参考自由**：虽然性能最佳，但需要文本特征（依赖参考或强假设），不适合完全零样本。
- **计算资源**：BLSTM 轻量但需提取每层嵌入，对长音频序列可能增加推理延迟。论文未分析实时性。

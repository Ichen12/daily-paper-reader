## 摘要
我们提出了Wan-Streamer，一种原生流式、端到端的交互基础模型，从头设计用于实时、低延迟、全双工的视听交互。Wan-Streamer在单个Transformer内无缝地将语言、音频和视频作为输入和输出建模，其中序列表示为交错的可视、音频和文本输入令牌以及可视、音频和文本输出令牌，通过块因果注意力协调实现增量流式处理。与依赖独立VAD、ASR、语言、TTS、音频驱动动画或视频生成模块的级联交互系统不同，Wan-Streamer不依赖外部语言、语音、虚拟形象或视频生成模块：感知、推理、生成、响应时序、话轮管理和跨模态同步都在一个统一模型中联合学习，减少了流水线延迟和错误累积。为了支持自然的视听响应，我们围绕可流式化重新设计了整个堆栈，包括因果编码器、因果解码器、块因果注意力和低延迟多模态令牌调度，使得在25fps下流式单元可短至160毫秒。Wan-Streamer实现了约200毫秒的模型端响应延迟，并结合350毫秒的双向网络延迟后总交互延迟约为550毫秒，支持亚秒级双工视听通信。这些结果使Wan-Streamer成为面向低延迟流式交互的统一、端到端、多模态交互基础模型。

## Abstract
We present Wan-Streamer, a native-streaming, end-to-end interactive foundation model designed from the ground up for real-time, low-latency, full-duplex audio-visual interaction. Wan-Streamer seamlessly models language, audio, and video as both input and output within a single Transformer, where the sequence is represented as interleaved visual, audio, and text input tokens together with visual, audio, and text output tokens, coordinated by block-causal attention for incremental streaming. Unlike cascaded interactive systems that rely on separate VAD, ASR, language, TTS, audio-driven animation, or video-generation modules, Wan-Streamer does not rely on external language, speech, avatar, or video-generation modules: perception, reasoning, generation, response timing, turn management, and cross-modal synchronization are learned jointly within one unified model, reducing pipeline latency and error accumulation. To support natural audio-visual responsiveness, we redesign the entire stack around streamability, including causal encoders, causal decoders, block-causal attention, and low-latency multimodal token scheduling, enabling streaming units as short as 160 ms at 25 fps. Wan-Streamer achieves approximately 200 ms model-side response latency and approximately 550 ms total interaction latency when combined with 350 ms bidirectional network latency, supporting sub-second duplex audio-visual communication. These results position Wan-Streamer as a unified, end-to-end, multimodal interactive foundation model for low-latency streaming interaction.

# Wan-Streamer v0.1 论文详细总结

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：现有实时视听交互系统普遍采用级联架构（如独立的 VAD、ASR、LLM、TTS、音频驱动动画、视频生成等模块），导致三个主要缺陷：（1）模块间等待时间累积，延迟高；（2）识别与生成误差逐级传递，同步困难；（3）话轮管理、中断、主动发言等全双工行为难以在分离模块中端到端学习。
- **整体含义**：真正的实时全双工交互要求系统持续感知、即时响应，且感知与表达在视听时间尺度上重叠。Wan-Streamer 旨在从头设计一个原生流式、端到端的**基础模型**，将语言、音频、视频同时作为输入和输出，在一个 Transformer 中联合建模，消除级联瓶颈，实现亚秒级全双工视听通信。

## 2. 方法论

### 核心思想
- 将交互建模为连续因果流：用户观测（语言、音频、视频）与智能体响应在同一因果序列中交错，由单一 Transformer 通过**块因果注意力（block-causal attention）** 处理，支持增量流式生成。
- **统一序列表示**：输入/输出均为交错的视觉、音频、文本令牌，共享上下文。
- **联合学习**：感知、推理、生成、响应时序、话轮管理、跨模态同步全部在一个模型中端到端学习。

### 关键技术细节
- **因果编解码器**：严格因果的音频/视频变分自编码器（VAE）、因果编码器和因果解码器，确保每个新观测单元立即可用。
- **块因果注意力**：在时间上保持因果关系，同时允许同一时间步内不同模态令牌间的交互。
- **响应生成**：语言部分用下一个令牌预测（交叉熵损失）；音频和视频用条件流匹配（conditional flow matching）生成连续潜变量。训练目标为估计速度场。
- **训练三阶段**：
  1. **独立任务预训练**：从语言模型初始化，混合理解任务（图像、音频、视频理解、ASR、TTS、对话）和生成任务（图像/音频/视频生成），对齐感知、推理与生成。
  2. **端到端交互训练**：使用双工信数据，用户输入和智能体输出交错在同一因果流中，学习响应时机、中断、主动倾听等行为。
  3. **蒸馏低延迟流式**：将带无分类器引导（CFG）和多求解步的教师模型蒸馏为学生模型，用滚动蒸馏（self-forcing + 分布匹配）缓解长程退化。
- **推理流水线（thinker-performer）**：部署为分离的两组件，通过 KV 缓存交换保持统一状态，重叠当前帧感知/状态更新、上一帧解码、下一帧潜变量去噪和通信。
  - Thinker：因果编码器、语言预测路径、因果解码器。
  - Performer：流匹配求解器，仅负责潜变量生成。
  - 实现约 200 ms 模型端延迟，配合 350 ms 双向网络延迟达到约 550 ms 总交互延迟。

## 7. 优点

- **架构创新**：从头设计原生流式架构，所有组件（VAE、编码器、解码器、注意力、调度）均为因果，支持 160 ms 粒度流式单元。
- **端到端统一**：单 Transformer 同时处理多模态输入输出，无需外部 ASR/TTS/音视频生成模块，降低延迟与错误累积。
- **Thinker-Performer 推理设计**：通过 KV 缓存交换和任务重叠，最大化硬件利用率，实现低延迟推理，且保持了单一模型语义。

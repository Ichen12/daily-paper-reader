## 摘要
代码转换（CS）自动语音识别（ASR）由于缺乏高质量的CS文本-语音对用于训练而仍然具有挑战性。尽管已经探索了通过文本到语音（TTS）进行合成数据增强，但现有的CS TTS方法主要优化重建保真度，并未明确强制执行语言边界一致性，从而限制了它们在CS ASR增强中的有效性。本文提出了一种代码混合引导的偏好学习框架，该框架利用代码混合指数（CMI）引导合成语音生成向改进的代码转换保真度发展。在SEAME普通话-英语会话语料库上的实验表明，所提出的方法增强了合成数据在ASR微调中的实用性。具体而言，在微调Whisper Large时，所提出的方法分别在DevMAN和DevSGE数据集上将混合错误率（MER）从12.1%/17.8%降低到8.9%/14.2%。

## Abstract
Code-switch (CS) Automatic Speech Recognition (ASR) remains challenging due to limited availability of high quality CS text-speech pairs for training. Although synthetic data augmentation via Text-to-speech (TTS) has been explored, existing CS TTS approaches primarily optimise reconstruction fidelity and do not explicitly enforce language-boundary consistency, thereby limiting their effectiveness for CS ASR augmentation. This paper proposes a code-mixing guided preference-learning framework that steers synthetic speech generation toward improved code-switching fidelity using the Code Mixing Index (CMI). Experiments on the SEAME Mandarin-English conversational corpus demonstrate that the proposed method enhances the utility of synthetic data for ASR fine-tuning. Specifically, when fine-tuning Whisper Large, the proposed approach reduces Mixed Error Rate (MER) from 12.1%/17.8% to 8.9%/14.2% on the DevMAN and DevSGE sets, respectively.

## 2. 论文提出的方法论：核心思想、关键技术细节
- **核心思想**：提出**代码混合引导的偏好学习框架**，利用声学层面的CMI度量（CMI_speech）作为偏好信号，通过直接偏好优化（DPO）训练TTS模型，使其生成的合成语音在CS保真度（语言混合比例）上更优，再用此优化后的TTS生成合成数据增强ASR训练。
- **关键技术细节**：
  - **声学级CMI_speech**：利用Whisper的跨注意力机制为合成语音的每个声学帧生成伪语言标签，计算帧级语言混合比例，定义为：CMI_speech(u) = (T(u) - max_k T_k(u)) / T(u)，其中T(u)为总帧数，T_k(u)为属于语言k的帧数。进一步定义ΔCMI = CMI_speech(合成语音) - CMI_speech(真实语音)，衡量合成语音与真实语音在语言混合结构上的差异。
  - **DPO对齐过程**：
    1. 候选生成：对每个文本，由微调后的TTS模型随机生成N个候选语音。
    2. 多维度评分：使用三个自动批评者——ASR识别MER（越低越好）、UTMOS感知质量（越高越好）、ΔCMI（绝对值越小越好），分别归一化后加权求和得到最终排序分数R = λ·S_UTMOS - γ·S_MER - ν·S_ΔCMI。
    3. 偏好选择：每个文本取最高分和最低分候选组成偏好对，并过滤掉不可靠对（MER>20%、UTMOS<2.5、ΔCMI>20%的舍弃）。
    4. DPO损失优化：L_DPO = -E[log σ(β log(π_θ(正样本)/π_ref(正样本)) - β log(π_θ(负样本)/π_ref(负样本)))]，使TTS模型更倾向于生成高评分候选。
  - **三阶段流程**：阶段1（基础微调TTS适应CS任务）→ 阶段2（DPO对齐，引入CMI_speech批评）→ 阶段3（用优化后TTS合成语音扩充训练数据，微调下游ASR模型）。

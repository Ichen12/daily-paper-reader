## 摘要
最近的流匹配文本到语音模型，如F5-TTS，在推理时依赖于从外部ASR系统获得的参考转录文本。这种依赖性使得零样本文语转换在口音或构音障碍说话人上表现脆弱，而这正是最需要该技术的场景。此外，我们发现基于文本的参考条件化会将非典型语音中的非典型声学模式传播到合成语音中，即使使用真实转录文本也是如此。为了解决这个问题，我们提出了RTFree-F5，该方法用连续的自监督语音表示替换参考转录文本，通过轻量适配器将其映射到F5-TTS的文本条件化空间，同时复用预训练检查点。在构音障碍语音上，RTFree-F5将词错误率从24.6%降低到10.4%，甚至超过了使用真实转录文本的基线，同时提高了自然度，并在标准基准测试中保持竞争力，而无需任何参考转录文本。

## Abstract
Recent flow-matching text-to-speech (TTS) models, such as F5-TTS, rely on a reference transcript at inference time, obtained from an external ASR system. This dependency makes zero-shot TTS brittle for accented or dysarthric speakers, precisely the scenarios where it is most needed. Moreover, we find that text-based reference conditioning can propagate atypical acoustic patterns from atypical speech into synthesis, even when ground-truth transcripts are available. To address this, we propose RTFree-F5, which replaces the reference transcript with continuous self-supervised speech representations mapped into F5-TTS's text-conditioning space via a lightweight adapter, while reusing the pretrained checkpoint. On dysarthric speech, RTFree-F5 reduces WER from 24.6% to 10.4%, surpassing even the ground-truth reference transcript baselines, while improving naturalness and remaining competitive on standard benchmarks without requiring any reference transcript.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究动机**：当前先进的流匹配（flow-matching）零样本文语转换（TTS）模型（如F5-TTS）在推理时依赖从外部ASR系统获取的参考语音转录文本。这导致两个核心问题：
  - 对于构音障碍（dysarthric）、口音（accented）或非母语（non-native）等非典型语音，ASR错误率很高，直接劣化参考条件化效果，使得零样本TTS在这些最需要应用的场景中表现脆弱。
  - 即使使用真实转录文本（oracle transcript），基于文本的条件化也会因“文本特征”（编码期望的规范音系）与“参考音频实际声学模式”之间的不匹配，将非典型语音中的异常发音模式（如不清晰的发音、异常韵律）传播到合成语音中，限制了合成质量。
- **整体含义**：该论文揭示了现有TTS对文本条件化的根本性依赖缺陷，并提出了一种摆脱这种依赖的方法，旨在为所有说话人（尤其是非典型语音）提供更鲁棒、更自然的零样本语音克隆和重建。

## 2. 方法论：核心思想、关键技术细节、流程（文字说明）

- **核心思想**：用连续的自监督学习（SSL）语音表示来替代参考转录文本，并通过一个轻量适配器将其映射到F5-TTS已有的文本条件化空间，从而兼容预训练好的F5-TTS检查点，避免从头训练。

- **关键技术细节（RTFree-F5架构）**：
  1. **SSL编码器**：使用冻结的WavLM-Large作为语音编码器，从参考音频提取帧级连续表示（1024维，50Hz）。
  2. **模态桥接投影器**：一个两层的MLP（含LayerNorm和GELU激活），将SSL特征从1024维投影到F5-TTS条件空间512维。投影器参数量约0.8M。为防止分布偏移，初始化最后一层权重缩放因子0.1。
  3. **特征对齐**：由于WavLM帧率（50Hz）与F5-TTS梅尔谱帧率（约93.75Hz）不符，对投影后的特征进行线性插值以匹配帧率。
  4. **条件化输入**：将投影后的参考语音特征 `H_ref` 与目标文本经F5-TTS文本编码器得到的 `H_tgt` 在时间轴拼接，形成最终条件 `H_cond`，输入DIFFusion Transformer（DiT）骨干网络。参考音频的梅尔谱仍作为未掩码的声学上下文（与原始F5-TTS一致）。
  5. **训练策略**：两阶段训练。
     - **Stage 1（跨模态对齐）**：仅训练投影器，冻结SSL编码器和整个F5-TTS模型（含DiT）。使用**跨语句对**（同一说话人的不同话语）作为训练样本，采用与原始F5-TTS相同的流匹配目标损失。目的是获得初始跨模态对齐。
     - **Stage 2（联合微调）**：联合微调投影器和DiT骨干，冻结文本和语音编码器。学习率：DiT骨干1e-5，投影器5e-5。进一步适应跨语句条件化场景。
  6. **推理**：给定参考音频和目标文本，构建条件 `H_cond`，使用Euler ODE求解器（32步）、摇摆采样系数-1、CFG强度2.0，生成梅尔谱，再经Vocos声码器合成波形。**无需参考转录文本**。

## 6. 主要结论与发现

- **主要结论**：RTFree-F5通过替换参考转录文本为连续SSL语音特征，完全消除了对转录文本的依赖，同时可复用预训练F5-TTS权重。
- **关键发现**：
  1. **非典型语音显著改善**：构音障碍语音WER从原声24.62%降至10.39%，非母语语音从10.75%降至1.44%，均优于真实转录基线（20.71%和2.00%）。自然度（MOS）也大幅提升。
  2. **文本条件化的根本局限**：即使有完美转录文本，其编码的“规范音系期望”与非典型语音实际声学特征冲突，导致异常模式传播；SSL条件化则能更好地与参考音频对齐，减少这种冲突。
  3. **典型语音保持竞争力**：在标准基准上，RTFree-F5的WER、MOS与基线相当或略优，未因去掉文本而退化。
  4. **说话人相似度权衡**：非典型语音上SIM略有下降（0.60→0.50），作者解释为“提高可懂度需部分修正病理特征，ECAPA-TDNN可能混淆身份与病理特征”，但认为在辅助沟通场景下可接受。

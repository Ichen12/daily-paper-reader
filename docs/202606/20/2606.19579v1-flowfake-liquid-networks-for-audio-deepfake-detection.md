## 摘要
由神经文本转语音和语音克隆系统生成的音频深度伪造威胁着说话人验证和大规模公共话语。核心挑战是跨数据集的泛化：在一个合成流水线上训练的检测器会在未见过的伪造品上崩溃。我们认为这一失败主要是因为结构性的合成语音伪影，这些是多时间尺度的轨迹异常。尽管每个现有检测器都聚合固定窗口的帧统计量，但这使得架构与信号不对齐。我们提出了FlowFake，一种液态时间常数（LTC）架构，其隐藏状态通过学习的ODE演化，每个神经元具有自适应时间常数，同时解析频谱（10ms）和韵律（2s）线索。仅34K参数，FlowFake实现了正式的BIBO稳定性和O(dt^4)积分误差。在四个数据集跨域基准（ASVspoof2019-LA、FakeOrReal、InTheWild、MLAAD）上，FlowFake仅在FakeOrReal上训练时在ASVspoof2019上达到75.29%，仅在MLAAD上训练时达到79.97%。它在每个评估对上优于RawGAT-ST和Whisper-DF，并以0.01%的参数数量与SSL Wav2vec2（大300倍）相当。源代码可在https://github.com/GhostRider2023/FlowFake获取。

## Abstract
Audio deepfakes generated by neural text-to-speech and voice-cloning systems threaten speaker verification and public discourse at scale. The core challenge is cross-dataset generalization: detectors trained on one synthesis pipeline collapse on unseen forgeries. We argue that this failure is primarily because of structural synthetic speech artifacts which are multi-timescale trajectory anomalies. Though every existing detector aggregates a fixed-window frame statistics, this misaligns the architecture with the signal. We propose FlowFake, a Liquid Time-Constant (LTC) architecture whose hidden state evolves via a learned ODE, with per-neuron adaptive time constants simultaneously resolving spectral (10ms) and prosodic (2s) cues. At only 34K parameters FlowFake achieves formal BIBO stability and O(dt^4) integration error. On a four-dataset cross domain benchmark (ASVspoof2019-LA, FakeOrReal, InTheWild, MLAAD), FlowFake reaches 75.29% on ASVspoof2019 trained only on FakeOrReal and 79.97% trained only on MLAAD. It outperforms RawGAT-ST and Whisper-DF on every evaluated pair and matching SSL Wav2vec2 (300x larger) at 0.01% of its parameter count. The source code is available on : https://github.com/GhostRider2023/FlowFake

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：神经文本转语音（TTS）和语音克隆技术能生成逼真的音频深度伪造，对说话人验证系统和公共话语构成威胁。现有检测器在单一合成流水线上表现尚可，但在跨数据集泛化时严重失效（例如，在FakeOrReal上训练的模型在ASVspoof 2019上表现接近随机）。
- **现有方法的缺陷**：三种主流范式（图注意力网络、自监督学习前端、ASR编码器复用）均因固定窗口帧统计量与信号结构不匹配而失败。合成语音的伪影本质上是多时间尺度的**轨迹异常**（频谱帧约10ms，韵律约2s），而现有模型只能聚合帧级统计量，结构性地丢失了轨迹信息。
- **核心主张**：需要一个具备连续时间轨迹建模能力的架构，直接检测发音动力学约束的违反，而非学习特定合成管线的指纹。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：采用**液态时间常数（Liquid Time-Constant, LTC）网络**，其隐藏状态通过学习到的常微分方程（ODE）演化，每个神经元拥有自适应时间常数，同时捕获频谱和韵律两个时间尺度的异常。

- **技术细节**：
  1. **前端**：16kHz波形→ℓ2归一化→对数梅尔频谱（128频带，nfft=512，hop=160样本，Δt≈10ms）。
  2. **卷积编码器**：5层1D卷积（核大小{5,1,3,3,1}，BN，ReLU，输出通道32），将每帧压缩为32维嵌入。
  3. **LTC细胞**：隐藏状态h(t)依ODE更新：
     ```
     dh/dt = (1/Cm) ⊙ [ W_in E_t + tanh(W_rec h(t)) + g_leak ⊙ (V_leak - h(t)) ]
     ```
     其中Cm、g_leak、V_leak为可学习的膜电容、漏电导和静息电位。简化版将原生物突触（sigmoid）替换为tanh，去除约3倍参数并稳定梯度。
  4. **自适应时间常数**：每个神经元在log空间参数化τ_i=exp(τ̂_i)，限制在[0.05, 10]秒，训练后呈双峰分布（快聚类0.1-0.3s，慢聚类1.5-5.0s），自动发现两种伪影时间尺度。
  5. **求解与分类**：用四阶龙格-库塔（RK4）以Δt=0.01s、每帧2次展开求解ODE，终止状态经2层全连接头（d=16）输出二元分类。使用带正类权重的BCEWithLogitsLoss处理类别不平衡。

- **理论分析**：
  - **BIBO稳定性**（定理4.2）：在输入有界条件下，隐藏状态范数有上界R*，由漏电导和输入权值决定。
  - **RK4全局误差**（定理4.3）：误差≤C_f·10⁻⁸，低于FP32精度。
  - **噪声鲁棒性**（命题B.4）：噪声扰动指数衰减，速率η≈g_leak/c_min。
  - **梯度衰减**（命题B.7）：早期帧梯度以指数速率衰减，因此设计数据集特定的LTC覆盖长度T'（1-2秒）。

## 摘要
本研究探讨了双语微调如何影响低资源语言的自动语音识别（ASR）。我们跨九个语言和地理多样性高的语言对进行评估，涵盖多种语系和书写系统。为区分两种语言，在训练期间，我们在每个输入文本前添加一个语言标识令牌。在推理时，模型仅从语音输入中联合预测语言和转录。由于语言被错误确定的文本表现出较低的ASR性能，我们还进行了一项后续实验，在训练和推理期间均提供语言标识令牌。我们的结果表明，当语言识别准确性高时，双语微调可能有益；而在语言识别性能低的情况下，在推理时包含语言标识令牌有助于提高ASR性能。

## Abstract
This study explores how bilingual fine-tuning affects automatic speech recognition (ASR) in low-resource languages. We evaluate this method across nine linguistically and geographically diverse language pairs, covering a range of language families and writing systems. To distinguish the two languages, during training, we pre-pend each input text with a language identification token. At inference, the model jointly predicts both the language and transcription from the speech input alone. As texts for which the language is incorrectly determined show low ASR performance, we also conduct a follow-up experiment in which the language identification token is provided both during training and inference. Our results show that bilingual fine-tuning can be beneficial when language identification accuracy is high, and that in cases where language identification performance is low, including the language identification token at inference helps to improve ASR performance.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：自动语音识别（ASR）在高资源语言（如英语）上取得显著进步，但低资源语言仍面临数据稀缺和方言变异等挑战。跨语言迁移学习是缓解该问题的有效途径，其中双语或多语微调被广泛探索。
- **核心问题**：先前研究（如 Amooie et al., 2025）表明，在微调时给每个样本添加语言标识（LID）词元有助于弗里斯兰语 ASR，但尚未系统验证该方法在不同语系、书写系统及语言相似度下的普适性。本文旨在回答：**双语微调结合显式语言标识在哪些条件下能稳定提升低资源语言 ASR 性能？**
- **整体含义**：揭示 LID 准确性是决定双语微调收益的关键因素，并探索在 LID 准确率低时如何弥补损失，为低资源多语言 ASR 提供实用策略。

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：在预训练模型 XLS-R 1B 基础上，对每个语言对进行双语微调。训练时，在每个转录文本前预置一个 **语言标识（LID）词元**（如 `[FY-NL]` 表示弗里斯兰语，`[NL]` 表示荷兰语）；推理时**不提供 LID 词元**，模型通过 CTC 解码先预测 LID，再预测转录，从而**联合学习语言识别和语音识别**。
- **关键技术细节**：
  - 使用 Wav2Vec 2.0 架构的 XLS-R 1B，微调时**冻结卷积特征编码器**，仅更新 Transformer 层（符合常规微调实践）。
  - 学习率 0.00008，批次大小 8，梯度累积步数 16，16-bit 浮点精度，训练 50 个 epoch。
  - 双语模型的数据量是单语的两倍，但通过固定 epoch 数（50 次迭代）确保每个样本被看到的次数与单语基线一致，从而避免因训练步数增加带来的性能提升。
- **后续实验（提供正确 LID 在推理时）**：
  - 为缓解 LID 低准确率问题，设计一个简单的**语言特定偏置嵌入**（每个语言一个向量，大小与词汇表相同），在 CTC 解码的 logits 上逐时间步添加该偏置。训练和推理时均提供真实的 numeric language ID，使解码器偏向目标语言的字素序列，编码器则完全共享，仅增加极少量参数。

## 3. 实验设计：数据集、基准与对比方法

- **数据集**：全部从 **Common Voice 17.0** 提取，采样率 16 kHz。每个语言对的目标语言和捐赠语言各取最多 3000 句话（若某语言不足则两者都取较小值），以确保训练实例数相当。测试集不下采样。
- **9 个语言对**，覆盖 5 个语系（日耳曼语系、罗曼语系、斯拉夫语系、达罗毗荼语系、乌拉尔语系）及拉丁字母、西里尔字母、天城文变体等不同书写系统：
  - 日耳曼语系：弗里斯兰语–荷兰语（FY-NL）、丹麦语–瑞典语（DA-SV）
  - 罗曼语系：加利西亚语–意大利语（GL-IT）
  - 斯拉夫语系：乌克兰语–白俄罗斯语（UK-BE）、斯洛伐克语–捷克语（SK-CS）、塞尔维亚语–保加利亚语（SR-BG）、斯洛文尼亚语–波兰语（SL-PL）
  - 达罗毗荼语系：马拉雅拉姆语–泰米尔语（ML-TA）
  - 乌拉尔语系：芬兰语–爱沙尼亚语（FI-ET）
- **基准**：每个语言对的基线模型是仅用目标语言数据（3000 句）训练的**单语模型**。双语模型则用目标 + 捐赠语言共 6000 句（或更少）训练。
- **对比方法**：
  - 主要对比单语 vs 双语（含 LID 词元）。
  - 后续实验对比：**推理时预测 LID** vs **推理时提供正确 LID**（通过语言偏置嵌入）vs **单语基线**。
- **评估指标**：词错误率（WER），∆WER = 单语 WER – 双语 WER（正表示双语提升）；LID 准确率（正确识别为目标语言的比例）。

## 6. 论文的主要结论与发现

1. **双语微调并非普遍有益，其收益与 LID 准确率强相关**。
   - 当 LID 准确率 **>95%** 时（如 FY-NL、GL-IT、DA-SV），双语微调带来显著的 ∆WER 改善（p < 0.01）。
   - 当 LID 准确率 **<95%** 时（如 UK-BE、SK-CS、FI-ET），双语微调可能损害性能（负 ∆WER），且该损失与 LID 准确率负相关。
2. **LID 准确率与 ∆WER 呈正相关**（全局 Pearson r = 0.621, p < 0.001），说明低 LID 准确率是制约双语微调收益的瓶颈。
3. **推理时提供正确 LID 可以弥补低准确率带来的损失**：
   - 对于 DA-SV（LID 准确率 ~95%）和 SK-CS（~89%），提供正确 LID 后 ∆WER 由负转正，分别提升 1.8% 和 0.6%；
   - 对于 FY-NL（LID 准确率 ~99%），提供 LID 无额外提升（已接近天花板）。
4. **书写系统差异（如马拉雅拉姆语–泰米尔语）不阻碍跨语言迁移**，反而取得正收益（∆WER = +1.3）。
5. **说话人数量** 未呈现明显影响（如爱沙尼亚语说话人多但对芬兰语无帮助，泰米尔语说话人少却对马拉雅拉姆语有帮助）。

## 摘要
能够生成逼真合成语音的文本转语音（TTS）系统的激增给音频取证带来了日益严峻的挑战。虽然二元深度伪造检测已受到广泛关注，但源追踪（即识别特定音频样本由哪个TTS系统生成）仍然未被充分探索，尤其是在可能遇到未知系统的开放集场景中。我们提出了一种基于Proxy-Anchor损失函数的度量学习框架，该框架作用于Wav2Vec2-BERT嵌入，以学习用于TTS源归属和未知系统的分布外（OOD）检测的判别性嵌入空间。我们在涵盖51种语言、140个TTS系统的MLAAD v9数据集上进行了评估，并引入了一种架构合并策略，将TTS系统版本分组为统一类别，从而减少了类间混淆。我们的系统在110个分布内类别上实现了99.76%的准确率，并且OOD检测的假阳性率（FPR@95）低至2.04%。此外，为了与当前最先进的技术进行公平比较，我们在MLAAD v5官方数据集划分上进一步评估，将OOD准确率提高了近一倍。这些结果表明，Proxy-Anchor度量学习结合架构感知的类别设计和事后OOD评分，为封闭集和开放集环境下的取证TTS源追踪提供了一个有效的框架。

## Abstract
The proliferation of text-to-speech (TTS) systems capable of generating realistic synthetic speech poses growing challenges for audio forensics. While binary deepfake detection has received considerable attention, source tracing (i.e., identifying which TTS system produced a given audio sample) remains underexplored, particularly in open-set scenarios where unknown systems may be encountered. We propose a metric learning framework based on the Proxy-Anchor loss function that operates on Wav2Vec2-BERT embeddings to learn a discriminative embedding space for TTS source attribution and out-of-distribution (OOD) detection of unseen systems. We evaluate it on the MLAAD v9 dataset spanning 140 TTS systems across 51 languages, and introduce an architecture merging strategy that groups TTS system versions into unified classes, reducing inter-class confusion. Our system achieves 99.76% accuracy on 110 in-distribution classes and a False Positive Rate (FPR@95) as low as 2.04% for OOD detection. Also, for a fair comparison against the current state of the art, we further evaluate it on the MLAAD v5 official dataset splits, improving the OOD accuracy by almost doubling it. These results demonstrate that Proxy-Anchor metric learning, combined with architecture-aware class design and post-hoc OOD scoring, provides an effective framework for forensic TTS source tracing in both closed-set and open-set settings.

## 1. 核心问题与研究动机
- **研究背景**：文本转语音（TTS）系统可生成极其逼真的合成语音，被滥用于欺诈、虚假信息等场景。现有音频深度伪造检测多聚焦于二分类（真实 vs 合成），但这不足以进行取证分析——当检测出合成语音时，调查者需要进一步追踪其来源（即哪一个TTS系统生成），即源追踪（source tracing）或归因（attribution）。
- **核心问题**：在开放集（open-set）场景下，测试样本可能来自训练时未见的未知TTS系统，此时系统需能识别出“未知”（out-of-distribution, OOD）样本，同时仍能正确归属已知系统。现有方法多限于封闭集，或对未知系统处理不足。
- **整体意义**：本文旨在提出一个既能在封闭集中准确区分大量已知TTS系统，又能在开放集中有效检测未知系统的统一框架，为音频取证提供实用工具。

## 2. 方法论
- **核心思想**：基于深度度量学习，使用Proxy-Anchor损失函数训练一个投影头，将Wav2Vec2-BERT提取的语音嵌入映射到一个判别性嵌入空间，每个已知TTS系统对应一个可学习的原型嵌入（proxy）。推理时，通过计算输入嵌入与各原型之间的余弦相似度进行归因；同时，利用不确定性评分（熵、软最大能量、最大原型距离）判断是否来自未知系统。
- **关键技术细节**：
  - **音频特征提取**：使用预训练的Wav2Vec2-BERT模型（facebook/w2v-bert-2.0），取第4层（共24层）的输出，经时间平均池化得到1024维的句子级嵌入。
  - **投影头**：一个线性层，将1024维输入映射到1024维度量空间，并对输出进行L2归一化，使其位于单位超球面上。
  - **损失函数**：Proxy-Anchor损失。每个类别有一个可学习的原型，损失以每个原型为锚点，拉近其正样本、推开负样本，超参数：margin δ=0.1，缩放因子α=32。
  - **OOD检测**：推理时分两步：①计算不确定性评分（三种方法：软最大能量、香农熵、最大余弦距离）；②若评分超过预校准阈值τ（在验证集上设置，使得TPR=95%），则判定为OOD；否则进入归因步骤，选择余弦相似度最高的原型作为预测类别。
  - **架构合并策略**：将共享相同底层架构但版本/参数量不同的TTS系统合并为同一类别（如Llasa-1B和Llasa-3B合并），减少类间混淆。实验二中，140个原始系统合并为130个类，其中110个用于ID，10个用于OOD标定，10个用于OOD测试。

## 6. 主要结论与发现
- **Proxy-Anchor度量学习**在TTS源追踪任务上有效，闭集准确率在110个合并类上达99.76%，远超k-NN（95.15%）。
- **架构合并策略**显著减少类间混淆：相对于不合并（实验1），合并后ID准确率提高1.53%，OOD检测FPR@95从9.59%降至2.04%（使用最大原型距离评分）。
- **最佳OOD评分方法**随类数变化：大类数（120类）时使用熵，小类数且高度结构化（110类合并）时使用最大原型距离效果最好。
- **与SOTA对比**：在MLAAD v5上，闭集准确率98.57%（优于Kulkarni的95.61%和Klein的95.80%），OOD准确率89.20%（接近Kulkarni的44.82%的两倍），FPR@95为3.36%（相比Klein的8.30%降低60%）。
- **关键发现**：闭集归因与开集拒绝可以互补——Prox-Anchor loss强制类内紧凑、类间分离，自然有利于OOD检测。

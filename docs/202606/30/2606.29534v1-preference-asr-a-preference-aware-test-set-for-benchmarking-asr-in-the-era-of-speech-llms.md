## 摘要
流行的ASR测试集在数字、不流畅、实体和大小写方面采用不一致的惯例，而标准归一化器会抹去用户关心的格式差异。因此，当前的基准测试无法衡量模型是否遵循用户对输出风格的偏好。我们引入PreferenceASR，一个测试集，评估ASR系统在四个类别（归一化、实体、不流畅和大小写）中遵循自然语言偏好指令的能力。该测试集通过两阶段LLM辅助流程（含人工验证）从七个开源语料库构建，并使用偏好感知归一化器进行评估，该归一化器会选择性跳过与当前指令匹配的步骤。对四个模型的基准测试显示，排名在不同偏好类型间发生变化，揭示了传统评估所掩盖的质量差异。我们公开发布该数据集。

## Abstract
Popular ASR test sets adopt inconsistent conventions for numbers, disfluencies, entities, and casing, while standard normalizers erase the format distinctions users care about. Current benchmarks therefore cannot measure whether a model follows user preferences for output style. We introduce PreferenceASR, a test set evaluating ASR systems on their ability to follow natural-language preference instructions across four categories: normalization, entities, disfluencies, and case. Built from seven open-source corpora via a two-stage LLM-assisted pipeline with human verification, it is evaluated with a preference-aware normalizer that selectively skips steps matching the active instruction. Benchmarking four models shows rankings shift across preference types, exposing quality differences traditional evaluation obscures. We publicly release the dataset.

## 1. 论文的核心问题与整体含义

- **研究动机**：现有的ASR测试集（如LibriSpeech、SPGISpeech、Earnings-22等）在数字格式、不流畅处理、实体大小写等方面采用不一致的标注惯例（例如GigaSpeech使用口语数字、Earnings-22使用书面数字；AMI保留填充词、SPGISpeech删除）。标准WER评估中的归一化操作会抹去这些格式差异，导致无法衡量模型是否遵循用户对输出风格的偏好。
- **核心问题**：当SpeechLLM能够根据自然语言指令调整输出格式时，传统基准无法评估这一能力。用户实际场景（如数据库管道需要ITN、播客脚本需要TN、发音辅导需要保留不流畅）对输出格式有明确偏好，但缺乏相应的测试集。
- **整体含义**：提出**Preference-ASR**测试集，填补评估ASR系统遵循人类偏好指令能力的空白，揭示传统WER指标掩盖的模型质量差异。

## 2. 论文提出的方法论

- **核心思想**：构建一个“音频-指令-参考”三元组测试集，覆盖四种常见的偏好类别，并设计偏好感知归一化器以公平计算WER。
- **关键技术细节**：
  - **两阶段LLM辅助流水线**（使用Qwen3-30B-A3B）：
    - Stage 1：偏好分类——对每个样本的转录文本判断其属于归一化、实体、不流畅、大小写中的哪些类别。
    - Stage 2：指令与参考生成——根据分类结果生成相应的指令（如“将数字和符号归一化为口语形式”）和对应的偏好参考文本。对归一化和不流畅类别生成两种方向（TN/ITN、保留/删除）。应用优先级排序（归一化>实体>不流畅>大小写）以避免样本重复归属。
  - **人工验证**：两个阶段均进行人工校正，确保参考文本正确。
  - **偏好感知归一化器**：标准归一化会抹去格式差异。该归一化器根据激活的指令选择性跳过对应步骤：
    - 归一化指令：跳过自身的TN或ITN步骤；
    - 不流畅指令：保留或删除填充词/重复；
    - 大小写指令：抑制小写化，直接评估大小写和标点；
    - 实体指令：使用标准归一化，因为WER自然能捕捉实体名称准确性。
- **数据集构成**：从7个开源语料库（AMI、Common Voice、Earnings-22、GigaSpeech、LibriSpeech、SPGISpeech、VoxPopuli）中选取约600个样本/语料库，共3545个样本经过人工验证，最终获得3210个唯一的三元组。剩余335个样本作为无偏好指令的基线测试。类别分布：归一化409、实体680、不流畅539、大小写1582。

## 6. 论文的主要结论与发现

- **模型排名因偏好类型而异**：在偏好感知WER下，模型排名发生显著变化，传统标准WER无法揭示这些差异。
- **Qwen3-Omni**在格式遵循上表现优秀（归一化、不流畅、大小写指令下WER低于或持平于默认基线），但在实体指令下出现严重的提示驱动幻觉（实体WER从5.12%升至12.85%），即模型过度依赖提示中的名称而忽视音频证据。
- **Canary-Qwen**对指令几乎不敏感（整体WER变化极小），表明仅有LLM后端而无偏好对齐训练不足以实现指令遵循。
- **Phi-4**在不流畅类别上指令遵循能力极强（默认WER 50.18% → 指令下10.46%），但大小写指令反而导致性能急剧下降（3.93% → 19.76%），说明其指令遵循具有类别依赖性。
- **偏好感知WER揭示了被标准归一化掩盖的质量差异**：所有模型在偏好感知评估下WER均上升（例如Canary-Qwen的大小写WER从3.59%跳至10.08%），说明即使词内容正确，输出格式也偏离了参考。

## 7. 优点

- **新颖的评估维度**：首次系统性地评估ASR系统遵循用户对输出格式（归一化、实体、不流畅、大小写）的偏好指令的能力，填补了现有基准的空白。
- **高质量的测试集**：通过两阶段LLM辅助 + 人工验证构建3210个三元组，覆盖7个高质量开源语料库，多样化真实场景。
- **偏好感知归一化器**：提出选择性跳过归一化步骤的方法，使WER计算能够忠实反映指令遵循程度，避免传统归一化抹去关键信息。
- **揭示实际问题**：通过实验暴露了SpeechLLM在上下文偏置下的幻觉问题（实体类别），这在传统基准中无法检测，对实际部署有重要警示作用。
- **开源贡献**：公开数据集和评估代码，促进可重复研究和后续改进。

## 8. 不足与局限

- **语言覆盖**：仅英语，未涵盖多语言或多说话人场景。
- **偏好类别有限**：仅考虑四个类别，未包括例如多说话人标注、语速/语调等更细粒度的偏好。
- **依赖LLM生成**：指令和参考文本由LLM生成并需人工验证，对于归一化类别尤其困难（因无法从纯文本推断声学上下文），可能引入细微错误或偏差。
- **未包含消融实验**：未比较不同LLM辅助生成的质量、不同优先级策略的影响。
- **模型选择范围**：虽然覆盖了非LLM和多种SpeechLLM，但未包括如Whisper等流行模型，也未对比不同提示模板的影响（但论文提到提示措辞变化已引起WER波动）。
- **应用限制**：测试集专注于转录级偏好，未评估下游任务（如翻译、问答）中偏好遵循的影响。且仅通过WER衡量，可能无法完全反映用户满意度。

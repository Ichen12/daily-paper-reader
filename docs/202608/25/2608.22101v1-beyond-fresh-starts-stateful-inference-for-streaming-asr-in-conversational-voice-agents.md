## 摘要
现代语音代理系统依赖于在严格延迟约束下运行的流式语音识别模型。本研究表明，由于实时处理的有限内存约束，这些系统会受到长静音和反馈等会话现象的不利影响。虽然许多代理管道通过在每个回合重置状态来缓解这一问题，但这种方法丢弃了关键上下文，并在回合开始时损害性能。我们提出了两种状态管理策略，以保留跨话语上下文来减少开始错误。在使用两种最先进的流式模型对两个口语对话基准进行的实验中，我们的最佳方法在话语开始处平均实现了15-21%的相对词错误率降低。

## Abstract
Modern voice-agent systems rely on streaming speech recognition models that operate under stringent latency constraints. This study shows that, due to the limited memory constraints of real-time processing, these systems are adversely impacted by conversational phenomena such as long silences and backchannels. While many agentic pipelines mitigate this by resetting state at each turn, this approach discards vital context and impairs performance at turn onsets. We propose two state-management strategies that preserve cross-utterance context to reduce onset errors. In experiments with two state-of-the-art streaming models on two spoken dialogue benchmarks, our best method yields an average of 15-21% relative WER reduction at utterance onsets.

## 1. 核心问题与整体含义

- **研究背景**：现代会话式语音代理（Voice Agent）普遍采用级联式流水线（ASR → LLM → TTS），且需在严格延迟预算（响应延迟 < 500ms，ASR 部分 < 200ms）下运行，因此必须依赖流式 ASR（Streaming ASR）模型进行实时转写。
- **核心问题**：流式 ASR 由于实时处理的内存限制（通常只有几秒的声学记忆窗口），在对话中两类常见现象——**长静音（long silences）** 和 **反馈词（backchannels，如 “mm-hm”、“uh-huh”）**——会显著损害识别性能。这些非任务相关内容会占据有限的声学记忆，冲掉此前语轮的有效上下文。
- **现有方案的缺陷**：多数商业化语音代理在每个语轮结束时重置模型状态（“Fresh Start”），以避免长静音和反馈词的污染，但这会导致**语轮起始处（turn onset）的识别错误率显著升高**。由于 LLM 往往对输入序列靠前的 token 赋予更高权重，句首错误会对下游自然语言理解产生不成比例的影响。
- **论文含义**：提出将状态管理视为一个**推理期决策问题**——在保留跨语轮上下文与排除会话噪声之间取得平衡——不需要重新训练模型，即可在句首显著降低 WER。

## 2. 方法论

- **核心思想**：利用流式模型自身已有的内部状态（encoder 的注意力 KV cache、卷积 cache，以及 decoder 的 LSTM 状态），在语轮之间通过**有选择地保留/丢弃状态**来维护跨语句上下文。
- **模型状态组成**（以 FastConformer-RNNT 为例，共六个组件）：
  - **Encoder 状态**：注意力 KV cache（形状 `[n_layers, 1, 70, hidden_dim]`）、逐层卷积 cache、有效 cache 长度计数器；
  - **Decoder 状态**：RNNT predictor 的 LSTM 循环状态、最后预测 token、已生成 token 数。
- **四种状态管理策略**：
  - **Fresh Start（FS）**：每轮开始前完全重置状态，每个语轮独立解码（商业化语音代理的主流做法）。
  - **Continuous State（CS）**：流式处理不做任何干预，连续跨过语轮间静音（类似实时字幕/会议转写场景）。
  - **State Carry-over（SC，本文提出）**：将上一语轮结束时的状态作为下一语轮的起始状态，跳过中间静音，保留跨语轮上下文。
  - **State Rollback（RB，本文提出）**：在 SC 基础上增加回滚机制——若前一语轮过短（ASR 输出 token 数 < 阈值 k，通常为反馈词），则回滚到最后一次“实质性语轮”结束时的状态，以丢弃反馈词的干扰。
- **算法流程**（Algorithm 1，文字描述）：

```
输入：音频流中的语轮序列 {u1,...,uT}；模式 m ∈ {FS, SC, RB}；阈值 k（仅 RB 用）
初始化：S = ∅（当前状态），S* = ∅（最后实质性语轮状态）
对每个语轮 ui：
    1. 使用当前状态 S 对 ui 解码，得到假设 hi 和新状态 Si
    2. 若 m = FS：S ← ∅（重置）
    3. 若 m = SC：S ← Si（直接携带状态）
    4. 若 m = RB：
       若 hi 的 token 数 ≥ k：S ← Si 且 S* ← Si（保留为实质性语轮）
       否则：S ← S*（回滚，丢弃反馈词上下文）
输出：所有语轮的假设 {h1,...,hT}
```

- **技术优势**：SC 无额外内存开销；RB 仅需存储一份额外状态 ≈ 2.6 MB（fastconformer-114m，约模型大小的 0.6%）或 7.32 MB（nemotron-streaming-0.6b，约 0.3%），开销可忽略。两种方法均**无需训练或微调**，可直接用于已训练好的流式模型。

## 3. 实验设计

- **模型**（两种 SOTA 流式 ASR 模型）：
  - **fastconformer-114m**：17 层 FastConformer 编码器，hidden size 512，约 114M 参数（435 MB），RNNT-CTC 混合训练目标，推理使用 RNNT 解码器。

- **数据集**：

- **评估指标**：
  - Overall WER（整体词错误率）；
  - **First Word**：语轮首词 WER（衡量句首错误）；
  - **After Long Pause**：前导静音 ≥ 5.6 s（超过模型声学记忆窗口）的语轮 WER；

## 6. 主要结论与发现

- Fresh Start 在多数场景下优于 Continuous State，但**首词错误率显著偏高**（fastconformer-114m 在 Switchboard 上首词 WER 高达 51.44%，是最明显的短板）。
- Continuous State 会随前导静音超过 5.6 s 记忆窗口而**性能急剧恶化**；也会因短语轮（反馈词）占用状态而损害后续转写。
- State Carry-over 对 fastconformer-114m 效果显著，但对 nemotron-streaming-0.6b 在反馈词后可能引入负面影响。
- **State Rollback 在所有模型、数据集、延迟设置和 VAD 边界条件下均为最优策略**——通过选择性丢弃短语轮（反馈词）上下文，同时保留实质性语轮上下文，达到最佳平衡。
- 在 160 ms 延迟下，RB 相对于 FS 在**首词 WER 上实现 20.6%–27.2% 的相对降低**（论文摘要报告平均 15–21%），且 Overall WER 也一致改善（相对降低 2.2%–14.4%）。
- 降低延迟至 160 ms 造成的性能损失相对可控：使用 RB 时，从 560 ms 降到 160 ms 的 WER 增幅低于 6%；fastconformer-114m 在 160 ms 延迟下的 RB 甚至优于 560 ms 延迟下的 FS。

- **问题定位精准**：明确指出语音代理场景中 ASR

- **实验证据扎实**：2 模型 × 2 数据集 × 4 策略 × 多类细分指标（首词、长静音后、短语轮后）的交叉验证，配合延迟消融、VAD 边界模拟和统计检验，结论可信度高；且同时报告了两种模型上的不同表现，避免了“单一模型结论”的偶然性。

## 8. 缺点与局限性

- **数据集覆盖面窄**：仅使用 Switchboard 和 CallHome 两个美式英语电话对话数据集（均为 1990 年代语料）。电话域的采样率、噪声条件和口音分布与现代语音代理的真实部署环境（如智能音箱、车载、多语言、近讲麦克风）差异较大；且两者风格相近，无法验证方法在会议、医疗、客服等多领域上的泛化性。
- **未评估下游任务影响**：论文声称句首 WER 降低对 LLM 理解“不成比例地重要”，但并未直接验证——没有将 ASR 输出送入 LLM/Voice Agent 做端到端评测，因此“句首错误改善能带来下游收益”这一核心动机属于推断而非实测。
- **VAD 实验不完整**：真实部署模拟仅覆盖 Switchboard 一个数据集（因 CallHome 缺词级时间戳）；且 Silero-VAD 与真实语轮边界差异大时，RB 相对 FS 的优势是否会缩小或反转，论文未做敏感性分析。
- **状态可迁移性未深究**：SC/RB 假设前轮状态对后轮有帮助，但未分析状态复用的机制性证据（如注意力各层到底"记住"了什么）；也未见对错误传播（误保留噪声状态导致级联错误）的讨论。
- **单风格模型评估**：两个模型均为 FastConformer 架构变体，结论是否适用于基于 E2E 的非自回归模型（如 Whisper 流式变体）或统计语言模型辅助解码的其他流式 ASR 架构，尚属未知。
- **延迟-精度权衡未在三方拉齐**：论文对 80 ms 右上下文的实验数据未在正文完整呈现（主要展示 160 ms 及更高值），且未报告 CPU 推理、实时率（RTF）等端到端部署性能指标。

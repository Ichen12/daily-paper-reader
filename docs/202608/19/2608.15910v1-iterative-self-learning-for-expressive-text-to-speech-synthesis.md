## 摘要
使用显式条件标签的表现力文本到语音（TTS）系统能够对表现力属性提供直接且可解释的控制，这与基于参考或基于提示的方法形成对比，但需要标注数据。大规模获取这些标签既昂贵又耗时，然而先前没有半监督框架针对这一特定瓶颈。现有的半监督TTS方法反而针对配对的语音-文本数据或转录文本的稀缺性。为了解决表现力标签的稀缺性，我们提出了一种用于表现力TTS的迭代自学习（ISL）框架，该框架基于Invert-Classify，一种通过反转冻结的生成模型来恢复离散表现力标签的无分类器方法。该框架使用当前模型对未标注语音进行迭代伪标注，在标注和伪标注数据的组合上重新训练，并重复此过程，逐步提升标签质量和合成效果。我们在两个表现力任务上进行了验证：词级突出性和话语级情感，跨越多个低资源数据划分。我们发现，与单次通过基线相比，迭代细化可以提高伪标签的准确性。此外，我们观察到，表现力伪标签的这些改进可转化为表现力标签遵循度和合成质量的提升，这通过客观指标和人类听感测试得到了确认。在数据最稀缺的条件下，经过ISL训练的模型优于单次通过伪标签方法，并进一步接近全监督性能，这表明基于梯度的ISL是低资源TTS中表现力标签稀缺问题的有效解决方案。

## Abstract
Expressive text-to-speech (TTS) systems that use explicit conditioning labels provide direct and interpretable control over expressive attributes, in contrast to reference-based or prompting-based approaches, but require labeled data. Obtaining these labels at scale is costly and time-consuming, yet no prior semi-supervised framework addresses this specific bottleneck. Existing semi-supervised TTS methods instead target scarcity of paired speech-text data or transcriptions. To address the scarcity of expressive labels, we propose an Iterative Self-Learning (ISL) framework for expressive TTS, built on Invert-Classify, a classifier-free method that recovers discrete expressive labels by inverting a frozen generative model. The framework iteratively pseudo-labels unlabeled speech using the current model, retrains on the combined labeled and pseudo-labeled data, and repeats, progressively refining label quality and synthesis. We validate on two expressive tasks, word-level prominence and utterance-level emotion, across multiple low-resource data splits. We find that iterative refinement can improve pseudo-label accuracy over single-pass baselines. Furthermore, we observe that these improvements in pseudo-labeling of expressivity translate to gains in expressive label adherence and synthesis quality, confirmed by objective metrics and human listening tests. In the most data-scarce conditions, ISL-trained models outperform single-pass pseudo-labeling and further approach fully supervised performance, demonstrating that gradient-based ISL is an effective solution to expressive label scarcity in low-resource TTS.

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想
采用"单模型自我进化"范式：模型先在少量标注数据上训练，随后冻结自身，通过反转（inversion）从未标注语音中恢复离散表现力标签（伪标注），再在标注+伪标注数据上重训，如此循环迭代，逐步提升标签质量和合成性能。

### 2.2 Invert-Classify 伪标注机制
- **原理**：不依赖外部分类器，而是利用TTS模型自身的生成损失（L_Total）对条件标签嵌入（conditioning embedding）做梯度下降，使嵌入收敛到与观测语音最一致的表示。
- **流程**：将缺失标签的嵌入初始化为所有可能标签嵌入的均值 → 用训练损失做梯度更新 → 更新后的连续嵌入通过余弦相似度量化到最近的离散标签条目。
- **与Classifier-Free Guidance的异同**：概念相似（都用生成模型本身解读条件空间），但CFG在推理时操纵条件以改善样本质量，Invert-Classify在输入层优化条件以恢复离散标签。

### 2.3 关键工程适配：确定性反转环境
- 标准flow-matching训练的损失函数在每批随机采样时间步t和噪声x₀，导致反转目标不稳定。
- **解决方案**：固定时间步t=0.9（靠近插值末端的较大梯度），固定单一噪声张量x₀，使梯度主要反映条件标签而非采样方差。

### 2.4 完整ISL循环（算法流程）
1. **初始化（Iteration 0）**：在仅含标注数据D_L上训练种子模型M₀，训练E_seed=100 epochs（遵循ASR领域协议）。
2. **伪标注**：冻结当前模型Mᵢ，用Invert-Classify对无标注数据D_U生成伪标签Ŷ，构成伪标注数据集D_PL。
3. **联合训练**：在D_comb = D_L ∪ D_PL上继续训练模型。
4. **循环**：更新后的模型Mᵢ₊₁被冻结，重复步骤2-3共I次迭代。

### 2.5 训练目标（公式）
```
L_Total = L_OT-CFM + λ_dur · L_dur + λ_enc · L_enc
```
该组合目标既用于训练，也用作反转损失。

### 2.6 匹配策略（Select-and-Retrain）
- 监控验证集上的伪标签准确率，选出最优迭代i*；
- 用D^(i*)_comb数据从随机初始化重新训练模型（1000 epochs），解耦"标签质量改善"与"迭代过程中的模型状态累积"。

### 2.7 模型与数据配置
- **骨干模型**：Matcha-TTS（OT-CFM flow matching，无需外部对齐工具，内部通过MAS学习对齐），从零训练，轻量可复现。
- **词级重音**：<PROM>/<NOTPROM>标记插入phoneme token边界处，使用独立嵌入表。
- **语句级情感**：将情感类别嵌入拼接到text encoder输出。
- **训练超参数**：Adam优化器，学习率4×10⁻⁴，batch size 32，梯度裁剪5.0。

## 6. 主要结论与发现

1. **迭代有效性**：ISL整体优于单遍伪标注基线，尤其在数据稀缺场景（如1%情感分割下伪标签F1相对提升超20%）。
2. **训练时长关键性**：50 epochs/迭代导致伪标签准确率显著退化（模型崩溃）；10 epochs/迭代是最稳健的折衷选择。
3. **任务依赖的动力学差异**：情感任务的性能提升集中在前1-2次迭代并快速饱和；重音任务需要更多迭代逐步累积提升。这与标注主观性和标签表征粒度有关。
4. **适用区间有界性**：0.5%极稀缺场景下提升有限（监督信号不足，无法启动自举）；20%充足标注时ISL收益消失甚至退化；**ISL在"足够初始化但标签仍稀缺"的中间区间最有效**。
5. **伪标签准确率→下游可控性的迁移**：伪标签准确率的提升确实转化为更好的标签遵循度和合成质量（客观指标和主观听感均证实）。在0.5%重音和5%情感条件下，ISL模型在主观测试中被显著偏好（胜率0.633-0.678）。
6. **尚未超越全监督**：在情感任务中，100% GT参考模型仍被偏好（0.633±0.042），但在重音任务中ISL与全监督打平（0.629±0.132）；ISL是逼近而非超越全监督上限的方向，是最低数据条件下的有效手段。

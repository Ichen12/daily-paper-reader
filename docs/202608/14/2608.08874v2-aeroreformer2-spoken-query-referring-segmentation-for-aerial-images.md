## 摘要
语音提供了一种自然、免提的接口，用于在密集的遥感图像中指定任意目标，然而现有的遥感图像指代分割基准仅接受书面表达。为弥合这一差距，我们引入了 \dataset，一个源自 RISBench 的语音查询基准，它在保留原始图像、掩码和数据划分的同时增加了口音和声音多样化的语音。其困难评估集结合了转子、风力和混合干扰，并设置了三种信噪比水平。我们还提出了 \model，一种高效的双边网络，它结合了边界保持的视觉路径与令牌保持的语音编码、核线性跨模态注意力以及分辨率细化头。该设计在不对密集语音-视觉亲和矩阵进行具体化的情况下，在两种尺度上条件化视觉特征，然后利用高分辨率视觉特征恢复精细边界。在干净测试集上，采用 Swin-Base 的 \model 实现了 62.09% 的平均交并比（mIoU）和 68.22% 的整体交并比（oIoU），分别比最强的音频适应遥感基线高出 5.38 和 2.08 个百分点。它在困难集上仍保持最佳 mIoU，为 54.09%。据我们所知，这是针对遥感图像的完整句子语音查询指代分割的首个基准和模型研究。代码将公开发布。

## Abstract
Spoken language offers a natural, hands-free interface for specifying an arbitrary target in dense remote-sensing imagery, yet existing referring remote-sensing image segmentation benchmarks accept only written expressions. To bridge this gap, we introduce \dataset, a spoken-query benchmark derived from RISBench that adds accent- and voice-diverse speech while preserving the original image, mask, and data splits. Its hard evaluation sets combine rotor, wind, and mixed interference with three signal-to-noise levels. We also propose \model, an efficient bilateral network that combines a boundary-preserving visual path with token-preserving speech encoding, kernel linear cross-modal attention, and a resolution refinement head. The design conditions visual features at two scales without materializing a dense speech--visual affinity matrix, then restores fine boundaries using high-resolution visual features. On the clean test split, \model with Swin-Base achieves 62.09\% mean intersection over union (mIoU) and 68.22\% overall intersection over union (oIoU), outperforming the strongest audio-adapted remote-sensing baseline by 5.38 and 2.08 percentage points, respectively. It retains the best hard-set mIoU at 54.09\%. To the best of our knowledge, this is the first benchmark and model study of full-sentence spoken-query referring segmentation for remote-sensing imagery. The code will be made publicly available.

## 2. 方法论

### 2.1 数据集构建（VoiceAeroRef）
- **来源**：基于 RISBench（由 DOTA-v2 和 DIOR 拼合而成，共52,472个三元组），剔除6个只含句号的无意义表达式后得到 **52,466个可用三元组**。
- **语音合成**：使用8个神经TTS声音，构成 **4×2 口音–性别** 因子设计（美式/英式/澳式/印度英语 × 女声/男声），输出16kHz单声道WAV文件。
- **训练集采样**：每个源描述配8个语音候选，但每个epoch只从中随机抽取1个（式2），避免视觉掩码被8倍过采样；保持每epoch 26,294个有效样本。
- **验证/测试集**：每类声音均衡分配单一干净语音。
- **硬评估集**：仅对测试集构造9种干扰条件——3种干扰类型（转子噪声、风声、0.6/0.4混合）× 3个名义SNR（15、7.5、0 dB），每个SNR带±1.5 dB随机扰动；每个源样本出现一次，不将评估集扩为9倍。

### 2.2 模型架构（AeroReformer2）

**核心设计原则**：双边（bilateral）效率原则 + token保持的语音编码 + 核线性注意力 + 高分辨率细化。

**整体流程**：
1. **视觉编码**：上下文路径（ResNet-101 或 Swin-Base）提取 1/4、1/8、1/16、1/32 分层的特征；细节路径保留1/8分辨率的边界信息；1/32处使用核线性自注意力（VKA）获取全局上下文。
2. **语音编码**：wav2vec 2.0（冻结）将波形转为 token 序列 A = [a₁,…,a_T] ∈ R^{T×D_a}，不做句子级池化。
3. **CGTM（Confidence-Gated Token Memory）**：对每个语音token预测置信度权重 g_t（式3），权重进入后续所有融合统计量，同时通过全局 FiLM 分支（式4）调制视觉特征。g_t 是学习到的"token对分割任务有用性"度量，并非概率。
4. **SV-KLA（Speech-Visual Kernel Linear Attention）**：使用正特征图 ϕ(x)=ELU(x)+1（式5），先累加固定大小的语音充分统计量 S 和 z（式6），再对每个视觉query做关联归一化（式7）。**关键优势**：不构建 N×T 亲和矩阵，复杂度从 O(NTd) 降为 O((N+T)d²)。
5. **双尺度路由**：1/16处SV-KLA做粗语义定位 → 上采样加到1/8上下文特征 → 1/8处第二个SV-KLA做精细定位 → 与细节路径融合 → VKA全局细化（式8–11）→ 1/4细化头融合骨干上下文、上采样语义特征和细节路径特征（式12–14）。
6. **损失函数**：BCE + soft Dice（式15）。

## 3. 实验设计

### 3.1 数据集与基准
- **主数据集**：\dataset（语音版RISBench），图像统一缩放至352×352，音频截断至8秒。
- **测试集**：干净测试集（16,159样本）+ 硬测试集（9种干扰条件下各1,795–1,796个样本）。
- **评估指标**：mIoU、oIoU、Pr@τ（τ ∈ {0.5, 0.6, 0.7, 0.8, 0.9}），掩码阈值0.5。

### 3.2 对比方法
- **传统分割基线**：Audio U-Net（FiLM瓶颈）、Audio FCN-ResNet101、Audio DeepLabV3-ResNet101（均用池化音频FiLM调节）。
- **音频适配的RRSIS模型**：FIANet、SBANet、STDNet、LSCF——将原文中的文本token替换为共享的wav2vec 2.0语音token（明确标注为"adapter"而非原文数字）。
- **自身变体**：AeroReformer2-ResNet101（骨干控制）、AeroReformer2-Swin-B（主模型）。

### 3.3 训练设置
- 40 epochs、AdamW、batch size 8、weight decay 1e-4、余弦退火、AMP、梯度裁剪1.0。
- 新初始化的音频融合与解码器参数 lr=2e-4；Swin-B 预训练骨干 lr=2e-5；按验证mIoU选模型；测试在512×512下生成掩码。

## 6. 主要结论与发现

1. **性能领先**：AeroReformer2-Swin-B 在干净测试集上 mIoU 62.09%、oIoU 68.22%，比最强非本文方法（LSCF适配器）分别高 **5.38 和 2.08 个百分点**；在硬测试集上 mIoU 54.09%，高 **5.63 个百分点**（oIoU上比SBANet高1.86）。
2. **高重叠区间优势明显**：Pr@0.8/0.9 分别比LSCF高6.48/5.30个百分点，说明1/4细化头对边界质量贡献大。
3. **组件贡献排序**（消融）：post-fusion KLA 最关键（移除降4.50 mIoU）→ 1/32视觉KLA（降1.01）→ 置信门（降0.27，但在Pr@0.9上降1.29，对高严格阈值更重要）。
4. **效率优势**：在5个Swin-B方法中参数最少、峰值内存最低；比LSCF快10.9%、轻13.7%；SV-KLA在352分辨率下亲和状态缩减 **1,890.62×**，注意力核心算力降 **37.58×**。
5. **噪声鲁棒性**：9个条件下全部第一，但所有方法在0 dB高干扰下显著退化——声学干扰仍是实质瓶颈。
6. **定性发现**：本文方法能正确利用关系性短语（如"partially visible at the lower edge"、"slightly left from the center"）和远距离方向词（"far left side of the waterfront"）来定位目标，而对比方法常被显著干扰物吸引。

## 7. 优点

- **填补空白**：首个将**全句子口语查询**引入遥感指代分割的研究，兼具基准和模型双重贡献。
- **数据设计合理**：训练集同源样本每次epoch换声（式2），在保留视觉统计规模的同时实现说话人增强；验证/测试集单声且类别均衡；硬评估不与训练分布重合。
- **效率与精度兼顾**：SV-KLA 将 O(NT) 亲和矩阵替换为 d×d 充分统计量，理论清晰且实测内存更低；双尺度路由将跨模态注意力限制在1/16和1/8，1/4细化头只在视觉域内操作。
- **双向消融设计**：既做组件消融，也做 ResNet-101 vs Swin-Base 骨干控制；对比方法统一为"audio-adapted"协议，避免不公平挪用原文结果。
- **语言统计扎实**：对词长、线索类别（位置/方向73.4%、尺寸43.8%）、指代语义族分布做了全面分析，为token级保留而非句子池化提供了实证依据。
- **诚实声明**：明确区分解析性注意力复杂度和端到端延迟，不夸大线性注意力的实际速度优势。

## 8. 不足与局限

- **真实语音缺失**：语音全部由TTS合成，口音/性别多样性是"受控模拟"而非真实人类语音；无法反映自然语音中的犹豫、连读、方言变异、发音错误等。
- **噪声合成简化**：转子/风声是本地合成的参数化模型，未使用真实录音，也未建模麦克风传输函数、房间混响、无线电通道等真实链路。
- **评估语言单一**：仅英语，未覆盖多语言/代码混合命令；仅8个TTS声音，说话人多样性范围有限。
- **缺少流式支持**：音频被整体截断至8秒后离线处理，不适用于低延迟在线掩码生成。
- **硬集评估存在不对称**：训练集干净、硬集只对测试集构造，模型无法学习噪声鲁棒性（但有意识地模拟了"部署环境噪声"这一真实场景）。
- **消融覆盖率不足**：缺少1/4细化头、CGTM在硬噪声集的独立消融；confidence gate在硬集上的作用被明确声明"不可归因"。
- **训练成本未披露**：未说明完整训练运行的GPU时长、额外算力消耗及对应的碳排放/能耗。
- **单一数据源**：仅基于RISBench，跨数据集泛化性（如NWPU-Refer、RefSegRS）未验证；模型在上百亿像素的真实业务流中的表现仍未知。
- **计算效率的适用范围**：分析性复杂度对比（表9）仅覆盖注意力核心，不包括投影、激活等；作者也承认在特定张量形状下优化过的softmax kernel可能更快，线性注意力的优势主要体现在内存占用而非端到端延迟。

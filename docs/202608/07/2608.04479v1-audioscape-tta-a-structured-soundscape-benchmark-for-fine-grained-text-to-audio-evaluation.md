## 摘要
文本到音频（TTA）生成近年来在从自然语言描述合成逼真音频方面取得了显著进展。然而，确定生成的音频是否忠实满足复杂的文本指令仍然具有挑战性。现有基准主要依赖全局相似性指标，对细粒度语义失败的洞察有限。为解决这一局限性，我们引入了 \textbf{AudioScape-TTA}，一个结构化且复杂度感知的细粒度TTA评估基准。AudioScape-TTA通过模态感知的语义结构表示真实音景，并利用事件密度和结构复杂性来表征生成复杂度。基于这些标注，我们提出了一种基于评分标准的音频接地评估框架，通过细粒度语义标准验证事件实现、声学属性和语音内容。该基准包含2,258个音频-文本对，配有25,707个二元问答评分标准，支持对TTA系统进行可扩展且可解释的分析。对13个代表性开源TTA模型的实验揭示了在细粒度属性控制、语音内容保留和组合音景生成方面的持续局限性。人工验证进一步表明，与传统的全局相似性指标相比，我们基于评分标准的评估与人类语义判断的一致性更强。

## Abstract
Text-to-audio (TTA) generation has recently achieved remarkable progress in synthesizing realistic audio from natural language descriptions. However, determining whether generated audio faithfully satisfies complex textual instructions remains challenging. Existing benchmarks mainly rely on global similarity metrics, providing limited insight into fine-grained semantic failures. To address this limitation, we introduce \textbf{AudioScape-TTA}, a structured and complexity-aware benchmark for fine-grained TTA evaluation. AudioScape-TTA represents realistic soundscapes through modality-aware semantic structures and characterizes generation complexity using event density and structural complexity. Based on these annotations, we propose a rubric-based audio-grounded evaluation framework that verifies event realization, acoustic attributes, and speech content through fine-grained semantic criteria. The benchmark contains 2,258 audio-text pairs with 25,707 binary QA rubrics, enabling scalable and interpretable analysis of TTA systems. Experiments on 13 representative open-source TTA models reveal persistent limitations in fine-grained attribute control, speech-content preservation, and compositional soundscape generation. Human validation further demonstrates that our rubric-based evaluation achieves stronger alignment with human semantic judgments than conventional global similarity metrics.

- **核心问题**：
  1. 现有基准缺乏对真实、结构化、组合性音景的统一表示，往往只提供粗粒度的自由文本描述，将语音当作普通音频事件，而忽略了语音内容（具体话语）的约束。
  2. 现有评估标准通常只给出全局相似度结果，无法刻画样本级复杂度差异，难以分析“指令遵循能力随音景复杂度提高而如何变化”。

- **整体思路**：为弥补上述缺口，论文提出 **AudioScape-TTA**——一个结构化（structured）、复杂度感知（complexity-aware）的细粒度 TTA 基准与评估框架，将真实音景表示为模态感知的语义结构，并利用基于评分标准（rubric）的音频接地评估进行细粒度验证。

## 2. 论文提出的方法论

### 2.1 总体框架

AudioScape-TTA 由两个核心部分组成：

1. **结构化音景基准**：将真实音频场景显式标注为场景、背景音乐（BGM）、音效（SFX）和语音（Speech）等组件，并用事件密度和结构复杂度刻画样本生成难度；
2. **基于 rubric 的音频接地评估系统**：将结构化描述自动转化为二值语义验证规则（QA），对生成音频逐条判定语义要求是否被满足，再进行层次化分数聚合。

### 2.2 结构化音景表示

- 每个样本表示为：
  - **Scene（场景）**：整体声学环境或语境；
  - **Background Music（BGM）**：乐器、风格、情绪等音乐属性；
  - **Sound Effects（SFX）**：离散声音事件与环境动作；
  - **Speech（语音）**：说话内容、说话人相关属性。
- 数据构建流程：影视音轨切分 → 关键词检索候选片段 → LLM 辅助生成初始结构化标注与描述 → 人工审核与修正（人工为最终权威）→ 得到最终 2,258 个样本、25,707 条语义 rubric。

### 2.3 复杂度感知刻画

复杂度由两个互补维度组成：

- **事件密度（Event Density）**：衡量片段声学内容的“量”：
  \[
  \text{Density} = N_{\text{SFX}} + N_{\text{Speech}} + N_{\text{BGM}}
  \]
  其中 \(N_{\text{SFX}}\) 为离散音效事件实例数（重复出现单独计数），语音和 BGM 因属于持续层/背景层，仅用 0/1 表示是否出现。
- **结构复杂度（Structural Complexity）**：衡量活动音频类别的多样性与片段级组合模式：
  \[
  \text{Structure\_Score} = S_{\text{modality}} + S_{\text{cooccur}}
  \]
  其中 \(S_{\text{modality}}\) 为活动模态数（Speech、SFX、BGM），\(S_{\text{cooccur}} = \mathbb{1}[\text{Speech} \land (\text{SFX} \lor \text{BGM})]\)，即语音与非语音成分共同出现时增加复杂度。
- 两个维度分别 z-score 归一化后相加得到总复杂度分数：
  \[
  C = Z(\text{Density}) + Z(\text{Structure\_Score})
  \]
  并按阈值划分 Easy（\(C \le -1\)）、Medium（\(-1 < C < 1\)）、Hard（\(C \ge 1\)）。
- 数据中密度与结构分数相关性很弱（Pearson r = 0.221、Spearman ρ = 0.153），说明二者确实刻画了互补的复杂度维度。

### 2.4 基于 rubric 的音频接地评估

- **结构化 rubric 构建**：使用 LLM 将结构化描述提取为“样本 → 模态 → 事件 → 属性”层次；基准构建时即生成三类固定二值规则：
  1. **事件存在（Event Presence）**：目标声音事件是否出现；
  2. **事件属性（Event Attribute）**：事件是否满足指定声学属性（如音源、材质、强度、时态、乐器、情绪、说话人身份等）；
  3. **语音内容（Speech Content）**：合成语音是否保留目标话语内容。
- **音频接地验证**：
  - 事件存在、事件属性由 **Qwen3-Omni-Instruct** 进行二分验证；
  - 语音内容由 **Qwen3-ASR** 转写后与目标文本做“混合单元覆盖率”匹配。
- **语音内容指标**：
  - 混合单元覆盖率 \(R_{\text{mixed}}\) 基于裁剪计数匹配（clipped-count matching），对英文单词与中文汉字单元分别计数后汇总，与顺序无关；
  - 定义 **SCCA@τ**（Speech Content Coverage Satisfaction Rate at threshold τ），当 \(R_{\text{mixed}} \ge \tau\) 时认为该 rubric 满足；主报告取 τ = 0.60。
- **分数聚合**：Overall SR、Event SR、Attribute SR 均为对应 rubric 集合上的微平均满足率（Satisfaction Rate, SR），并可按模态、复杂度、组合类型等子集分层统计。

## 3. 实验设计

### 3.1 Benchmark 与数据

- 基准即 **AudioScape-TTA**：2,258 个音频-文本对、25,707 条二值 QA rubric，平均音频时长约 9.95 秒，平均标注 32.45 词，平均约 4 个语义事件。
- 语音相关统计：358 个片段含语音标注（占 15.85%），其中 83 个片段带目标话语，语音内容 rubric 163 条，语音属性 rubric 931 条。
- 来源：从影视剧音轨中提取的真实音景，覆盖音效、音乐、语音及多模态组合；与既有基准（AudioCaps、Clotho、AudioTime、RiTTA、TTA-Bench 等）相比，只有 AudioScape-TTA 同时支持结构化 schema、语音内容、语义诊断和复杂度感知评估。

### 3.2 评估模型

对 **13 个开源 TTA 模型** 进行了评测，覆盖多种生成范式：

- 潜在扩散/扩散模型：AudioLDM 2、Make-An-Audio 2、Tango 2、Stable Audio Open、EzAudio
- 流匹配模型：TangoFlux、MMAudio、Foley-Omni
- 自回归/非自回归 token 模型：AudioGen、MAGNeT、Dasheng AudioGen
- 统一多模态系统：Omni2Sound、AudioStory

### 3.3 评估指标

- 细粒度语义：Overall SR、Event SR、Attribute SR、SCCA@0.60，并按模态/复杂度/QA 类型/模态组合分层分析；
- 常规全局质量：CLAP 文本-音频对齐分数（CLAP_MS）、FAD、KL、ISC、Audiobox-Aesthetic（CE/CU/PC/PQ）及 WER/CER 转写诊断；
- 用户研究：随机选 10 条提示 × 13 模型 = 130 个样本，由 26 名参与者在事件完整性、属性满足率、音频质量三个维度进行 5 点李克特量表打分。

### 3.4 控制与鲁棒性实验

- 音频掩码/音频打乱对照：表明 rubric 判定依赖真实且正确配对的音频证据，而非问题格式；
- 评估器能力检查：使用 Gemini-2.5-Pro 在参考音频上达到 95.03% Overall SR，高于 Qwen3-Omni 的 84.88%，说明评估器能力会影响上限；

- 语音阈值敏感性：SCCA 阈值在 0.40–0.80 范围内，Dasheng AudioGen 和 Foley-Omni 始终为前两名。

## 6. 论文的主要结论与发现

1. **属性控制明显弱于事件生成**：所有模型中事件属性满足率普遍低于事件存在满足率，说明“生成出目标事件”比“精确控制事件声学属性”容易得多。
2. **语音内容保留是当前 TTA 的突出短板**：除 Foley-Omni（57.06%）和 Dasheng AudioGen（77.30%）外，其余 11 个模型在 SCCA@0.60 上均为 0%，即很多系统能生成“像语音”的声音，却无法保留可验证的语言内容。
3. **全局相似度 ≠ 细粒度语义遵循**：MMAudio 的 CLAP_MS 最高（0.5169），但语义满足率仅 64.73%；Foley-Omni 语义满足率最高，CLAP 排名却不高。二者反映互补能力。
4. **复杂度越高，性能下降越明显**：多数模型的满足率在 Medium/Hard 子集上显著下降，Foley-Omni 在 Hard 子集上鲁棒性最强；组合性音景（尤其语音+音效+音乐）是当前系统的普遍难点。
5. **与人类判断的一致性**：Overall SR 与复合人类语义分数呈强相关（Spearman ρ = 0.879），显著优于 CLAP_MS（ρ = 0.312），表明 rubric 式评估更能反映人类感知的指令遵循程度。

## 7. 优点

- **结构化表示创新**：将真实音景统一表示为 Scene/SFX/BGM/Speech 的层级结构，弥补了自由文本描述无法显式承载多组件语义的不足。
- **复杂度感知设计**：通过事件密度 + 结构复杂度双维度刻画难度，并给出 Easy/Medium/Hard 划分，能系统分析模型在声景复杂度上升时的鲁棒性变化。
- **rubric 评估可解释、可审计**：每条规则是固定二值问答，答案基于人工确认的标注，所有模型共用同一套标准；能逐条定位“事件缺失 / 属性不符 / 语音错误”等语义失败。
- **语音内容专门评估**：Qwen3-ASR 转写 + 混合单元覆盖率，支持中英混说、对顺序不敏感，并经过阈值敏感性分析，不把语音简单当作普通音效。
- **评估体系严谨性**：进行了掩码/打乱对照、答案位置平衡、评估器能力对比、正负样例鉴别力测试，排除了“盲目答 Yes”和选项顺序偏差等干扰；同时采用人工审核最终标注，保证数据质量。

## 8. 不足与局限

- **语音样本占比偏低**：358 个语音片段仅占 15.85%，语音内容 rubric 仅 163 条；虽能揭示“大多数模型为零分”的明显痛点，但不足以对语音生成模型做细致排名。
- **复杂度定义有边界**：论文也承认，复杂度只刻画“事件数量 + 模态类别组合”，未显式建模事件间的时序顺序、因果依赖、空间关系

（接上）——未显式建模事件间的时序顺序、因果依赖、空间关系，也未涵盖声源距离、混响、运动轨迹等声学空间属性；因此“Hard”样本的界定仍偏重成分叠加，而非结构叙事复杂性。

- **复杂度划分依赖相对阈值**：Easy/Medium/Hard 基于当前 2,258 个样本分布的 z-score 阈值（±1）划分，具有语料相对性；迁移到其他分布（如音乐为主、语音为主）的语料时，绝对难度含义可能发生变化。
- **rubric 来源与容错有限**：25,707 条 rubric 由 LLM 辅助生成并人工审核，但部分属性描述（如“阴森”“轻快”“紧张”）语义边界模糊，不同标注者对电影音效的风格判断可能存在分歧；评估器对这类主观属性的判定一致性未逐条量化。
- **评估资源与泛化性**：音频接地判定依赖 Qwen3-Omni-Instruct 的内部先验，参考音频上仅 84.88% Overall SR，说明评估器本身仍会漏判或误判；未来若更换更强评估器，模型绝对分数可能整体上移。
- **数据集规模与领域单一**：2,258 个样本全部来自影视剧音轨，领域集中于电影音效、配乐与对白，对音乐生成、播客、游戏音频等场景的代表性有限；人工标注成本也限制了其扩展速度。
- **只对“生成结果是否满足提示”做合规判断**，未对“未出现在提示中但被模型脑补的额外内容”进行惩戒式检测；一个模型可能通过大量冗余音效“覆盖”关键事件而获得较高 SR，反而不利于忠实性评价。

## 9. 对研究领域的启示与展望

- **评估范式从“相似度”走向“语义满足”**：AudioScape-TTA 证明，rubric 式细粒度评估与人类指令遵循判断高度相关（ρ = 0.879），而全局 CLAP 对齐仅 0.312；这为 TTA 社区提供了可复用的“逐条目可审计”评估思路，也为多模态生成模型的评测体系（如 T2I、T2V 的细粒度基准）提供了参照。
- **语音与其他模态应分而治之**：实验表明语音内容保留是当前 TTA 模型最薄弱环节，而多数系统的失败不是因为“没生成语音”，而是因为没有转录出目标话语。这提示未来 TTA 架构需要考虑显式语音内容条件（如将文本/韵律 token 与音频 token 联合建模），而非把语音事件当作普通音效采样。
- **复杂度感知分析应成为基准标配**：事件密度与结构复杂度正交（相关性仅约 0.15–0.22），能有效暴露模型在不同难度层级上的退化模式；未来基准可以进一步加入时序关系模板、空间声场模板、事件因果链等更细粒度结构单元。
- **评估器能力、采样方差与成本需一起标准化**：报告显示评估器选择对绝对分数影响显著（Gemini 与 Qwen3 相差约 10 个百分点），但相对排序较稳定；建议后续基准发布时同时提供“参考音频校准分”和“轻量级评估器 + 强评估器”两级方案，并在论文中要求报告多次采样均值与标准差。

## 10. 总体评价

AudioScape-TTA 是文本到音频评估领域一项结构扎实、方法完整、结论清晰的基准工作。它的核心贡献不在于提出新的生成模型，而在于把“真实音景的多组件结构”和“细粒度指令遵循验证”第一次系统性地纳入同一框架：既给出了带有人工审核的结构化标注语料，又设计了复杂度感知划分和基于 rubric 的自动接地判定，还通过大规模模型评测与用户研究验证了该评估体系的有效性和解释力。

其主要局限集中在数据规模与领域单一、复杂度刻画未触及时序与空间关系、语音样本偏少以及评估器能力上限等方面。但这些不足更多属于“工程扩展与后续迭代”的问题，而非方法论缺陷。整体而言，这项工作对 TTA 基准设计、语音感知式音频生成评估以及多模态细粒度评测都有较强的参考价值，可以作为该方向后续研究的基线框架。

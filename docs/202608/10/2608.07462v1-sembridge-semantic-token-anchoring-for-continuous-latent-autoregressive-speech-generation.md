## 摘要
连续潜在自回归语音生成已成为离散标记建模的一种有前景的替代方案，它避免了量化损失并保留了更丰富的声学信息。然而，连续声学目标并未将语言结构暴露为显式的标记级预测目标。因此，自回归语言模型（LM）必须通过声学预测间接获取语言结构，这可能损害生成语音的内容保真度。我们提出了SemBridge，一种仅用于训练的语义标记锚定框架，用于连续潜在自回归语音生成。SemBridge使用离散语义标记直接监督自回归LM状态，并采用语义对齐声学变分自编码器（Semantic-Aligned Acoustic VAE）在相同语义参考下组织连续目标空间。语义监督仅在训练期间使用，而推理过程完全保持连续。我们在零样本文本到语音（TTS）和乐谱条件歌声合成（SVS）上评估了SemBridge。在多个基准测试中，SemBridge提高了内容准确性（以词错误率和字符错误率（WER/CER）衡量），同时保持了具有竞争力的说话人相似度和感知质量。实验结果表明，显式语义标记监督用于自回归状态学习是连续语音生成的一个有效且通用的方向。语音样本可获取。1 模型代码和检查点将在 https://github.com/ASLP-lab/SemBridge 提供

## Abstract
Continuous-latent autoregressive speech generation has emerged as a promising alternative to discrete-token modeling by avoiding quantization loss and preserving richer acoustic information. However, continuous acoustic targets do not ex- pose linguistic structure as explicit token-level prediction tar- gets. Consequently, the autoregressive language model (LM) must acquire linguistic structure indirectly through acous- tic prediction, which can compromise the content fidelity of generated speech. We propose SemBridge, a training-only semantic-token anchoring framework for continuous-latent autoregressive speech generation. SemBridge uses discrete se- mantic tokens to directly supervise autoregressive LM states and employs a Semantic-Aligned Acoustic VAE to organize the continuous target space under the same semantic refer- ence. The semantic supervision is used only during train- ing, while inference remains entirely continuous. We evalu- ate SemBridge on zero-shot text-to-speech (TTS) and score- conditioned singing voice synthesis (SVS). Across multi- ple benchmarks, SemBridge improves content accuracy, as measured by word and character error rates (WER/CER), while maintaining competitive speaker similarity and percep- tual quality. Experimental results demonstrate that explicit semantic-token supervision for autoregressive state learning is an effective and general direction for continuous speech generation. Speech samples are available.1 The model code and checkpoints will be available at https://github.com/ASLP- lab/SemBridge

## 1. 核心问题与研究动机

- **研究背景**：自回归（AR）语音生成模型经历了从离散标记建模到连续潜在建模的范式演进。离散标记方案（如 VALL-E、CosyVoice、Seed-TTS 等）将语音表示为离散 token 序列，但量化过程会引入信息瓶颈，损失细粒度声学细节。连续潜在方案（如 MELLE、DiTAR、VibeVoice 等）直接建模 mel 谱或学习的连续声学潜在表示，避免量化损失，保留更丰富的声学信息，正成为高保真语音合成的有前途方向。
- **核心问题**：连续声学目标虽然在隐式层面编码了语言内容，但不像离散语义标记那样在每一步提供显式的"下一标记"预测目标。因此，自回归 LM 必须通过连续生成目标**间接**推断语言结构，导致生成语音的内容保真度（content fidelity）不足，具体表现为字/词错误率（CER/WER）偏高。
- **现有方案的不足**：
  - 已有方法（如 SemaVoice、MELA-TTS）主要用连续语义特征做特征对齐，但连续特征中混有与语言无关的说话人、韵律等变异，语义监督不够聚焦。
  - 半离散方法（如 VoxCPM）虽然引入显式语义分支，但改变了原始连续生成接口，推理时仍需额外的语义建模组件。
  - 利用**离散语义标记**显式监督连续潜在自回归状态这一方向尚属空白。

## 2. 方法论

### 2.1 核心思想

SemBridge 的核心是**仅训练阶段的语义标记锚定（semantic-token anchoring）**：在训练时用离散语义 token 标签直接监督自回归 LM 的隐状态；推理时完全不依赖离散标记，保持纯连续生成。同时搭配一个**语义对齐声学 VAE（Semantic-Aligned Acoustic VAE, SA-VAE）**，在连续目标空间组织语义结构。

### 2.2 整体框架与技术细节

**（1）共享语义参考：冻结的 GLM-4 语义 tokenizer**

- 使用开源 GLM-4 tokenizer，工作频率为 12.5 Hz，词表大小为 16,384。
- 对训练波形提取两类监督信号：
  - 连续语义嵌入 `e_t`：用于 SA-VAE 目标空间对齐。
  - 离散标记 ID `s_t`：用于 LM 状态锚定（分类目标）。

**（2）时间对齐与 patch 构造**

- SA-VAE 编码器产生 25 Hz 的连续声学潜在帧，每两帧拼接为一个声学 patch，得到 12.5 Hz 的 patch 序列。
- 由此形成一一对应关系：`z_t ↔ (e_t, s_t)`——每个连续 patch 在训练时对应一个语义嵌入和一个离散标记。

**（3）阶段 I：SA-VAE 训练**

- 保留连续高斯 VAE 结构（无矢量量化），不设离散瓶颈。
- 目标函数：`L_SA-VAE = L_VAE + λ_align * L_align`。
- 对齐损失 `L_align` 将声学 patch 经轻量投影后与冻结语义嵌入做余弦对齐加弱 L1 约束。
- 目标：不牺牲重构质量前提下提升连续声学目标空间的语义结构化程度。

**（4）阶段 II：连续自回归生成器训练**

- 架构沿用 PatchEnc – 因果 LM – LocDiT（局部扩散 Transformer）的连续自回归框架。
- 因果 LM 共 32 层 Transformer，最终层状态 `h_t^(L)` 经 RMSNorm 后作为全局条件，联合前一个 patch 输入 LocDiT，用 flow matching 生成下一个连续 patch。
- **语义锚定**：在选定的 Transformer 层 ℓ\* 后接轻量语义分类头 `f_φ`，对状态 `h_t^(ℓ\*)` 做离散 token 分类：
  - `L_sem = -1/|T| Σ log q_φ(s_t | h_t^(ℓ\*))`
  - 因果对齐保证该状态只能看到符号条件、prompt 上下文和先前 patch，看不到目标 patch 或目标语义标签。
- 联合训练目标：`L_gen = L_FM + λ_sem * L_sem + λ_stop * L_stop`，默认 `λ_sem = 0.1`。
- 同一 LM 状态同时支持互补的双重预测：最终层状态 → 连续 patch `z_t`；锚定层状态 → 离散语义标记 `s_t`。

**（5）纯连续推理**

- 推理时移除语义头和 SA-VAE 对齐投影，不输入任何离散标记。
- 生成路径完全为连续的 PatchEnc–LM–LocDiT 链路，离散标记只改变**训练方式**，不改变**生成接口**。

## 6. 主要结论与发现

1. **SemBridge 显著提升内容保真度**：在零样本 TTS 上，CER/WER 在多个中英文子集上取得一致降低；系统级模型在 Seed-TTS-Eval 中文 CER 达 0.95，英文 WER 达 1.81。在 SVS 上，中英文歌词错误率同样下降，说明语义锚定可跨任务迁移。
2. **状态级锚定是主要收益来源**：在受控消融中，单独加入锚定将 ZH/EN/ZH-Hard 的 CER/WER 从 1.58/2.43/16.87 降至 1.21/2.18/13.97；目标空间对齐单独仅降至 1.51/2.30/15.94；两者联合最优（1.01/1.87/11.87）。表明离散标记显式监督的增益大于连续特征对齐。
3. **锚定深度存在内容-质量权衡**：Anchor@32 内容错误最低，Anchor@24 在说话人相似度和 UTMOS 上更优，因此系统级模型采用 Anchor@24 以取得平衡。
4. **锚定强度不宜过大**：λ_sem = 0.1 最优；过大的 λ_sem 会破坏内容、相似度和感知质量，说明语义监督应"正则化"而非"主导"连续生成目标。
5. **SA-VAE 不牺牲重构质量**：语义对齐对重构指标影响极小（PESQ 2.99 vs 3.00），但显著提升潜在空间的类别结构（线性探针精度从 61.50% 提升至 82.00%，5-NN 从 42.25% 提升至 67.00%）。
6. **离散 token 分类优于连续嵌入回归**：在相同条件下，token-ID 分类的 CER/WER 相对降低了 15.5–23.6%（对比最优连续回归配置），表明类别化目标提供的语义约束更有效。
7. **语义锚定加速收敛**：40K 步锚定模型的 WER 已接近无锚定模型 100K 步的水平，全程每个 checkpoint 均优于无锚定模型。

## 7. 方法优点

- **训练-推理解耦，零推理开销**：语义分支（语义头、对齐投影）只在训练时使用，推理完全保持纯连续链路，不改变生成接口，不引入额外计算。
- **共享语义参考的协同设计**：连续嵌入对齐目标空间 + 离散标记锚定状态空间，同一冻结 tokenizer 提供两种互补监督，从"预测什么"和"如何预测"两个层面注入语义结构。
- **显式类别目标的信息聚焦优势**：相比连续特征对齐要求状态"复现"完整教师特征几何，离散 token 分类只要求状态能被线性分类器区分，抑制了与语言无关的因素，监督信号更聚焦。
- **通用性与迁移性**：不限于 TTS，可迁移至乐谱条件歌声合成，展示了对更复杂生成条件的适应性。
- **方法论价值**：为连续潜在语音生成提供了一种新的训练策略视角——通过离散语义监督强化 AR 状态的语言建模能力，而不牺牲连续表示的声学表达力。
- **实验风格严谨**：区分受控诊断与系统级比较，充分披露数据来源与评估方式，消融逻辑清晰。

## 8. 不足与局限

- **依赖于单一冻结语义 tokenizer**：GLM-4 tokenizer 的时间粒度、词表规模和领域覆盖会直接影响语义监督质量；对 tokenizer 预训练阶段未充分覆盖的语言或风格，效果可能下降。
- **跨训练随机性未评估**：每种配置仅训练一次（固定种子），无法刻画不同随机初始化下的性能波动；仅评估了推理时采样变化。
- **自动指标不能完全替代人类评估**：UTMOS、SingMOS 等自动感知指标的直接推断力有限，论文缺少对人类听感偏好的直接测量。
- **系统级比较非完全匹配**：120K 小时模型同时改变了训练数据和任务组合，与外部系统（不同数据、不同规模）的比较存在混淆变量。
- **SVS 中 FFE 非最优**：语义锚定主要提升歌词建模和感知质量，音高准确性（FFE）不及部分基线，说明在耦合乐谱条件时仍有改进空间。
- **实际部署风险**：高保真语音生成可能被滥用于伪造声音，需注意数据许可、说话人同意和负责任使用；内部歌声数据因许可限制无法完全再分发。
- **实验规模限制**：受控实验在 100K 小时数据上进行，更大数据规模或更大模型下的收益是否保持尚未验证。

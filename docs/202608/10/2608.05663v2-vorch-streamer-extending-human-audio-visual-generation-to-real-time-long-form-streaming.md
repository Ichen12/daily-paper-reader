## 摘要
实时长时虚拟人物音视频生成要求因果、连续的合成，同时保持音视频同步和视觉一致性。将预训练的双向模型适配到该设置面临两个关键难题。首先，自回归地将已生成的块作为上下文复用会产生暴露偏差，导致在长序列生成过程中错误和视觉漂移不断累积。其次，当仅有有限的局部音视频上下文可用时，全局语音语句无法指示因果生成器接下来应说出哪一部分。我们提出了Vorch-Streamer，一个后训练框架，解决了这些挑战并实现了实时的长时文本到音视频（T2AV）流式生成。我们构建了一个包含8万个虚拟人物片段（时长12-21秒）的合成语料库，首先使用混合教师强制和扩散强制训练一个因果生成器。随后，我们应用带有DMD蒸馏的长时程自我强制，使模型暴露于其自身的生成分布，同时保持预训练双向教师模型的质量。为显式控制语音进度，一个外部语言模型预测离散的25赫兹语音规划标记，其连续特征条件化音频扩散分支，并使每个因果块与其应说的内容对齐。通过有界因果上下文和四步去噪，Vorch-Streamer以27.12 FPS的帧率从文本联合生成音频和视频，超过24 FPS的实时播放速率，同时在长时生成中保持竞争力的音唇同步和强身份保持。

## Abstract
Real-time long-form avatar audio-video generation requires causal, continuous synthesis while maintaining audiovisual synchronization and visual consistency. Adapting a pretrained bidirectional model to this setting presents two key dilemmas. First, autoregressively reusing generated blocks as context creates exposure bias, causing errors and visual drift to accumulate over long rollouts. Second, a global speech utterance does not indicates a causal generator which portion should be spoken next when only limited local audio-video context is available. We present Vorch-Streamer, a post-training framework that addresses these challenges and enables real-time long-form Text-to-Audio-Video (T2AV) streaming. We construct a synthetic corpus of 80K avatar clips spanning 12-21 seconds and first train a causal generator with mixed Teacher Forcing and Diffusion Forcing. We then apply long-horizon Self Forcing with DMD distillation, exposing the model to its own rollout distribution while preserving the quality of the pretrained bidirectional teacher. To explicitly control speech progression, an external language model predicts discrete 25-Hz speech-planning tokens, whose continuous features condition the audio diffusion branch and align each causal block with the content it should speak. With bounded causal context and four-step denoising, Vorch-Streamer jointly generates audio and video from text at 27.12 FPS, exceeding the 24-FPS real-time playback rate while maintaining competitive audio-lip synchronization and strong identity preservation over long-form generation.

## 1. 核心问题与研究动机

- **研究背景**：实时虚拟人物音视频生成在教育、娱乐、虚拟通信和交互式智能体等领域具有重要价值。现代音视频扩散模型已支持文本/图像/音频等多种条件生成，并能够同时合成自然语音与面部表情，但大多数模型面向短时、离线片段，采用双向注意力模式，假设去噪时完整序列可见。
- **核心矛盾**：将预训练双向模型适配到流式生成存在两个关键难题：
  1. **暴露偏差（Exposure Bias）**：流式生成需自回归地将自身预测结果作为后续块上下文，微小误差随时间累积，产生训练与推理分布不匹配，导致伪影、时间漂移和不稳定；
  2. **全局话语与因果生成的错配**：T2AV的文本提示描述整个话语，而因果生成器每个块只能访问有限的历史上下文，难以确定"当前应说哪部分"，尤其在完整转录不可预知或语音短段频繁切换时更为严重。

## 2. 方法论：Vorch-Streamer

### 2.1 核心思想

Vorch-Streamer将"向因果生成转换"与"向长时程生成转换"分离，通过三阶段后训练流程，将预训练的LTX2.3双向音视频基础模型转化为实时、长时、因果流式生成器，并引入显式LLM语音规划路径解决语音进度对齐问题。

### 2.2 三阶段训练流程

- **Stage 1：合成语料构建** — 使用预训练的LTX2.3生成80K个12-21秒的虚拟人物音视频片段（768×512分辨率、24 FPS），确保训练数据与初始化模型分布一致。
- **Stage 2：混合教师强制与扩散强制（Mixed TF/DF）** — 将音视频潜在表示划分为同步块（默认约1秒，含3个视频潜在帧和25个音频潜在token）；块内保持双向注意力，块间采用因果注意力，每个块关注前3个前缀块和最近3个块（`H_b = {0,1,2} ∪ {max(0,b-3),...,b-1}`）。训练时，10%样本历史序列保持干净（Teacher Forcing），90%样本历史序列被扰动（Diffusion Forcing），优化标准流匹配目标：  
  `L_CF = Σ λ_m ||v̂_m − (ε_m − x^m_0)||²₂`
- **Stage 3：长时程自我强制（Long-Horizon Self Forcing）+ DMD蒸馏** — 学生模型块接块地自回归生成12-21秒完整序列（基于自身预测和固定窗口KV缓存），直接暴露于推理时真实分布；冻结的双向LTX2.3作为真实分数模型，可训练的双向fake-score模型估计学生分布，二者之差构成DMD更新方向，学生优化代理损失：  
  `L_DMD = Σ (λ_m/2) ||x̃^m_0 − sg(x̃^m_0 − g_m)||²₂`  
  fake-score模型以标准流匹配损失独立更新。该阶段支持4步因果长时程去噪。

### 2.3 LLM语音规划模块

- 外部语音规划器（Fun-CosyVoice LLM）以25 Hz预测离散语音规划token（每个对应40ms规划单元），通过预训练查找表（LUT）和可学习投影转换为连续特征。
- 这些规划特征通过额外的语音交叉注意力注入音频扩散分支，仅允许音频token关注同一块内的规划特征，输出与原始文本条件音频特征经可学习门控融合：  
  `h_a^ℓ ← h_a^ℓ + sigmoid(g^ℓ)·Attn_speech^ℓ(h_a^ℓ, e_s)`
- 这种设计将"说什么/何时说"的规划与"如何音视频实现"解耦，支持语音中断、切换和可学习的静默token（silent listening），无需在流开始前确定完整未来话语。
- 训练中因果学生接收场景描述与对齐的语音规划token，而双向教师仍通过原始文本通道接收完整话语，形成非对称条件。

## 7. 方法亮点

1. **三阶段解耦设计**：将因果转换与长时程适应分离，避免单阶段训练的复杂性，使得每个阶段目标清晰、可独立验证。
2. **长时程自我强制**：训练过程与推理部署完全对齐（相同的固定窗口KV缓存和4步去噪），直接消除暴露偏差。
3. **DMD蒸馏**：在保持预训练双向教师质量的同时支持4步高效推理，生成器与fake-score交替更新使蒸馏方向持续有效。
4. **显式LLM语音规划**：将规划与生成解耦，有效解决因果T2AV中的"说什么/何时说"歧义，同时天然支持语音中断/切换和静默监听，为交互式应用奠定基础。
5. **有界因果上下文**：全局前缀块+近期块的组合在恒定内存下保持身份与场景锚定，实现了与序列长度无关的稳定流式生成。
6. **合成数据策略**：使用与初始化同源的模型生成训练语料，确保模型一致性监督。
7. **评估的严谨性**：区分T2AV与TIA2V任务等价性，详细的时间轨迹分析和端点变化报告避免短窗误导，95%置信区间的可视化增强结论可信度。

## 8. 不足与局限

1. **计算资源要求高**：训练需要64+32张H200 GPU，成本高昂，限制了方法的可复现性和普及性。
2. **依赖合成数据**：80K合成片段可能引入领域偏移，且高度依赖LTX2.3的生成质量上限。
3. **对比条件不完全公平**：OmniForcing和Hallo-Live仅评估30秒（因内存限制），JoyAI-Echo的某些定性表现（如手-物交互）展示了特定长项但总体分数不高；TIA2V参照需外部音频和首帧，虽然指出但未做任务等价的对照实验。
4. **质量指标的权衡**：FVD（549.99）和Dynamic Degree（0.2706）并非最优，低于JoyAI-Echo（354.85/0.0471但运动极低）和部分变体；Vorch-Streamer在追求稳定性的同时可能牺牲了部分生成多样性。完整模型FVD较无Stage 3变体更高（549.99 vs 442.99），这一质量代价未被充分讨论。
5. **Human Anatomy相对偏低**（0.9233，低于多数方法），论文对此未做深入分析。
6. **语音规划的适用边界**：规划器为Fun-CosyVoice LLM，语音切换/中断能力仅在设计上支持，无专门针对交互中断场景的量化评估。
7. **扩展性未验证**：论文未展示在多说话人、复杂场景、非虚拟人物内容上的泛化能力，也未测试超过2分钟的更极端时长。
8. **图像分辨率局限**：768×512相对较低，离电影/广播级质量还有距离。

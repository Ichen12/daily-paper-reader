## 摘要
生成式视频建模的最新进展已实现多样化生成、基于参考的合成、扩展和编辑，但现有方法往往依赖于碎片化的任务特定模型。通用模型必须区分异构的目标、源和参考信号，以确定要生成、保留或用作指导的内容，同时减少任务间的干扰。联合视听生成通过引入跨模态的多样条件设置和输出配置，进一步增加了这一挑战。我们提出了Vorch-Omni，一个基于任意条件到任意输出公式的统一多任务视听合成框架。它灵活地将视频和音频信号视为条件输入或生成目标。令牌级条件掩码和任务标识符区分目标、源内容和参考，而位置类型将时间上下文与独立条件分开。为捕捉语义和结构信息，Vorch-Omni采用互补的视觉条件路径：视觉语言模型用文本指令解释采样帧，视频VAE将条件编码为潜在令牌以提供直接指导。我们进一步构建了一个分布式数据管道，以策划多样化的时间对齐视听片段，生成结构化字幕和元数据，并平衡异构任务分布。基于单一流匹配扩散变压器，无需特定于任务的架构更改，Vorch-Omni支持超过10种任务，包括文本到视频、文本到音视频、图像和参考条件生成、时间扩展、音频驱动生成、视频变换以及视听编辑。该统一框架为通用视听生成和操作提供了可扩展的基础。

## Abstract
Recent advances in generative video modeling have enabled diverse generation, reference-based synthesis, extension, and editing, but existing approaches often rely on fragmented task-specific models. A general model must distinguish heterogeneous target, source, and reference signals to determine what to generate, preserve, or use as guidance, while reducing interference among tasks. Joint audio-visual generation further increases this challenge by introducing diverse conditioning and output configurations across modalities. We present Vorch-Omni, a unified multi-task framework for audio-visual synthesis based on an arbitrary-condition-to-arbitrary-output formulation. It flexibly treats video and audio signals as either conditioning inputs or generation targets. Token-level conditioning masks and task identifiers distinguish targets, source content, and references, while position types separate temporal context from independent conditions. To capture semantic and structural information, Vorch-Omni employs complementary visual conditioning pathways: a vision-language model interprets sampled frames with text instructions, and a video VAE encodes conditions into latent tokens for direct guidance. We further build a distributed data pipeline to curate diverse temporally aligned audio-visual clips, generate structured captions and metadata, and balance heterogeneous task distributions. Built on a single flow-matching diffusion transformer without task-specific architectural changes, Vorch-Omni supports over 10 tasks, including text-to-video, text-to-audio-video, image- and reference-conditioned generation, temporal extension, audio-driven generation, video transformation, and audio-visual editing. This unified framework provides a scalable foundation for general-purpose audio-visual generation and manipulation.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：视频生成模型已从文本/图像条件生成，扩展到参考条件合成、时间扩展和指令编辑等能力，但这些能力通常由**碎片化的任务特定模型或流水线**实现。商业产品（如 Veo 3.1、Sora 2 等）虽展示了原生视听生成能力，却只覆盖部分条件-输出配置。
- **核心问题**：能否设计一个**统一且可扩展的任务接口**，在支持多样视觉任务的同时，也支持音频与视频条件的任意组合？具体挑战包括：
  - **跨模态条件消歧**：视觉或声学上相似的输入在不同任务中可能扮演源、参考或前缀等不同角色，隐式拼接易导致混淆。
  - **条件二重性**：高层指令遵循需要语义推理（文本+视觉），而身份/纹理/运动保持又需要潜在空间中的细粒度结构信息。
  - **数据一致性与平衡**：联合训练需要真正同步对齐的音频视频对、可复用的标注，以及各任务类型间足够平衡的采样。
- **整体含义**：Vorch-Omni 试图以**单一模型、无需任务特定架构修改**的方式，统一超过 10 种视听生成与编辑任务，为通用视听生成与操作提供可扩展基础。

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心公式化抽象：任意条件到任意输出（Arbitrary-Condition-to-Arbitrary-Output）**
  - 任务表示为四元组 `T = (Xv, Cv, Xa, Ca)`：视频生成目标、视频条件、音频生成目标、音频条件。任一集合可为空，从而统一刻画纯视觉、纯音频、视听联合、扩展、参考、编辑等任务类型。
- **角色感知序列构造中的三个关键机制**：
  - **Token 级条件掩码（m）**：每个 token 用二值掩码区分“干净条件”（m=1）与“含噪生成目标”（m=0）。推理时条件 token 固定不变，目标 token 从噪声恢复。
  - **任务标识符（r）**：每个 token 关联任务 ID，通过可学习嵌入区分“目标”“源”“主体参考”“音频参考”“编辑条件”等角色；ID 为 0 时无偏移。
  - **位置类型（p）**：p=−1 表示独立参考（独立时间网格），p≥0 表示与目标同一连续时间轴（前后缀/第一帧约束），从而区分"时间连续上下文"与"独立条件"。
- **互补视觉条件路径**：
  - **VLM 语义路径**：以 1 FPS 采样条件帧，结合任务模板与用户指令，由视觉语言模型产出高层语义上下文，并分别投影到视频/音频流。
  - **VAE 潜在路径**：视频 VAE 将完整视觉条件编码为干净潜在 token，保留外观、布局、身份和运动细节。
- **音频-视频联合去噪骨干**：
  - 基于 LTX-2.3 的非对称双流流匹配扩散 Transformer（48 层；视频流 32 头×128 维，音频流 32 头×64 维）。
  - 每层内：视频/音频各自自注意力（3D/1D RoPE）与文本交叉注意力，随后进行**双向门控交叉注意力**（视频↔音频），再经各自 FFN。
  - 单个流缺失时对应跨模态注意力被跳过，模型自然退化为单模态生成。
- **训练目标（流匹配）**：
  - 对目标 `x0` 与噪声 `z` 插值：`xσ = (1−σ)x0 + σz`，预测速度场 `u = z − x0`。
  - 损失 `L = Lv + La`，各模态 loss 仅在目标 token 上计算，并按目标 token 占比归一化。
- **数据基础设施**：
  - 分布式版本化流水线：来源聚合 → 镜头感知分割（TransNetV2 + PySceneDetect）→ 去重（SigLIP 嵌入）与重平衡 → 质量/叠加层过滤 → 结构化视频字幕（动态-静态 schema）与音频元数据 → 任务打包（VAE 潜在+掩码+任务 ID+位置类型）→ 加权多任务采样。
- **推理**：将请求转换为同一四列表配置，目标槽位由高斯噪声初始化，流 ODE 积分从噪声到数据，条件 token 保持干净，最后经 VAE 解码输出视频/音频。

- 单一模型在无需任务特定架构修改的情况下，可覆盖 **超过 30 种条件-输出训练配置**（文中宣称支持 10 余种任务）。

### 7. 优点：方法或实验设计上的亮点

- **统一而优雅的公式化抽象**："四列表"任务配置 + 掩码/标识符/位置类型三者解耦，使任务范围扩展不需改网络结构，仅需更换配置。
- **任务规范与骨干计算分离**：同一 LTX-2.3 骨干可处理文本条件、干净前缀、噪声延续、多参考与编辑对，体现了高度的接口可扩展性。
- **互补视觉条件路径**：VLM 语义路径与 VAE 潜在路径并行，兼顾"理解指令"与"保持细节"，这是解决条件二重性难题的实用设计。
- **角色-位置分解**：区分"同类内容不同任务角色"（源 vs 参考 vs 前缀）和"时间连续 vs 独立条件"，有效降低异构 token 间干扰。
- **数据基础设施工程化**：版本化、可审计、可重跑的分布式数据流水线，配以加权多任务采样，为多任务联合训练提供了可复现基础。
- **实验评估分层设计**：将"总体偏好"细分为多个能力维度（音频同步、参考对齐等），能精确定位模型特有的优势，而非停留于笼统的"更好看"。

### 8. 不足与局限

- **实验对比不足**：仅与 Wan 2.7 单一基线对比，缺乏与 SkyReels-V4、Kling-Omni、Ovi 等统一多模态模型的直接比较；无消融实验验证各设计组件（掩码、任务 ID、位置类型）的独立贡献。
- **定量评估缺失**：没有报告 FVD、IS、CLAP 同步度等自动指标，也缺乏统计显著性检验。
- **评估偏差风险**：人工评估尽管专业，但评分细则复杂（多维度×多任务），存在评审一致性问题；样本总数虽大，分配到每个细分子任务后统计功效可能有限。
- **训练资源配置透明性低**：未报告 GPU 型号、集群规模、训练时长，可复现性和资源需求评估受限。
- **已承认的局限性**（论文自述）：
  - 长范围一致性（long-horizon consistency）仍有挑战。
  - 细粒度编辑局部性（fine-grained edit locality）不足。
  - 跨语言、跨说话人的稳健语音生成仍需改进。
- **应用限制**：参考条件驱动的角色替换、声音克隆等能力涉及潜在的身份/声音滥用风险，论文未讨论安全与伦理对策。

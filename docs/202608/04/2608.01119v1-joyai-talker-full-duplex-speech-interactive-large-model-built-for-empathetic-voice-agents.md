## 摘要
我们提出了JoyAI-Talker，一个全双工语音对话系统，在提供强大基础模型能力的同时，赋能共情交互与语音代理智能。JoyAI-Talker采用模块化的Thinker-Talker架构，并进一步实现统一的语音-文本联合训练流程，以缓解常见的“认知退化”瓶颈，从而在将模型核心的文本推理、STEM和逻辑能力扩展至基于语音的交互的同时，大幅保留这些能力。对于富有表现力的语音合成，Talker模块采用文本可控的生成范式，使自然语言指令能够灵活控制声音属性和局部副语言事件（如笑声和叹息），支持更具表现力和细粒度的语音响应。为增强对话共情，我们引入了Persona-Adaptive Empathetic Response (PAER)框架。PAER采用层级认知流程，从原始输入音频中提取非语言说话人线索（如性别、年龄和情绪状态），将其融入Thinker的思维链推理中，并生成上下文自适应响应，将语义上合适的文本与话语层面表现力和局部副语言事件（包括叹息、语速和音量）的细粒度控制相结合。我们进一步集成了Joy-Duplex，一个状态驱动的即插即用全双工框架，作为实时轮流控制的高效门控引擎。广泛评估表明，JoyAI-Talker在基础T2T和S2T基准上取得了极具竞争力的性能。在全双工评估中，系统在用户打断下实现了0.88的高响应率，同时在背景语音下保持极低的误触发率，展示了其支持流畅自然语音对话的完备性。

## Abstract
We present JoyAI-Talker, a full-duplex speech dialogue system that delivers robust foundation model capabilities while empowering empathetic interaction and voice agent intelligence. JoyAI-Talker adopts a modular Thinker-Talker architecture and further implements a unified speech-text joint training pipeline to mitigate the common "cognitive degradation" bottleneck, thereby largely preserving the model's core textual reasoning, STEM, and logical capabilities while extending them to speech-based interaction. For expressive speech synthesis, the Talker module employs a text-controllable generation paradigm that enables natural-language instructions to flexibly control vocal attributes and localized paralinguistic events, such as laughter and sighs, supporting more expressive and fine-grained speech responses. To enhance conversational empathy, we introduce the Persona-Adaptive Empathetic Response (PAER) framework. PAER employs a hierarchical cognitive pipeline to extract non-verbal speaker cues, such as gender, age, and emotional state, from raw input audio, incorporate them into the Thinker's CoT reasoning, and generate context-adaptive responses that align semantically appropriate text with fine-grained control over utterance-level expressiveness and localized paralinguistic events, including sighs, speaking rate, and volume. We further integrate Joy-Duplex, a state-driven, plug-and-play full-duplex framework that functions as an efficient gating engine for real-time turn control. Extensive evaluations show that JoyAI-Talker achieves highly competitive performance on foundational T2T and S2T benchmarks. In full-duplex evaluation, the system reaches a high response rate of 0.88 under user interruptions while maintaining an extremely low false-trigger rate under background speech, demonstrating its readiness for fluid and natural speech dialogue.

# 2. 方法论

## 2.1 总体架构：Duplex-Thinker-Talker

- 采用**解耦模块化架构**，将对话状态协调（Duplex）、认知语义推理（Thinker）和表现性语音合成（Talker）分离，避免端到端双流架构对主干模型造成的认知干扰。
- 优点：模块可独立训练/升级；保护 Thinker 的语义核心免受高频流式状态追踪任务的损害。
- 代价：存在一定延迟开销、模块接口信息瓶颈、服务基础设施较复杂。

## 2.2 Thinker：共情语音-文本基础模型

- **结构**：编码器-投影器-解码器架构。语音编码器基于 ASR 预训练，输入音频转为 log Mel 特征后经 8× 下采样，声学 token 速率降至 12.5 Hz。语言主干为 JoyAI-LLM Flash（48.9B 总参数，约 3.28B 激活/ token），采用 MLA、RMSNorm、RoPE、SwiGLU，40 层 Transformer（1 层稠密 + 39 层 MoE），256 个专家 + Top-8 路由 + 1 个共享专家，无辅助损失负载均衡。
- **统一语音-文本联合训练**：从 **Mid-training 阶段**即开始多模态联合训练，而非推迟到 SFT，以缓解认知退化，覆盖 Mid-training → Context Extension → SFT → DPO 四个阶段：
  - Mid-training：先冻结主干/编码器训练音频适配器，再全参数联合优化；文本与语音数据混合。
  - Context Extension：上采样长文本数学/代码数据与长语音对话，序列长度扩展至 64K。
  - SFT：覆盖文本指令遵循与语音问答、翻译、共情对话等，通过 TTS 合成大量 S2T 数据。
  - DPO：基于 SFT 策略自生成的偏好对，采用“语音专属”偏好构造策略，避免跨模态分布失配；配备通用 QA、指令遵循和规则三种判别器。
- **训练细节**：基于 Megatron-Core，使用 DP/TP/SP/PP + 8 路 EP，DeepEP 加速 MoE，CUDA Graph 优化；长序列阶段使用 CP + THD 注意力，音频感知打包算法提升吞吐；严格 loss masking，只对 Assistant 回复计算损失。

## 2.3 PAER：Persona-Adaptive Empathetic Response

- 层级认知流程：**音频理解 → CoT 推理 → 共情对话生成**。
- 先从原始音频中提取说话人属性（性别、年龄、情绪状态），再将其融入 Thinker 的思维链推理，生成上下文自适应回复。
- 回复包含语义文本 + 话语级表达控制（语速、音量等）+ 局部副语言事件（如 [Sigh]、[Laughter]），同时保持助手身份一致。

## 2.4 Talker：指令可控表现性语音生成

- 基于 JoyVoice 的 Transformer–DiT 架构：自回归 Transformer 预测语音 token，其隐表示条件化因果 Diffusion Transformer 生成 mel-spectrogram，再经 Vocoder 合成波形。
- **序列形式**：`I = [P; T; S]`，其中 `P = [Psys; Ig]`，`T = [spk; Il; t1, ..., tN]`，`S = [s1, ..., sM]`；Ig 为全局说话人指令，Il 为局部表达指令（均为自然语言 token 序列）。
- **层级指令**：全局指令描述说话人稳定特征（角色、性别、口音等），局部指令描述当前话语的情绪、语速、音量、音色等；部署时全局特征被吸收进固定目标音色，仅局部指令作为动态控制接口。
- **副语言建模**：定义 10 种特殊 token（如 [Laughter]、[Sigh]、[Cough]、[Uhm] 等），可插入文本任意位置，实现位置精确的局部副语言事件控制。
- **低代价目标音色适配**：通过**风格借用**（voice conversion）将影视等来源的表现性语音迁移到目标助手音色，避免为目标说话人录制全部表达组合。
- **流式生成**：支持流式文本输入和语音输出，局部指令作为完整条件单元保留。

## 2.5 Joy-Duplex：状态驱动全双工交互框架

- **结构**：流式音频编码器 + 1.7B 参数 Joy-Duplex Decoder。编码器以 160ms 非重叠分块处理输入波形，采用动态分块注意力（仅看历史与当前块）；解码器在统一序列中交错解码文本 token、边界 token（`<|asr_eos|>`）和状态 token。
- **状态 token**：
  - `<|partial|>`：用户语义意图尚未完成，SDM 保持待命。
  - `<|complete|>`：转写达到完整句法和语义边界。
  - `<|backchannel|>`：用户发出“嗯哼”等短反馈时，仅确认不抢占话轮。
  - `<|accept|>` / `<|reject|>`：语义门控最终决策，决定是否触发下游对话模型。
- **概率建模**：每一帧文本与状态序列的联合概率分解为 `P(Tt | A≤t, Ht−1) · P(St | A≤t, T≤t, Ht−1)`，即先预测当前帧文本，再基于文本预测交互状态。
- 可并行运行 Speaker Verification 插件，仅允许授权说话人触发系统。

# 6. 主要结论与发现

- JoyAI-Talker 通过统一语音-文本联合训练有效缓解认知退化：T2T 上 DPO 模型 MATH 达 94.62%、MMLU-Redux 达 90.80%、RULER(64K) 达 76.88%，表明语音训练未明显损害文本推理能力。

- Joy-Duplex 在 Full-Duplex-Bench v1.5 上取得最佳平衡：用户打断响应率 0.88（最高）、打断误坚持率 0.07（最低）；背景语音下误触发率 0.10、继续率 0.85；backchannel 场景继续率 0.96、误触发率 0.01。
- 总体结论：JoyAI-Talker 在核心认知、共情表达和全双工交互三个维度上均达到有竞争力的水平，为自然情感语音代理提供了较完整的工程方案。

# 7. 优点

- **架构设计清晰**：Duplex-Thinker-Talker 解耦认知、交互和语音生成，模块可独立优化，避免了端到端双流架构对推理能力的损害。
- **训练范式合理**：从 Mid-training 开始语音-文本联合训练，贯穿 Context Extension、SFT 和 DPO，并采用“语音专属”DPO 偏好对，严谨地处理了跨模态分布失配问题。
- **共情建模有层次**：PAER 将“感知→推理→生成”串成明确流程，把性别、年龄、情绪等副语言信息显式引入思维链，而非简单贴情感标签。
- **细粒度控制**：副语言特殊 token + 自然语言指令的组合，同时实现全局表达控制和局部事件定位控制，表现力强且可解释。
- **全双工方案轻量稳健**：Joy-Duplex 作为即插即用门控器，不修改主干模型，通过语义状态 token 实现低误触发的轮次控制，工程部署性好。
- **低数据成本适配**：基于语音转换的“风格借用”策略，大幅降低目标音色表达性数据采集成本。

# 8. 不足与局限

- **感知范围有限**：目前只处理语音和说话人属性，缺乏对环境声音、背景噪声、警报、音乐等通用音频事件的理解和推理能力。
- **RL 对齐尚未完成

## 摘要
准确且响应的轮次转换对于口语对话系统至关重要，系统必须实时区分用户打断、应忽略的反馈信号以及话语的结束。先前的模块化方法通常在话语或固定块级别优化轮次状态预测，这与连续的轮次状态估计不匹配，并且通常依赖辅助ASR模型，这限制了响应性并增加了整体系统复杂性。因此，我们提出了X2-Turn，一种通过延迟流建模的帧同步轮次状态预测方法。具体来说，基于预训练的Voxtral Realtime模型，我们引入了一个帧同步轮次状态头，与ASR头在共享的流式表示上并行操作，在帧级别联合预测ASR标记和细粒度的轮次状态。我们在中英双语Easy-Turn测试集上评估了我们的方法，结果表明其在实现准确轮次检测的同时保持低延迟的有效性。

## Abstract
Accurate and responsive turn-taking is essential for spoken dialogue systems, which must distinguish in real time between user interruptions, backchannels that should be ignored, and the completion of an utterance. Prior modular approaches typically optimize turn state prediction at the utterance or fixed-chunk level, creating a mismatch with the continuous turn state estimate, and often depend on an auxiliary ASR model, which limits responsiveness and increases overall system complexity. Therefore, we present X2-Turn, a frame-synchronous turn state prediction method via delayed-stream modeling. Specifically, building on the pretrained Voxtral Realtime model, we introduce a frame-synchronous turn state head that operates in parallel with the ASR head on shared streaming representations, jointly predicting ASR tokens and fine-grained turn states at the frame level. We evaluate our method on the bilingual Chinese-English Easy-Turn test sets, and the results demonstrate its effectiveness in achieving accurate turn-taking detection while maintaining low latency.

# X2-Turn 论文深度总结

## 1. 核心问题与研究动机

- **背景问题**：口语对话系统（Spoken Dialogue System）必须实时、准确地区分三类关键用户行为——打断（interruption）、应忽略的反馈词（backchannel，如"嗯""啊"）以及话语结束（utterance completion），这就需要**帧级连续的轮次状态估计**（turn state prediction）。
- **现有方法的两个主要缺陷**：
  1. **时间粒度不匹配**：大多数方法在**话语级（utterance-level）或固定块级（chunk-level）** 预测轮次状态，与实际对话中**连续、帧级**的状态变化不匹配，限制了实时响应的精度和速度。
  2. **依赖辅助 ASR 模块**：许多级联式（cascaded）方法依赖单独优化的上游 ASR 模型，不仅引入**顺序延迟**和**错误传播**，还使系统整体复杂化、响应速度受限。
- **论文目标**：提出一种**帧同步（frame-synchronous）** 的轮次状态预测方法，将 ASR 和轮次状态预测**融合到同一个流式前向传播过程**中，在保证低延迟的同时实现高精度的轮次检测。

## 2. 方法论

### 2.1 总体框架：双头建模（Dual-Head Modeling）

- **骨干网络**：基于预训练的 **Voxtral Realtime**——一种基于延迟流建模（Delayed-Stream Modeling, DSM）的原生流式 ASR 模型，由三部分组成：
  1. 因果音频编码器（将 16kHz 波形映射为帧级特征）
  2. 时间适配器（下采样至 12.5Hz）
  3. 仅有解码器（decoder-only）的语言模型（每 80ms 步长发射一个 token）
- **关键创新**：在 Voxtral Realtime 基础上**新增一个并行的轮次状态预测头（turn state head）**，与原有的 ASR 头共享因果解码器的隐藏状态 $h_i$，同时完成 ASR token 和轮次状态预测。
- **两大头联合优化**，总损失函数为：

$$
L = L_{asr} + \lambda L_{turn}
$$

其中 $L_{asr}$ 为 ASR 词汇上的 token 级交叉熵，$L_{turn}$ 为轮次状态分类损失，$\lambda = 0.1$ 用于调节两者贡献。

- **解码流程**：推理时，自回归解码仅由 ASR 头驱动，轮次状态头从共享隐藏状态独立预测；**轮次预测错误不会反馈进解码循环**，不会影响后续 ASR 结果。

### 2.2 轮次状态 Token 设计

定义了 **5 种轮次状态 token**：

| Token | 含义 |
|---|---|
| `<\|idle\|>` | 用户静音（由强制对齐得到的非语音段） |
| `<\|noidle\|>` | 活跃语音但尚无语义内容（如话语开头音节） |
| `<\|incomplete\|>` | 活跃语音且包含部分语义内容（话语未完成） |
| `<\|complete\|>` | 活跃语音且语义内容完整（话语完成） |
| `<\|backchannel\|>` | 用户反馈词或填充词（如"um""ah"） |

**关键区别**：`<|noidle|>` 仅指"尚未累积足够语义的早期语音"，**不包括非语音或背景噪声**，从而将"真正的静音"与"用户话语的早段"区分开来。

### 2.3 ASR 锚定的轮次状态监督（ASR-Anchored Turn State Supervision）

- **ASR 目标序列构造**：每个词用一个词边界 token `[W]` 后接其子词 token 表示；`[W]` 的位置锚定到**词起始时间**（而非原 Voxtral 的词偏移），计算如下：

$$
p_i = \text{round}(s_i / \Delta) + n_\tau
$$

其中 $\Delta = 80\text{ms}$ 为帧时长，$n_\tau = \tau / \Delta$ 为目标延迟帧数。

- **轮次状态标签构造**：先用 LLM（Qwen3.5-Plus）为每个词标注语义轮次状态，再将词级标签投影到该词 `[W]` 和子词 token 占据的所有 80ms 帧位置；未占据位置（包括语音前静音、词间停顿、句尾拖音）标注为 `<|idle|>`。
- **三大性质**：
  1. 词级轮次标签与对应 ASR token 占据相同的帧位置，两个任务在位置上一一对应；
  2. 静音得到显式监督，下游策略可通过计数 `<|complete|>` 后的连续 idle 帧来做端点检测（endpointing）；
  3. ASR 与轮次目标在**同一帧同步离散时间轴**上优化，而非话语或块级对齐。

## 6. 主要结论与发现

1. **流式性能优势**：X2-Turn（τ = 480ms）在两个语言测试集上持续优于 SoulX-Duplug（流式基线），精度与最强级联系统相当，但**延迟显著更低**（中文 288ms vs. 级联的 VAD 延迟 + 数百 ms），具有更优的精度-延迟权衡。
2. **延迟可控**：τ 从 480ms 降至 320ms 时，延迟大幅下降，仅伴随轻微的精度损失，验证了模型在紧延迟约束下的鲁棒性。
3. **单模型实时性**：无需任何辅助 ASR 模型即可在单次流式前向传播中同时解码 ASR 转录和轮次状态，极大简化了系统架构。
4. **ASR 性能保持**：Stage1-ASR（τ = 480ms）在几乎所有测试集上优于块式流式基线；Stage2 联合训练引入轻微劣化后仍匹配或超过 Freeze-Omni。

## 7. 方法亮点与优势

- **真正的帧同步预测**：将轮次状态预测压缩到 80ms 帧级，比现有话语级/块级方法粒度更细，更贴合真实对话的动态变化。
- **优雅的双头架构**：ASR 与轮次预测共享计算和表示为单前向传播，**零额外推理延迟**，且两个任务"互不干扰"（错误不传导）。
- **ASR 锚定监督设计巧妙**：将词级语义标注精确投影到流式 ASR token 时间轴，实现了两个任务的天然对齐；同时将静音显式建模为 `<|idle|>`，为下游交互策略提供了端点检测基础。
- **延迟可配置**：通过目标延迟 τ 在训练时对多种配置采样，单模型即可适应不同延迟需求，实现 320~480ms 的灵活运行点选择。
- **模块化集成友好**：轮次状态估计与响应生成解耦，可无缝集成到不同对话系统中。

## 8. 不足与局限

- **算力信息缺失**：未披露训练使用的 GPU 资源与时长，影响复现性。
- **数据规模有限**：轮次转换训练数据为中英各约 100~250 小时的子集，且使用 LLM 自动标注，未经人工验证，可能存在标注噪声。
- **实验覆盖不完整**：backchannel 检测仅在中文测试集上评估，英文缺乏对应结果；未在真实完整口语对话或语音交互场景中验证。

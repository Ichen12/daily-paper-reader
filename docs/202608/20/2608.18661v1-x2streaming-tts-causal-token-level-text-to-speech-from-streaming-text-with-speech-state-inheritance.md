## 摘要
流式文本到语音合成对于低延迟口语对话系统至关重要，然而许多系统等待句子级文本，因此只是伪流式。真正的词元级合成必须从不确定的前缀生成语音，同时在有界上下文中保持无界流上的感知连续性。我们提出了X2Streaming-TTS，一个因果TTS框架，它消费异步到达的文本词元，并在不访问未来输入的情况下生成语音。为了处理不确定的前缀，我们引入了因果承诺，它通过不确定性感知缓冲保持歧义表达的临时性，并执行容量自适应、标点感知的分段。为了保持声学连续性，我们进一步引入了因果语音状态继承，它跨段边界携带完整的Code2Wav状态和选定的历史Talker状态。结合注意力先验约束，它在保留有界声学上下文的同时阻止对未来位置的访问。实验表明，X2Streaming-TTS在大多数主观和客观指标上优于现有的伪流式模型。进一步分析表明，因果承诺稳定了在线分段，减少了因上下文不足而导致的失败，而语音状态继承提高了边界连续性，而不降低自然度或说话人身份。因此，X2Streaming-TTS实现了严格的词元级合成，其质量与评估的离线基线相当，单次请求的首次音频词元中位时间（TTFT）为15.8毫秒，在128个并发请求时中位TTFT为260.8毫秒。我们的实现可在https://github.com/X-Square-Robot/X2Streaming-TTS公开获取。

## Abstract
Streaming text-to-speech is essential for low-latency spoken dialogue systems, yet many systems wait for sentence-level text and are therefore only pseudo-streaming. True token-level synthesis must generate speech from uncertain prefixes while maintaining perceptual continuity over an unbounded stream with bounded context. We present X2Streaming-TTS, a causal TTS framework that consumes asynchronously arriving text tokens and emits speech without accessing future input. To handle uncertain prefixes, we introduce causal commitment, which keeps ambiguous expressions provisional through uncertainty-aware buffering and performs capacity-adaptive, punctuation-aware segmentation. To preserve acoustic continuity, we further introduce causal speech-state inheritance, which carries the complete Code2Wav state and selected historical Talker states across segment boundaries. Together with an attention prior constraint, it blocks access to future positions while retaining bounded acoustic context. Experiments show that X2Streaming-TTS outperforms existing pseudo-streaming models on most subjective and objective metrics. Further analysis shows that causal commitment stabilizes online segmentation and reduces failures caused by insufficient context, while speech-state inheritance improves boundary continuity without degrading naturalness or speaker identity. X2Streaming-TTS thus achieves strict token-level synthesis with quality comparable to the evaluated offline baselines, a median time to first audio token (TTFT) of 15.8 ms for a single request, and a median TTFT of 260.8 ms at 128 concurrent requests. Our implementation is publicly available at https://github.com/X-Square-Robot/X2Streaming-TTS .

# 论文详细总结

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：流式文本到语音合成（Streaming TTS）对于低延迟口语对话系统至关重要，但现有大多数系统仍需等待**完整句子**才启动合成，本质上只是"伪流式"（Pseudo-streaming）。真正的**词元级（Token-level）流式合成**必须实现在文本前缀尚不确定的情况下就开始发声，且无法访问任何未来输入。
- **根本矛盾——不可逆性**：语音一旦播出就无法修正。例如上游语言模型输出前缀 "He finished 3"，后续可能是 "3 laps"（读作 *three*）或 "3rd"（读作 *third*），两种发音在单词完成前就产生分歧，系统一旦发出 *three* 便无法改为 *third*。这种"在部分可观测条件下做出不可逆承诺"的问题，是 token 级 TTS 与离线/句子级 TTS 的本质区别。
- **三个子挑战**：
  1. **读音不确定**：数字、单位、符号等可能被后续到达的字符重新解释；
  2. **呼吸感与分段**：纯标点驱动会产生过多短段（浪费生成预算），固定窗口又会在与语言结构无关的位置硬切；
  3. **连续性**：从静音状态重新生成一段语音需要重建音高与音色，分段处产生可感知的裂缝（seam）。
- **整体意义**：这项工作把 token 级流式合成形式化为"何时可以承诺（when may I commit）"与"如何延续已产生的状态（how do I continue the state I have produced）"两个问题，并给出了可实现的解决方案。

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

该方法建立在 Qwen3-TTS 骨干之上，利用其三个特性：**可计数的离散声学 token 输出**、**可迁移的解码器状态**、**可观测的剩余 KV-cache 容量**。系统由三部分组成：流式前端（Frontend）、Talker（文本→声学 token）、Code2Wav（声学 token → 波形）。整体严格满足因果约束式 (1)：

> `y_u ⊥ x_{N(τu)+1:} | x_{1:N(τu)}, y_{<u}, h_{k-1}`

即每个声学 token 只能依赖生成时刻之前已观测到的文本、此前生成的声学 token 以及继承的语音状态。

### 2.1 因果承诺（Causal Commitment）

由两个耦合组件构成：

**（1）不确定性感知语义就绪（Uncertainty-Aware Semantic Readiness）**

- 前端维护一个待定后缀 U_t，其中的表达可能被未来 token 改变发音；
- 每个新 token 到达时，按式 (2) 将缓冲区切分为"最长可释放前缀 E_t + 待定后缀 U_t"；
- 确定性闭合规则覆盖数字、单位、符号、缩写和标点。只有当下游任何合法延续都无法改变某段表达的发音时，该段才会被**原子性释放**（如 "3" 被保留直到 "laps" 或 "rd" 出现，随后整体归一化并释放），释放后绝不修改；
- 语义就绪只决定"什么可以被承诺"，容量控制决定"当前段何时必须关闭"。

**（2）容量自适应标点感知分割（CAPS, Capacity-Adaptive Punctuation-aware Segmentation）**

- **离线优化问题**（式 3–4）：将分段表述为约束优化——在 KV-cache 容量 B 的约束下，最小化"段数惩罚 + 边界类型代价"（标点边界分三级：句末 < 从句 < 弱标点，硬切代价最高），可通过动态规划精确求解，作为离线参考；
- **延迟反馈容量估计**（式 5–6）：对每个已完成段估计"声学扩展比" ρ_k = A_k / n_k（每文本 token 对应的自回归解码步数），用 EMA 更新在线估计 ρ̂_k，据此预测下一段容量：
  - `Ĝ_k(S; ξ) = P̂_k + ρ̂_k|S|`
  - `Ĉ_k = ⌊(B − R − P̂_k) / ρ̂_k⌋`
- **因果标点闭合规则**（式 7）：设三级阈值 T_{ℓ,k} = ⌈α_ℓ·Ĉ_k⌉（α₁=0.7, α₂=0.8, α₃=0.9），当遇到底 ℓ 级标点且当前文本长度 L_t ≥ T_{ℓ,k}，或 L_t ≥ Ĉ_k（硬切）时关闭当前段；
- **碎片化上界定理（Theorem 1）**：在 Ĉ_k = C 的假设下，段数上界为 `m_CAPS ≤ (1/α₁)·m*_C + 1`，即至多约为最优段数的 1.429 倍加 1。该定理保证分段策略不会产生无界碎片化。

### 2.2 因果语音状态继承（Causal Speech-State Inheritance）

**（1）两条独立状态路径**

- **路径一（波形解码器状态）**：完整保存并传递 Code2Wav 的 KV cache、卷积状态、转置卷积状态和帧索引，用于下一段的热启动（warm-start）；
- **路径二（声学历史状态）**：传递固定数量 H=4 个尾部 token 对齐的 Talker 状态，作为有界的历史记忆（上下文复杂度 O(H)，与流长度无关）；
- **健康检查（Health Check）**：仅当上一段完整接收输入、消费全部文本、正常终止解码、扩展比 ρ_k ∈ [1, 12]、Code2Wav 快照完整时，继承链才保持激活，否则清空状态从默认状态重启。

**（2）固定因果注意力先验**

- 将 H 个历史 Talker 状态与当前段投影后的表示拼接为记忆 M；
- 注意力 logits 采用式 (9)–(10)：`ℓ_{u,j} = 2·cos(q_u, m_j) + b(d_{u,j})`，其中距离偏置 b(d) = −d²/8（0≤d≤4）、log 0.1（d≥5）、**−∞（d<0）**——未来位置权重为零，满足严格因果性；当前位置相对距离≥5 的位置有 10:1 的先验优势。

**（3）有界注入（Bounded Injection）**

- 用归一化注意力集中度 s_u（式 11）作为门控得分；
- 注入增益 gu = 0.015·(0.5 + 0.5·s_u) ∈ [0.0075, 0.015]，按式 (12) 将因果上下文注入：`z'_u = z_u + g_u·m_u`；
- 扰动上界为 `‖z'_u − z_u‖ ≤ 0.015·max‖m_j‖`，显式限制了携带上下文的影响范围。

## 6. 主要结论与发现

- **质量与离线相当**：X2Streaming-TTS 与同一骨干的离线参考相比，在 8 个条件下有 3 个条件识别错误率更低，剩余 5 个条件的最大退化为 0.62 个百分点——token 级输入几乎不损失可懂度；
- **优于流式基线**：在 8 个流式条件中 6 个取得最低错误率；长文本 1× 时 CER 2.55%（优于所有对比方法包括离线），10× 时 4.36% 仍优于所有流式对比；
- **边界连续性强**：PBD 为 0.1092，与最近对比方法 FireRedTTS-2（0.1915）的置信区间完全分离；ΔF₀ 22.61 Hz、ΔE 1.66 dB 均显著最低；
- **说话人一致性突出**：ECAPA 相似度 0.951，远超 FireRedTTS-2 的 0.5205（对比方法在长文本中说话人漂移严重，说明"边界连续性"与"长期一致性"是两个互补问题）；
- **分段策略有效**：CAPS 将预算利用率从纯标点的 11.77% 提至 76.93%，硬切率从固定窗口的 87.13% 降至 0.54%；F1=0.952 超过 SaT-3L（0.940）——纯标点（F1=0.017）与纯容量（F1=0.199）均远不足以识别合适边界；
- **歧义处理有效**：数字和流式歧义类目 0% CER、100% 完全正确读出；整体语义保持率 93.33%（高于完全正确率 73.3%，说明剩余错误多为不影响理解的发音变体）；
- **低延迟**：单请求 TTFT 中位数 15.8 ms；128 并发时为 260.8 ms（≤64 并发时均低于 120 ms）。

- **语言覆盖有限**：核心分段与连续性实验仅在中文上进行，英文仅报告识别率，符号歧义测试也以中文为主；跨语言泛化能力（尤其是英文数字/单位规则的差异）有待验证；
- **对比公平性争议**：对比模型使用各自的内部架构和训练数据，虽同属先进水平，但非严格同条件下训练；FireRedTTS-2 的 ECAPA 相似度异常低（0.52），可能反映其评测协议差异而非真实模型能力差距；
- **长文本稳定性依赖健康检查**：状态继承在健康检查失败时回退到默认状态，实际长时间运行中健康检查的触发频率未统计，系统的退化模式不明确；

- **主观评价规模有限**：符号评测仅 120 名听者，未报告评分者间一致性（如 ICC 或 Fleiss' κ），也未给出各子类评分的置信区间或显著性检验，统计稳健性不足以完全支撑"所有类别均无缺陷"的强结论；此外听者来源与设备条件未说明，可能存在众包噪声。

## 10. 总体评价与展望

**总体评价**：

这篇论文的核心价值不在于刷高了多少个百分点的指标，而在于把 token 级流式 TTS 从"工程 hack"提升为"可建模、可证明、可复用"的研究问题。作者清晰地区分了"容量驱动的截断"与"语义驱动的承诺"两个正交维度，并用因果注意力先验与有界注入解决了"流式状态下如何优雅地延续"这一长期被忽视的问题。碎片化上界定理虽简单，但标志着该领域开始具备形式化分析能力。相比同类流式系统，它在延迟、边界连续性与说话人一致性上取得了明显且统计可靠的优势，同时几乎没有牺牲可懂度——这是一项完成度较高的系统性工作。

**未来研究方向**：

1. **概率化承诺**：当前语义就绪依赖确定性规则，未来可将上游 LLM 的下一 token 概率分布引入归一化决策，实现"不确定性越大、越倾向于延迟承诺"的概率化权衡；
2. **多语言扩展**：英文数字、日期、缩写、量纲的歧义模式与中文差异显著，规则库需扩展为可配置的多语言符号系统，并验证状态继承在不同语言韵律边界下的普适性；
3. **端到端联合优化**：将 Talker 的前缀感知能力与 LLM 的流式解码器联合训练，使文本生成器主动规避发音歧义（如输出规范化的 phoneme 中间表示），从源头消除不可逆决策；
4. **动态到达间隔的鲁棒性**：引入随机文本到达时间的压力测试，研究突发输入对 CAPS 容量预测与健康检查触发率的影响，并设计自适应的缓冲长度调节策略；
5. **减少硬回退**：健康检查失败时完全重置状态是安全但保守的策略，可探索"部分继承"（如仅继承 Code2Wav 的卷积状态而丢弃注意力 cache）以降低回退带来的音色跳变概率。

**总体而言，该工作为 token 级流式 TTS 确立了新的设计范式与评估基线，其形式化思路与工程实践的深度结合，为该方向后续研究提供了扎实的参照系。**

## 摘要
生成同时融合语音、音乐和音效的连贯音频场景仍然是一项重大挑战。现有方法通常依赖一种不连贯的流水线，即使用冻结的解耦文本编码器馈送独立的音频解码器，这限制了跨模态优化并导致语音可懂度较差。为克服这些局限性，我们提出了MiDashengLM-Gen，一种端到端框架，将预训练的大型语言模型（LLM）与基于逐令牌条件流匹配相结合，用于自回归、可变长度的混合音频场景生成。MiDashengLM-Gen代表了首个通过端到端训练模型实现通用文本到音频生成的方法。实证评估表明，MiDashengLM-Gen显著提高了现有统一模型的语音可懂度。在Seed-TTS基准上，英文词错误率（WER）从12.15%降至2.79%，接近专用文本到语音（TTS）系统的性能（1.24%）。此外，该框架有效扩展到多语言设置，与现有基线相比，在多语言WER上展现出极具竞争力的结果。最后，该模型在MECAT基准上保持了具有竞争力的混合音频生成质量。代码和检查点可在https://github.com/xiaomi-research/midashenglm-gen和https://huggingface.co/mispeech/midashenglm-gen获取，演示页面可在https://xingws.github.io/midashenglm-gen-demo/访问。

## Abstract
Generating coherent audio scenes that simultaneously blend speech, music, and sound effects remains a significant challenge. Current approaches typically rely on a disjointed pipeline where a frozen, decoupled text encoder feeds a separate audio decoder, limiting cross-modal optimization and leading to poor speech intelligibility. To overcome these limitations, we introduce MiDashengLM-Gen, an end-to-end framework that couples a pre-trained Large Language Model (LLM) with per-token conditional flow matching for autoregressive, variable-length mixed-audio scene generation. MiDashengLM-Gen represents a first approach for general text-to-audio generation with one end-to-end trained model. Empirical evaluations demonstrate that MiDashengLM-Gen drastically improves speech intelligibility over existing unified models. On the Seed-TTS benchmark, English Word Error Rate (WER) drops from 12.15% to 2.79%, approaching the performance of dedicated Text-to-Speech (TTS) systems (1.24%). Furthermore, the framework extends effectively to multilingual settings, yielding highly competitive multilingual WERs compared to existing baselines. Lastly, the model maintains competitive mixed-audio generation quality on the MECAT benchmark. Code and checkpoints are available at https://github.com/xiaomi-research/midashenglm-gen and https://huggingface.co/mispeech/midashenglm-gen, and the demo page is available at https://xingws.github.io/midashenglm-gen-demo/.

## 2. 方法论：核心思想、关键技术细节

### 2.1 总体架构
- 以预训练因果语言模型 **Qwen3-1.7B** 作为序列建模骨干，替代传统分离的 T5 文本编码器 + 交叉注意力结构。
- 使用 **DashengTokenizer 编码器的输出**（768 维、25 Hz 的语义-声学连续隐表示）作为音频表征，而非低维 VAE 特征或离散 codec token。
- 结合 **逐 token 条件流匹配（Per-Token Conditional Flow Matching）**：LLM 在每个自回归位置输出隐藏状态，作为 DiT 流匹配解码器生成该位置音频 token 的条件。

### 2.2 结构化多视角场景字幕（Structured Multi-View Captions）
- 每个音频场景被分解为六个文本视图：全局场景描述、语音转写、说话人身份与风格、音效、音乐内容、录音环境。
- 每个视图对应一个专用特殊 token（如 `<|caption|>`、`<|asr|>`、`<|sfx|>` 等），不适用时用 `<|unknown|>` 填充，降低控制因素间的语义纠缠。

### 2.3 音频-文本对齐预训练
- **关键步骤**：在正式生成训练前，先用通用音频描述（general audio captions）将 DashengTokenizer 的音频隐表示映射到 LLM 的 token 空间。
- 通过音频适配器（MLP）将连续 5 帧（k=5）编码器输出下采样为 5 Hz（200 ms/token）的 LLM 输入 token：
  \[
  a_i = \text{MLP}(\text{concat}(z_{(i-1)k+1}, \ldots, z_{ik})) \in \mathbb{R}^{d_{llm}}
  \]
- 消融实验表明，**该对齐阶段是生成质量的前提条件**，去掉后各项指标显著恶化。

### 2.4 自回归输入与训练目标
- 输入序列为：`[文本嵌入, <|audio_bos|>, a_1, a_2, ..., a_N]`，LLM 在每个音频位置 i 输出隐藏状态 \( h_i \)，作为该位置的条件。
- **流匹配损失**（每个 token 独立计算）：
  \[
  \mathcal{L}_{FM} = \mathbb{E}\left[\left\| v_\theta(z_t^{(i)}, t, h_i, z_{hist}^{(i)}) - (z_1^{(i)} - z_0^{(i)}) \right\|_2^2 \right]
  \]
- 推理时使用 10 步 Euler 求解器，应用无分类器引导（CFG，scale=2.0）。

### 2.5 变长生成机制
- 通过**学习的停止头（stop head）**预测每个位置的继续/停止二分类分布，使用平衡交叉熵训练并挖掘困难负样本。
- 推理时，当停止概率超过阈值 τ=0.5 且已生成最少 imin=5 步后终止生成。

### 2.6 关键架构发现
- **DiT 宽度必须严格大于音频隐表示的维度**（768 维 → DiT 宽度需 >768）才能收敛，该规律在 0.6B/1.7B/4B LLM 和 768/1280 维隐空间上均成立，与图像扩散领域的理论发现一致。

## 6. 主要结论与发现

1. **LLM 骨干 + 逐 token 流匹配可成功实现端到端混合音频场景生成**，支持变长输出和多语言。
2. **语音可懂度大幅提升**：Seed-TTS 英文 WER 从 Dasheng AudioGen 的 12.15% 降至 2.79%（专用 TTS Qwen3-TTS 为 1.24%）；中文从 >100% 大幅降至 3.87%。
3. **多语言能力显著优于前代统一模型**：在 9 种语言上的平均 WER 大幅下降（如中文从 99.62% 降至 3.51%）。
4. **MECAT 混合场景上 LLM 背书的优势体现在多源协调与全局一致性**：在多数含语音的混合类别（S0A、SM0、SMA）上 FAD 优于 Dasheng AudioGen；但非自回归架构在部分细粒度分布指标（FD、KL）上仍具优势。
5. **两个关键架构原则**：① 音频-文本对齐预训练必不可少（去掉后语音 WER 恶化约 4 倍）；② DiT 宽度必须严格超过音频隐维度才能收敛，该规律具有跨模型规模的普遍性。

## 7. 优点与亮点

- **端到端统一架构**：首次将预训练 LLM 与流匹配结合用于音频场景生成，消除冻结文本编码器带来的跨模态优化瓶颈，简化了架构复杂度。
- **高维语义-声学隐空间的有效利用**：证明高维 DashengTokenizer 特征可用于 LLM 条件生成，避免了离散 token 的量化伪影和低维 VAE 的信息损失。
- **关键收敛条件的发现**：DiT 宽度需严格大于隐维度，这一架构洞察对后续音频生成模型设计具有直接指导价值。
- **语音可懂度的巨大飞跃**：WER 从 12.15% 降至 2.79%，缩小了统一模型与专用 TTS 之间的差距，是实用性提升的关键一步。
- **多语言零样本能力**：凭借 LLM 预训练的语言理解能力，无需针对每种语言单独训练即可生成多种语言的语音。
- **结构化控制**：多视角字幕 + 专用 token 提供了细粒度的条件控制机制，且不适用字段可用 `<|unknown|>` 掩蔽，灵活性强。
- **开源开放**：代码、权重和演示页面均已公开，有利于后续研究复现和跟进。

## 8. 不足与局限

- **语音质量仍有差距**：英文 WER 2.79% vs. 专用 TTS 1.24%，差距约 2.2 倍；低资源语言（日语 16.45%、俄语 13.19%）差距更大。
- **缺少现成的能力**：不支持零样本声音克隆、无显式说话人身份条件控制，说话人风格控制较粗糙。
- **长度受限**：训练数据为 1–20 秒，超出此范围的连贯长音频生成仍待解决。
- **部分基准落后**：在 AudioCaps 上 FAD 明显差于 TangoFlux（5.01 vs. 2.26），论文将其归因于训练数据分布而非方法缺陷，但该解释需要更多实验验证。
- **训练数据规模未完整披露**：77k 小时 ACAVCaps 为私有数据，标注质量、版权合规等细节未充分讨论；TTS 语料的语言分布不均衡也直接影响多语言效果。
- **主观评测缺失**：无 MOS 评分，尤其对混合场景中多声源的感知自然度和协调性的评估不够充分。
- **缺少与其他方法的详细对比分析**：未与 BagPiper 等混合场景方法在相同条件下的定量对比。
- **算力需求未披露**：无法评估该方法的训练成本与资源门槛，不利于社区复现和扩展。

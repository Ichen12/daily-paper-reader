## 摘要
语码转换在双语非洲对话中普遍存在，然而大多数自动语音识别（ASR）系统假设单语输入，并在精心设计的单语基准上进行评估。我们提出了AfriSwitch，一个61.36小时的人工转写的非正规场景语码转换语音基准，涵盖16种非洲语言及其变体，并附带切换级别的英语跨度标签、每话语语码混合指数（CMI）和切换点计数。语料库统计显示，非洲语言的混合行为在两个大致独立的轴上差异很大：说话者交替的频率以及混合的平衡程度。没有单一的标量能够捕捉一种语言的语码转换程度。对五个开放和商业多语言ASR系统进行零样本基准测试，得到的词错误率远高于同一语言已发表的单语数字，其中最佳系统平均词错误率为35.93%，且没有系统在任何语言上低于24%。针对非洲的训练，而非模型规模或名义上的语言覆盖范围，最能预测性能。

## Abstract
Code-switching is pervasive in bilingual African conversation, yet most ASR systems assume monolingual input and are evaluated on curated monolingual benchmarks. We present AfriSwitch, a 61.36-hour human-transcribed benchmark of in-the-wild code-switched speech spanning 16 African languages and language varieties, released with switch-level English span tags, perutterance Code-Mixing Index (CMI), and switch-point counts. Corpus statistics show that mixing behaviour varies widely across African languages along two largely independent axes: how often speakers alternate, and how balanced the mixture is. No single scalar captures how code-switched a language is. Benchmarking five open and commercial multilingual ASR systems zero-shot yields word error rates far above published monolingual figures for the same languages, with the best system averaging 35.93% WER and no system falling below 24% on any language. Africa-targeted training, not model scale or nominal language coverage, best predicts performance.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究动机**：非洲双语/多语日常交流中语码转换（Code-switching）极为普遍，即在同一句话内交替使用英语/法语、地区通用语与本地语言。然而，现有 ASR 系统大多假设输入是单语，且主流评测基准（如 AfriSpeech、FLEURS、SimbaBench 等）也基于单语话语构建；这导致“测量鸿沟”：在单语测试集上报告的准确率无法反映真实部署中的系统表现。
- **核心问题**：缺少一个同时满足以下条件的评测资源：
  1. 语音是**自然发生的语码转换**，而非合成或脚本化的；
  2. 语言覆盖足够广，能体现非洲语言之间混合模式的差异；
  3. 提供**切换级标注**，从而能直接度量嵌入语言（embedded-language）内容的识别质量，而不是被聚合 WER 平均掩盖。
- **整体含义**：本文通过发布 AfriSwitch 基准并零样本评测 5 个多语言 ASR 系统，证明“自然语码转换”是当前非洲 ASR 实际部署中的显著失败模式；且**非洲定向训练数据与训练策略**比模型规模或名义语言覆盖更能决定性能。

## 2. 方法论

### 2.1 核心思想

- 构建一个“野外”（in-the-wild）人工转写的语码转换语音基准，提供：
  - 每句话的 **Code-Mixing Index（CMI）** 与 **切换点计数（S\*）**；
  - **切换级英语跨度标签**（使用 `[[EN]] … [[/EN]]` 标记）。
- 基于该基准对现有 ASR 系统进行**零样本评测**，并采用严格、可复现的归一化与评分流程。

### 2.2 数据构建流程（AfriSwitch 数据集）

1. **语言选择**：覆盖 16 种非洲语言/变体，按地区分布：
   - 西非：Hausa、Igbo、Yoruba、Nigerian Pidgin、Akan、Wolof；
   - 东非：Swahili、Kinyarwanda、Amharic、Oromo、Luganda；
   - 南部非洲：Zulu、Shona、Tswana、Afrikaans；
   - 法语区：French。
2. **数据来源**：从公开 YouTube 视频和播客中获取，由非洲众包平台的双语标注者挑选含语码转换的片段。
3. **处理与转写**：
   - VAD 分段，短片段拼接至最多 40 秒以增加捕获切换点的概率；
   - 双语母语者进行逐字转写，经过初转写+审查+独立元审查两级质量控制；
   - 采用字符率过滤（各语言 5–95 百分位）剔除疑似音频/文本错位片段；
   - 对声音片段进行 **token 级英语标注**，自动标注并人工验证子集。
4. **指标定义**：
   - **S\*（切换点）**：任意一个 token 与前一个 token 语言标签不同的位置计数，统计每句话的平均值与语料总数；
   - **CMI**（Das & Gambäck 2014）：
     - 当 n > u 时：`CMI = 100 × [1 - max(w_i) / (n - u)]`
     - 当 n = u 时：`CMI = 0`
     - 其中 `w_i` 为语言 i 的词数，`max(w_i)` 为最显著语言词数，`n` 为总词数，`u` 为语言无关词数。
   - 两个指标被看作“两个大致独立的轴”：交替频率（S\*）与混合平衡度（CMI）。

### 2.3 ASR 评测方法（归一化与评分）

- **零样本设置**：不做任何微调，不注入代码切换训练数据；但会向模型提供每句话的**主导（矩阵）语言**（通过各系统文档化的接口，如语言 prompt 或语言 ID）。这是理想化/乐观条件，实际部署中语言标签通常不可用。
- **统一预处理的规则链**（对称地应用于假设与参考，不校正系统输出）：
  1. 删除标注标记（如 inaudible、silence、music 等），覆盖括号、花括号及裸形式；
  2. 删除语气填充词（ah、eh、hmm、um 等）；
  3. 数字规范化（如 twenty five → 25、third → 3rd）；
  4. 标点符号的口语化映射（comma/full stop/koma 等）；
  5. 排版规范化（弯引号、连字符、括号、冒号分号等替换为空格）；
  6. 小写化与空白压缩。
- **语言特定归一化器**：由语言学家编写、母语者验证；处理同一个词的不同拼写变体、词边界/附着语素约定、英语借词的本土化拼写等。规则集未随数据发布，以保证评测公平性。
- **变音符号保留**：不剥离组合变音符号（如 Yoruba 的声调、Igbo 的声调）。理由：剥离后如 `igba` 会混淆“两百/葫芦/时间/花园蛋”等多个词；保留变音才能反映真实识别能力。表中所有 WER 均为保变音符号的结果。
- **WER 计算**：使用 jiwer 计算**语料级 WER**（总编辑操作数 / 总参考词数，而不是每句 WER 的平均），避免长句被低权重；若一侧为空则用哨兵 token 替代。

### 3.4 定性错误分析（§4.5）

- 人工检查了 Sahara V2.5、Omnilingual LLM 7B、Gemini 3.6、ElevenLabs 四个系统的输出，归纳三种反复出现的失败模式：

  2. **脚本分离性影响**：Amharic 例句中，有的系统将英语词保留拉丁字母（视为切换），有的则将教授、大学名等均本土化为埃塞俄比亚音节文字（视为借词），后者被计为错误，但可能反映模型对“是否算切换”的歧义处理；
  3. **克里奥尔语的矩阵/嵌入边界问题**：Nigerian Pidgin 中，四个系统对首词 `gats` 给出 `gatz`、`guys`、`Gas`、省略四种不同结果，无人完全匹配参考；而对不歧义的 Pidgin 短语 `I dey do am professionally` 所有系统都识别得基本一致，说明错误集中在边界 token 而非 Pidgin 整体。

## 6. 主要结论与发现

1. **自然语码转换显著降低 ASR 性能**：所有系统的 WER 均远高于同一语言在单语基准上的公开数值，最佳系统平均 WER 为 35.93%，没有系统在任何语言上低于 24%。
2. **非洲定向训练是最强预测因素**：Sahara V2.5（非洲优化系统）在 10/12 语言上领先；同一家族从 V2 到 V2.5 的提升（59.90% → 35.93%）比所有其他系统之间的差距还大。
3. **模型规模/名义语言覆盖不等于实际能力**：Omnilingual 7B 宣称支持 1600+ 语言，但在非洲语码转换场景中表现弱于小规模非洲特化系统。
4. **不同语言的语码转换结构差异很大**：切换频率（S\*）与混合平衡度（CMI）两个维度独立；例如 Swahili 高频短切换（S\* = 10.29、CMI = 25.72），而 Akan 低频但平衡切换（S\* = 2.89、CMI = 28.20），Pidgin 两个指标都很低（1.46、4.19）——不能用单一标量衡量“语码转换程度”。
5. **系统选择比语言内在难度更关键**：同一语言上最差和最好系统的差距经常超过 40 个 WER 点。
6. **聚合 WER 掩盖系统中重要的失败模式**：切换边界删除几乎不被 WER 惩罚，点对点指标（如 PIER）是必要的补充。

- **缺乏条件对照**：未做“不提供主导语言 vs 提供主导语言”的对比，因此无法量化论文自述“乐观条件”带来的偏差幅度。
- **统计检验缺失**：未提供置信区间或显著性检验，难以判断系统间差距（如 Omnilingual 51.46% vs Gemini 55.05%）是否具有统计意义。
- **标注与标签的歧义**：英语 token 标注由自动流程生成并人工验证子集，但未报告验证覆盖率与标注者间一致性；对“借词 vs 切换”的界定标准也未量化说明。
- **语音内容单一性**：语料多为对话/播客语音，缺少命令式、朗读式或嘈杂环境语音，因此结论不能推广到所有非洲 ASR 应用场景。

## 9. 对相关工作的定位与创新点评估

- **与现有基准的区别**：
  - AfriSpeech、FLEURS、SimbaBench 等主要为单语话语，而 AfriSwitch 专门收集自然发生的语码转换语音；
  - 其他语码转换语料（如 Miami Bangor、SEAME）多为特定语言对或特定地区，AfriSwitch 覆盖非洲 16 种语言/变体的多样混合模式；
  - 提供 CMI 与 S* 两个独立指标，而多数语料只给整体标签或简单混合比例；
  - 提供英语跨度 token 标注，支持更细粒度的嵌入语言质量评估。
- **核心创新**：
  - 首次系统性地把“自然语码转换”作为非洲 ASR 的独立评测维度；
  - 证明“非洲定向数据+训练策略”比“模型规模”或“名义语言覆盖数”更重要，挑战了“大模型必然更好”的隐含假设；
  - 将定性错误分析（切换边界删除、脚本分离性）与定量 WER 结合，给出失败模式的机制性解释。
- **创新程度评估**：
  - 数据构建本身不是全新方法，但将其系统化应用于非洲低资源语码转换场景，填补了明确空缺；
  - 评测设计和指标选择相对成熟，其贡献更多在“资源+洞察”而非“新算法”。

## 10. 潜在改进方向

- 发布归一化规则与评测脚本，使 WER 完全可复现；
- 增加切换级指标（PIER、嵌入语言召回、切换点检测 F1）作为主报告指标；
- 补充不提供主导语言条件的对照实验，测量语言提示的乐观偏差；
- 扩充低资源语言（如 Afrikaans、Luganda）的语料时长至 5 小时以上，并给出置信区间；
- 对标注者一致性、英语跨度标签验证比例进行量化报告；
- 引入更多非洲语言变体（如肯尼亚 Swahili vs 坦桑尼亚 Swahili）和多说话人、多场景条件；
- 可考虑与下游应用（如医疗对话、客服）结合评测，验证实际部署中的影响。

## 11. 打分与推荐意见

- **创新性**：7.5/10（数据资源导向，系统评测设计扎实，但方法论本身没有突破性创新）
- **实验充分性**：6.5/10（60 个 WER 数据点+定性分析，但缺少切换级指标、消融和统计检验）
- **严谨性**：8/10（归一化与变音符号处理尤其严谨，但规则未公开影响可复现性）
- **资源价值**：9/10（非洲语码转换自然语音+标注公开，具有明确的社区价值）
- **写作清晰度**：8.5/10（表格清晰、失败模式解释直观、行文流畅）
- **总体推荐**：建议接收，但要求补充归一化规则发布或至少提供语言内置信区间；作为“资源+测评”论文，其数据价值足以支撑发表，但在实验分析完整性上仍有提升空间。

## 12. 总结

AfriSwitch 通过构建一个包含 16 种非洲语言/变体、61.36 小时自然语码转换语音的基准，首次系统揭示了“自然发生的语码转换”对现有多语 ASR 系统的显著挑战：所有评测系统平均 WER 均高于 35%，没有系统能在任何语言上低于 24%。更关键的是，论文证明非洲定向训练数据和训练策略（Sahara V2.5）比模型规模或名义语言覆盖数更能预测实际性能，而聚合 WER 会掩盖“系统直接删除嵌入英语短语”这类严重失败模式。数据集的 CMI 与 S* 双维度设计、token 级英语跨度标注、严格的归一化与变音符号保存流程，使 AfriSwitch 不仅是一个静态基准，也为未来切换级评测和更公平的低资源 ASR 研究提供了可扩展的平台。其核心局限在于评测仅限 12 种语言、WER 单一指标、归一化规则未公开以及缺少对照与统计检验，但这些均不影响其作为非洲 ASR 评测新标准的重要价值。

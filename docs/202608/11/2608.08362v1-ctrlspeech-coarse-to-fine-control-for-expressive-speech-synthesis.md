## 摘要
最近的文本到语音（TTS）系统已经实现了强大的自然度和零样本声音克隆性能，但在词或音素级别对表达性语音进行细粒度控制仍然具有挑战性。我们提出了CtrlSpeech，一个具有从粗到细控制的可控、表达性TTS框架。基于DiTAR架构，CtrlSpeech将全局说话人条件与音素对齐的音高、响度和时长信号相结合，在保留目标说话人音色的同时实现局部韵律控制。这种设计允许用户在精细的时间粒度上调整表达属性，使语音细化更加灵活和可控。实验结果表明，CtrlSpeech实现了具有竞争力的零样本TTS性能，并提高了对表达属性的可控性，展示了其在灵活实用的表达性语音合成中的有效性。

## Abstract
Recent Text-To-Speech (TTS) systems have achieved strong naturalness and zero-shot voice cloning performance, but fine-grained control of expressive speech at the word or phoneme level remains challenging. We propose CtrlSpeech, a controllable, expressive TTS framework with coarse-to-fine control. Built on the DiTAR architecture, CtrlSpeech combines global speaker conditioning with phone-aligned pitch, loudness, and duration signals, enabling localized prosodic control while preserving the target speaker's timbre. This design allows users to adjust expressive attributes at a fine temporal granularity, making speech refinement more flexible and controllable. Experimental results show that CtrlSpeech achieves competitive zero-shot TTS performance and improves controllability over expressive attributes, demonstrating its effectiveness for flexible and practical expressive speech synthesis.

# CtrlSpeech：用于表达性语音合成的从粗到细控制

## 1. 论文的核心问题与整体含义

**研究背景与动机**：

- 近年来，文本到语音（TTS）系统在自然度和零样本声音克隆方面取得了显著进展。基于参考条件的系统可以从短提示波形中合成未见说话人的语音，而基于文本提示和指令的系统则提供了更直观的说话风格控制接口。
- 然而，现有的TTS系统在**词或音素级别的精细表达控制**方面仍存在明显不足。具体表现在：
  - 说话人身份、韵律和风格高度纠缠，难以独立控制；
  - 即使模型暴露了多属性控制能力，控制通常仅在句子或话语层面提供（如全局风格提示），而非与特定音素或词对齐的时序信号；
  - 用户缺乏一种实用的方式来精确操纵局部韵律事件（如特定片段的音高、响度或时长），同时保留目标音色。

**核心问题**：如何在不牺牲零样本语音合成质量的前提下，实现词/音素级别的细粒度韵律控制？

**整体含义**：该论文提出了一种名为 CtrlSpeech 的可控表达性语音合成框架，通过从粗到细的控制机制，同时支持全局说话人条件与音素对齐的局部韵律信号控制，使语音合成更加灵活、可控且实用。

## 2. 论文提出的方法论

**核心思想**：CtrlSpeech 构建在 DiTAR（Diffusion Transformer Autoregressive）架构之上，采用“粗到细”的控制策略——以全局说话人条件作为粗粒度控制（控制音色），以音素对齐的基频（pitch）、响度（loudness）和时长（duration）信号作为细粒度控制（控制局部韵律），从而实现既保留目标说话人音色、又支持精细局部韵律调节的语音合成。

**关键技术细节**：

1. **连续语音表征**：
   - 使用 VAE（变分自编码器）将原始波形转换为连续的潜在表征，避免离散码本带来的信息损失。
   - 16 kHz 波形被压缩为 40 Hz 帧率、64 维的潜在 token 序列。
   - 编码器采用堆叠卷积层，解码器基于 BigVGAN 架构。

2. **Diffusion Transformer 自回归建模（DiTAR 主干）**：
   - 将连续 token 序列划分为大小为 P 的非重叠 patch（本文取 P=4）。
   - 采用两层级联生成：自回归模块捕获 patch 间的长程依赖；局部扩散 Transformer（LocDiT）重建下一个 patch 内的细粒度 token。
   - 扩散过程采用方差保持（VP）前向过程：x_t = α_t x₀ + σ_t ε，使用条件流匹配目标训练：L_diff = E‖v_θ(x_t,t) − v(x_t,t)‖²。

3. **可控属性设计**：

   **粗粒度条件（全局）** ：
   - 说话人嵌入：采用 CosyVoice 的方法，使用预训练的声纹模型（CAM++）提取说话人嵌入，用于保留目标音色。
   - 提示语音（prompt speech）也可作为辅助条件。

   **细粒度条件（局部、音素对齐）** ：
   - **音高（f0）** ：通过 WORLD 声码器（DIO 算法 + StoneMask 精化）提取基频，转换为 Mel 尺度（f_mel = 1127 ln(1 + f₀/700)），量化到 128 个 bin（65.0–650.0 Hz 范围），清音帧归为 bin 0，高于 650 Hz 归为 bin 127。
   - **响度**：波形先经过 A 加权滤波器（模拟人耳对中频更敏感的特性），计算帧级 RMS 能量并转换为 dB 刻度（L_dB = 20 log₁₀(max(RMS, ε))），截断到 −60~0 dB，量化到 64 个 bin（约 1 dB 分辨率）。
   - **时长**：使用强制对齐将音素与音频对齐，以音素覆盖的声学帧数作为音素时长。

4. **模型结构设计**：
   - 文本/控制 token 与声学 patch token 拼接后输入因果自回归 Transformer 主干，采用模态感知位置索引（文本和语音流分别重置位置）。
   - 自回归主干输出每个声学 patch 的上下文表征，作为条件传递给局部扩散解码器并行重建下一个 patch。
   - 训练目标：L = L_flow + λL_stop，其中 L_flow 为流匹配损失，L_stop 为辅助停止预测损失（对每个声学 patch 分类为第一/中间/最后）。
   - 推理时使用无分类器引导（CFG），32 步采样，引导尺度 1.5。

## 6. 论文的主要结论与发现

1. **零样本 TTS 性能具有竞争力**：CtrlSpeech（0.6B）在 LibriSpeech-PC 上达到 2.46% WER 和 0.65 SIM-o，在 Seed-TTS test-en 上达到 2.58% WER 和 0.63 SIM-o，均优于复现的 DiTAR 基线；SMOS 也显示出一致的说话人相似度提升。

2. **说话人条件组合效果最佳**：仅用说话人嵌入或仅用提示语音都能提升音色相似度，但两者结合效果最好（SIM-o 从 0.48/0.53 提升到 0.63），表明它们提供互补的说话人信息。

3. **细粒度控制显著改善韵律精度**：
   - 音高 RMSE 从 67.86 Hz 降至 38.39 Hz（0.6B），降幅 43%；
   - 响度 RMSE 从 6.35 dB 降至 4.56 dB（0.6B），降幅 28%；
   - 音素时长 MAE 从 28.08 降至 11.86（0.6B），降幅 58%，远超复现的 DiTAR（28.00）。

4. **该框架支持迭代精炼的实际应用**：用户可以先以粗粒度条件生成语音，再通过微调局部韵律信号逐步优化输出，提高了表达性 TTS 的实用性。

## 7. 优点

1. **创新性的从粗到细控制框架**：全局说话人条件 + 局部音素对齐韵律信号的组合设计，既解决了音色保持问题，又实现了细粒度的韵律操纵，弥补了现有 TTS 系统仅支持句子级控制的不足。

2. **基于连续表征的架构选择**：采用 VAE 连续潜在表征而非离散 codec token，避免了量化带来的信息损失和多阶段级联误差累积，更适合建模精细的韵律变化。

3. **扎实的骨干网络设计**：DiTAR 的 patch 级自回归 + 局部双向扩散解码的组合，兼顾了长程依赖建模和局部声学一致性；辅助停止预测损失进一步提升了生成稳定性。

4. **实用的用户工作流**：迭代精炼机制（先粗后细）符合实际使用场景，用户可以根据听感反馈逐步调整输出。

5. **消融实验设计完整**：对粗粒度（说话人条件）和细粒度（音高/响度/时长）控制都做了清晰的消融验证，归因明确。

6. **资源开放**：提供演示、代码和模型权重，便于复现和后续研究。

## 8. 不足与局限

**技术层面**：

1. **语言覆盖有限**：实验主要基于英文语音，多语言或代码混合合成效果未知，无法评估框架的跨语言泛化能力。

2. **依赖上游工具质量**：细粒度控制信号依赖音高提取（WORLD）和强制对齐工具，这些工具的误差会直接影响控制精度和合成质量。在噪声环境或非标准发音下，误差可能更严重。

3. **文本驱动时的韵律预测不足**：在仅提供文本的情况下（无显式控制信号），模型难以准确预测局部韵律，特别是音高（pitch RMSE 仍较高，且高于 DrawSpeech），限制了在纯文本场景下的表现力。
